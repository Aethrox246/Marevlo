Joint Distributions
& Marginals

One random variable is a line. Two is a plane. The relationships between variables — covariance, correlation, conditional structure — is where the interesting business signal lives. Every ML model is ultimately a joint distribution approximator.

Module 2.6 Joint PMF · Joint PDF · Marginals · Conditionals Independence · Covariance · Correlation Kartify: (Return, Late) · (Revenue, Category) · (X, Y) Evans & Rosenthal Ch. 2.5–2.7
⚡ Kartify — The Feature-Label Problem
Monday. Arjun is training a return-prediction model. He has features per order — delivery time, price, city, payment method — and a label: returned (1) or kept (0). He opens the notebook and types: X, y = df[features], df["returned"]. Then stops. What even is the thing he just split?

It's a sample from a joint distribution $P(X, Y)$ — features and label living together. Every ML model learns to approximate some function of this joint: logistic regression models $P(Y \mid X)$ (conditional), Naive Bayes models $P(X, Y)$ directly, GANs learn $P(X)$, and so on. Understanding joint distributions is understanding what an ML model is actually estimating.

This module builds the formal objects: joint PMFs and PDFs, marginals (recover one variable's distribution), conditionals (what we already met in 2.2, formalized across continuous variables), covariance (how variables move together), and the relationship between independence and zero-covariance.
// Section 1

Joint PMFs — Two Discrete Variables

A joint PMF describes the probability that two discrete random variables take specific values simultaneously.

Joint PMF · two discrete random variables
$$p_{X,Y}(x, y) = P(X = x, Y = y), \qquad \sum_{x, y} p_{X,Y}(x, y) = 1, \qquad p_{X,Y}(x, y) \ge 0$$

Kartify — the (returned, late) joint PMF

From Module 2.2's 1,000-order Kartify sample, normalized to probabilities:

$Y = 1$ (Returned)$Y = 0$ (Kept)$p_X$ (row sum)
$X = 1$ (Late)0.0350.1150.150
$X = 0$ (On-time)0.0450.8050.850
$p_Y$ (col sum)0.0800.9201.000

The interior four cells are the joint PMF $p_{X,Y}$. The row sums are the marginal PMF of $X$; the column sums are the marginal of $Y$. Marginalization is just "sum over the variable you want to forget."

Marginal PMFs — recovering one variable from the joint
$$p_X(x) = \sum_{y} p_{X,Y}(x, y), \qquad p_Y(y) = \sum_{x} p_{X,Y}(x, y)$$
Why "marginal" — the etymology
In hand-computed statistics tables of old, marginal distributions were literally written in the margins of the joint table — the row and column sums next to the cells. The name stuck. Conceptually: the marginal is what you get when you integrate (sum) out the other variable, leaving only one behind. Forgetting $Y$ gives you $p_X$.
// Section 2

Joint PDFs — Two Continuous Variables

For continuous joint distributions, density replaces mass. Probability lives in areas (for 2D) or volumes (higher dimensions), not at points.

Joint PDF · two continuous random variables
$$P((X, Y) \in A) = \iint_A f_{X,Y}(x, y)\, dx\, dy, \qquad \iint_{\mathbb{R}^2} f_{X,Y}(x, y)\, dx\, dy = 1$$
Marginal PDFs — integrate out the other variable
$$f_X(x) = \int_{-\infty}^{\infty} f_{X,Y}(x, y)\, dy, \qquad f_Y(y) = \int_{-\infty}^{\infty} f_{X,Y}(x, y)\, dx$$
Kartify · delivery time vs order value
Model. Let $X$ = delivery time (hours), $Y$ = order value (₹ '000). Joint density $f_{X,Y}(x, y) = c \cdot e^{-x/20} \cdot e^{-y/3}$ on $x, y > 0$ if they were independent (product form).
Normalization. $\iint f = 1$: $c \int_0^\infty e^{-x/20} dx \cdot \int_0^\infty e^{-y/3} dy = c \cdot 20 \cdot 3 = 60c$, so $c = 1/60$.
Marginals. $f_X(x) = \int_0^\infty (1/60) e^{-x/20} e^{-y/3} dy = (1/20) e^{-x/20}$ — Exp(1/20), mean 20h. Similarly $f_Y(y) = (1/3)e^{-y/3}$ — Exp(1/3), mean ₹3000.
Observation. Because $f_{X,Y}(x, y) = f_X(x) f_Y(y)$, these two are independent in this model. In real Kartify data they wouldn't be — bigger orders often take longer. Independence is the clean case; dependence is the interesting case.
// Section 3

Conditional Distributions — The Slicing Operation

Fix one variable at a value; look at the distribution of the other. For discrete:

Conditional PMF and PDF
$$p_{Y \mid X}(y \mid x) = \frac{p_{X,Y}(x, y)}{p_X(x)}, \qquad f_{Y \mid X}(y \mid x) = \frac{f_{X,Y}(x, y)}{f_X(x)}$$
Kartify · conditional return rate given late
From the joint table. $p_{Y \mid X}(Y=1 \mid X=1) = p_{X,Y}(1, 1) / p_X(1) = 0.035 / 0.150 = 0.233$.
Distribution of $Y$ given $X = 1$. $Y \mid X=1$ is Bernoulli$(0.233)$ — concentrated, not the marginal Bernoulli$(0.08)$.
Distribution of $Y$ given $X = 0$. $p(Y=1 \mid X=0) = 0.045/0.850 = 0.053$ — Bernoulli$(0.053)$.
The marginal $p_Y = 0.08$ is a weighted mix of these two conditional distributions: $0.08 = 0.150 \cdot 0.233 + 0.850 \cdot 0.053$. That's the Law of Total Probability (Module 2.2) stated in terms of joint PMFs.
The ML framing — conditionals are predictors
Every supervised ML model is a parametric approximation to $P(Y \mid X)$. Logistic regression: $P(Y = 1 \mid X) = \sigma(w^T X + b)$. Classification trees: piecewise-constant $P(Y \mid X)$ on leaf partitions. Neural nets: $P(Y \mid X) = \text{softmax}(f_\theta(X))$. Conditional distributions are the thing being learned. Everything else — losses, optimization, regularization — is mechanics.
// Section 4

Independence of Random Variables — The Product Rule

Module 2.2 defined independence for events. For random variables, the definition is structurally identical, stated over PMFs/PDFs:

Independence — discrete or continuous
$$X \perp Y \iff p_{X,Y}(x, y) = p_X(x)\, p_Y(y) \text{ for all } x, y$$
$$(\text{continuous:}) \; f_{X,Y}(x, y) = f_X(x)\, f_Y(y) \text{ for all } x, y$$
Kartify · are (late, returned) independent? Check via the joint PMF
If independent: $p_{X,Y}(1, 1)$ should equal $p_X(1) \cdot p_Y(1) = 0.150 \times 0.080 = 0.012$.
Observed: $p_{X,Y}(1, 1) = 0.035 = 2.92 \times$ the product. So not independent.
Same conclusion as Module 2.2, now seen as a joint PMF property. Independence = joint PMF factors into marginals, everywhere. A single cell violating the product kills independence.
◆ Why factorization matters in ML

Naive Bayes's "naive" assumption is: features are conditionally independent given the class. I.e., $p(X_1, X_2, \ldots, X_d \mid Y) = \prod_i p(X_i \mid Y)$. This lets the model be trained with only $O(d)$ parameters instead of $O(2^d)$. The assumption is wrong on correlated features (e.g., Kartify price and order value), but the model often works anyway — a celebrated case of "wrong but useful" modeling.

Covariance & Correlation — How Variables Move Together

Covariance · definition
$$\mathrm{Cov}(X, Y) = E[(X - E[X])(Y - E[Y])] = E[XY] - E[X]\,E[Y]$$
Pearson correlation · scaled covariance
$$\rho_{X,Y} = \frac{\mathrm{Cov}(X, Y)}{\sigma_X \sigma_Y}, \qquad \rho_{X,Y} \in [-1, 1]$$
Proof — the second form of Cov
1
$\mathrm{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)]$ — definition.
2
Expand: $= E[XY - X\mu_Y - Y\mu_X + \mu_X \mu_Y]$.
3
Linearity of expectation: $= E[XY] - \mu_Y E[X] - \mu_X E[Y] + \mu_X \mu_Y$.
4
Recognize $E[X] = \mu_X$, $E[Y] = \mu_Y$: $= E[XY] - \mu_X \mu_Y - \mu_X \mu_Y + \mu_X \mu_Y = E[XY] - \mu_X \mu_Y$. $\blacksquare$
Kartify · Cov(Late, Returned)
Compute $E[XY]$. $XY = 1$ only when both Late and Returned: $E[XY] = 1 \cdot 0.035 + 0 = 0.035$.
Means. $E[X] = 0.150$, $E[Y] = 0.080$.
Cov. $\mathrm{Cov}(X, Y) = 0.035 - 0.150 \cdot 0.080 = 0.035 - 0.012 = 0.023$.
Variances (Bernoulli). $\mathrm{Var}(X) = 0.150 \cdot 0.850 = 0.1275$. $\mathrm{Var}(Y) = 0.080 \cdot 0.920 = 0.0736$. $\sigma_X = 0.3571$, $\sigma_Y = 0.2713$.
Correlation. $\rho = 0.023 / (0.3571 \cdot 0.2713) = 0.023 / 0.0969 \approx 0.237$.
Reading. $\rho \approx 0.24$ — moderate positive correlation. Late deliveries and returns genuinely move together, but the relationship is not deterministic. Consistent with Module 2.2's "~3× more likely to return if late."
⚠ Zero covariance ≠ independence

Independence implies Cov = 0 (if both variances exist). The converse is not true. Example: $X \sim N(0, 1)$ and $Y = X^2$. $E[X] = 0$, $E[Y] = 1$, $E[XY] = E[X^3] = 0$ (odd function of Normal). So $\mathrm{Cov}(X, Y) = 0$. But $Y$ is a function of $X$ — they're totally dependent! Correlation only detects linear relationships. For general dependence, use mutual information or non-linear correlation measures.

$\rho = +1$
Perfect positive linear
$Y = aX + b$ with $a > 0$. Kartify example: quantity × unit price always gives revenue — perfect correlation.
$\rho \approx 0.3$
Moderate positive
(Late, Returned) at Kartify. Signal is real but noisy. Useful as a feature; not a guaranteed predictor.
$\rho = 0$
No linear relation
Kartify order-number parity vs. return: no relation. But watch for non-linear: $Y = X^2$ has $\rho = 0$ under Normal $X$.
$\rho = -1$
Perfect negative
$Y = -aX + b$, $a > 0$. Kartify: remaining inventory vs. orders shipped in a day — as one rises, the other falls deterministically.

The Covariance Matrix — Multiple Variables at Once

With $d$ random variables $X_1, \ldots, X_d$, the $d \times d$ covariance matrix $\Sigma$ stores all pairwise covariances:

Covariance matrix
$$\Sigma_{ij} = \mathrm{Cov}(X_i, X_j), \qquad \Sigma_{ii} = \mathrm{Var}(X_i)$$

Key properties: $\Sigma$ is symmetric ($\Sigma_{ij} = \Sigma_{ji}$) and positive semi-definite ($v^T \Sigma v \ge 0$ for any vector $v$). These properties are why covariance matrices show up all over ML:

⚡ Where the covariance matrix lives in ML

PCA: eigenvectors of $\Sigma$ give principal components. The top-$k$ eigenvectors minimize reconstruction error.

Multivariate Normal: $X \sim N(\mu, \Sigma)$ — $\Sigma$ defines the entire joint density.

Ridge regression / Gaussian Processes: $\Sigma$ (or its inverse) is the core object.

Gradient estimation: REINFORCE variance reduction uses covariance structure.

Kartify — a 4-feature covariance matrix

Consider four per-order features: $X_1$ = late (0/1), $X_2$ = price (₹'000), $X_3$ = delivery time (hours), $X_4$ = returned (0/1). An illustrative $\Sigma$:

$\Sigma$latepricetimeret
late0.1280.0320.1850.023
price0.0321.8500.4100.008

Reading off-diagonal: covariances — $\mathrm{Cov}(\text{late}, \text{time}) = 0.185 > 0$, late deliveries do have longer times (as expected). Scale-invariant reading: divide by $\sigma_i \sigma_j$ to get correlations.

Python — Joint Distributions in Code

python · joint PMF, marginals, conditionals — Kartify (Late, Returned)
import numpy as np
import pandas as pd

# Kartify 1000-order sample as joint counts
joint = np.array([
    [0.035, 0.115],   # Late:     [Returned, Kept]
    [0.045, 0.805]    # On-time:  [Returned, Kept]
])
assert np.isclose(joint.sum(), 1.0)     # must sum to 1

# Marginals — sum over the other axis
p_X = joint.sum(axis=1)                   # [P(X=1 late), P(X=0 on-time)]
p_Y = joint.sum(axis=0)                   # [P(Y=1 ret),  P(Y=0 kept)]
print(f"P(X=1, late)     = {p_X[0]:.3f}")
print(f"P(Y=1, returned) = {p_Y[0]:.3f}")

# Conditional P(Y | X) — divide joint row by marginal row
p_Y_given_X = joint / p_X[:, None]         # broadcast
print(f"P(Y=1 | X=1, late)   = {p_Y_given_X[0, 0]:.3f}")   # 0.233
print(f"P(Y=1 | X=0, ontime) = {p_Y_given_X[1, 0]:.3f}")   # 0.053

# Independence check: joint == outer product of marginals?
indep = np.outer(p_X, p_Y)
ratio = joint / indep
print(f"Ratio joint / (marginal product) at (1,1) = {ratio[0, 0]:.2f}x")
# = 2.92x; independence would give 1.0 — clearly dependent.
python · covariance, correlation, covariance matrix
import numpy as np
import pandas as pd

# Simulate 10k Kartify orders from the joint Bernoulli model
np.random.seed(42)
N = 10_000
joint_flat = np.array([0.035, 0.115, 0.045, 0.805])   # (L=1,R=1), (L=1,R=0), (L=0,R=1), (L=0,R=0)
idx = np.random.choice(4, size=N, p=joint_flat)
late = np.isin(idx, [0, 1]).astype(int)
ret  = np.isin(idx, [0, 2]).astype(int)

# Two ways to compute covariance
cov_def = np.mean((late - late.mean()) * (ret - ret.mean()))    # definition
cov_np  = np.cov(late, ret, ddof=0)[0, 1]                     # numpy
print(f"Cov(L, R) def    = {cov_def:.4f}")                # ~0.023
print(f"Cov(L, R) numpy  = {cov_np:.4f}")

# Pearson correlation
corr = np.corrcoef(late, ret)[0, 1]
print(f"Correlation      = {corr:.3f}")              # ~0.237

# Full covariance matrix on a 4-feature Kartify DataFrame
df = pd.DataFrame({
    "late": np.random.binomial(1, 0.15, N),
    "price": np.random.lognormal(1, 0.4, N),
    "time": np.random.exponential(18, N),
    "ret": ret,
})
print(df.cov().round(3))           # 4x4 covariance matrix
print(df.corr().round(3))          # 4x4 correlation matrix
