Week 8. Arjun is reviewing three analyses from last week. Each used a different statistical tool. Each gave a confidence interval or $p$-value. Each felt like a different technique.

Analysis 1. Campaign conversion rate — one-proportion $z$-test. "Is $\theta = 0.035$ ruled out?" $\to$ yes.
Analysis 2. Delivery time difference — two-sample $t$-test. "Does group A take longer than group B?" $\to$ yes.
Analysis 3. Conversion model — logistic regression coefficient test. "Does mobile lower conversion?" $\to$ yes.

Three different tests, three different test statistics, three different reference distributions. But here's what's striking: all three are special cases of a single framework. Each model has a likelihood function $L(\theta; \text{data})$. The MLE is the maximizer. The Fisher information measures the curvature at the maximum. Confidence intervals come from inverting a test; tests come from comparing likelihoods. The three families — Wald, score, likelihood ratio — are three different ways of measuring "how far is the null from the MLE?"

This module is the unifier. It takes you from "I know how to do a $t$-test" to "I can build the right inference for any parametric model by writing down its likelihood." That skill — deriving inference from first principles — is what separates statistical engineers from people who call library functions.

Running example. Kartify's conversion rate $\theta$ — a simple Bernoulli model where we can show all three test forms giving the same answer asymptotically, and pinpoint where they differ in finite samples.
// Section 1 · Likelihood vs Probability

Likelihood vs Probability — Two Views of the Same Function

Likelihood and probability involve the same mathematical object $f(x; \theta)$ but hold different variables fixed. This distinction is subtle but foundational.

Probability vs likelihood — what's fixed, what varies
$$P(\text{data} \mid \theta) = f(x_1, \ldots, x_n; \theta) \;\;\text{— } \theta \text{ fixed, } x \text{ varies}$$
$$L(\theta; \text{data}) = f(x_1, \ldots, x_n; \theta) \;\;\text{— } x \text{ fixed, } \theta \text{ varies}$$
Probability
A function of data
"Given this true $\theta$, what's the chance of observing this particular data?" Integrates to 1 over the data space. Used before you collect data — predictive.
Likelihood
A function of parameter
"Given this observed data, how plausible is each candidate $\theta$?" Does NOT integrate to 1 — it's not a probability over $\theta$ (unless you're Bayesian and apply a prior). Used after collecting data — inferential.
Relative, not absolute
Likelihood ratios are what matter
$L(\theta) / L(\theta')$ compares how plausible $\theta$ is relative to $\theta'$. The absolute value of $L$ isn't meaningful — multiplying by any constant doesn't change inference. This is why we work with log-likelihoods.
MLE
$\hat\theta = \arg\max L(\theta)$
The most plausible $\theta$ given the data. Module 4.1 introduced this; Module 5.3 applied it to logistic regression. Here we use it as a launching point for all of inference.
Why "likelihood of theta given data" is slightly misleading language
Likelihood is NOT a probability distribution over $\theta$. In the frequentist framework, $\theta$ is a fixed (unknown) constant, not a random variable. "Likelihood of $\theta$" is not "probability that $\theta$ equals some value" — it's "compatibility of $\theta$ with the observed data." That compatibility can be ranked and compared, but never normalized into a probability (without a prior). This distinction becomes concrete when we reach Bayesian inference in later tracks: posterior = prior × likelihood, and only after combining with a prior does $\theta$ acquire a probability distribution.
// Section 2 · The Log-Likelihood Surface

The Log-Likelihood Surface — Where Inference Lives

Almost all frequentist inference can be read off the shape of $\ell(\theta) = \log L(\theta)$ near its maximum. Three features of this surface matter:

Location
$\hat\theta$ — the maximum
The MLE itself. First-order condition: $\ell'(\hat\theta) = 0$. Best point estimate under the model.
Curvature
$-\ell''(\hat\theta)$ — observed Fisher information
How sharply $\ell$ peaks. Sharper peak = more precision. $\hat{\mathrm{Var}}(\hat\theta) \approx -1/\ell''(\hat\theta)$. Section 5 derives this rigorously.
Slope at null
$\ell'(\theta_0)$ — score at the null
How far up the slope we are when evaluating at $\theta_0$. A slope far from zero means $\theta_0$ is far from the MLE. Basis of the score test.
Height at null
$\ell(\hat\theta) - \ell(\theta_0)$ — LR drop
How much the log-likelihood falls from the peak to the null. Large drop = null is implausible. Basis of the likelihood ratio test.

// Section 3 · Likelihood Ratio Test

Likelihood Ratio Test — The Gold Standard for Nested Models

Likelihood ratio statistic
$$\Lambda = \frac{L(\theta_0)}{L(\hat\theta)} \quad \in (0, 1]$$
$$-2 \log \Lambda = 2[\ell(\hat\theta) - \ell(\theta_0)] \;\xrightarrow{d}\; \chi^2_k \quad \text{under } H_0$$

Where $k$ = number of restrictions in $H_0$ (typically the difference in dimensionality between the full and restricted parameter spaces). This is Wilks's theorem.

Sketch of Wilks's theorem — why $-2\log\Lambda \sim \chi^2$
1
Taylor-expand $\ell(\theta)$ around $\hat\theta$: $\ell(\theta) \approx \ell(\hat\theta) + \ell'(\hat\theta)(\theta - \hat\theta) + \tfrac{1}{2}\ell''(\hat\theta)(\theta - \hat\theta)^2$.
2
Since $\ell'(\hat\theta) = 0$ (MLE first-order condition): $\ell(\theta) \approx \ell(\hat\theta) + \tfrac{1}{2}\ell''(\hat\theta)(\theta - \hat\theta)^2$.
3
Therefore $\ell(\hat\theta) - \ell(\theta_0) \approx -\tfrac{1}{2}\ell''(\hat\theta)(\hat\theta - \theta_0)^2 = \tfrac{1}{2} \hat I(\theta) (\hat\theta - \theta_0)^2$, where $\hat I = -\ell''$ is observed Fisher info.
4
Under $H_0$: $\hat\theta - \theta_0 \sim N(0, 1/(n I(\theta_0)))$ asymptotically, so $\sqrt{n I(\theta_0)}(\hat\theta - \theta_0) \sim N(0, 1)$.
5
$-2\log\Lambda = 2[\ell(\hat\theta) - \ell(\theta_0)] \approx n I(\theta_0)(\hat\theta - \theta_0)^2$ — the square of a standard Normal $\sim \chi^2_1$. For $k$-dimensional restrictions, the same argument gives $\chi^2_k$. $\blacksquare$
Kartify · LRT for $H_0: \theta = 0.035$ vs $H_1: \theta \ne 0.035$
Data. $n = 12{,}000$, $k = 489$ conversions.
MLE. $\hat\theta = 489/12{,}000 = 0.04075$.
Log-likelihood at MLE. $\ell(\hat\theta) = 489 \log(0.04075) + 11511 \log(0.95925) = 489 \cdot (-3.200) + 11511 \cdot (-0.0416) = -1564.9 - 479.0 = -2043.9$.
Log-likelihood at null. $\ell(0.035) = 489 \log(0.035) + 11511 \log(0.965) = 489 \cdot (-3.352) + 11511 \cdot (-0.0356) = -1639.1 - 410.3 = -2049.4$.
LR statistic. $-2\log\Lambda = 2[-2043.9 - (-2049.4)] = 2 \cdot 5.5 = 11.0$.
$p$-value. $P(\chi^2_1 > 11.0) = 0.00091$.
Decision. Reject $H_0$ at any reasonable $\alpha$. LR strongly rejects 3.5% as the true rate.
// Section 4 · Wald Test

Wald Test — "How Far Is MLE from the Null?"

Wald statistic
$$W = \frac{(\hat\theta - \theta_0)^2}{\hat{\mathrm{Var}}(\hat\theta)} = \frac{(\hat\theta - \theta_0)^2}{1/(n \hat I(\hat\theta))} \;\xrightarrow{d}\; \chi^2_k$$

Or equivalently as a $z$-statistic: $z = (\hat\theta - \theta_0)/\hat{\mathrm{SE}}(\hat\theta) \sim N(0, 1)$. Wald is locally the Gaussian approximation of the log-likelihood surface at $\hat\theta$.

Kartify · Wald test on the same data
Fisher info at MLE. $\hat I(\hat\theta) = 1/[\hat\theta(1 - \hat\theta)] = 1/(0.04075 \cdot 0.95925) = 25.59$ per observation.
SE. $1/\sqrt{n \hat I(\hat\theta)} = 1/\sqrt{12000 \cdot 25.59} = 1/\sqrt{307080} = 0.001805$.
Wald $z$-statistic. $z = (0.04075 - 0.035)/0.001805 = 3.185$.
Wald $W = z^2 = 10.14$. $p = P(\chi^2_1 > 10.14) = 0.00145$.
Compare to LRT. LRT gave $-2\log\Lambda = 11.0$; Wald gives $W = 10.14$. Close but not identical. They agree asymptotically but differ in finite samples — here the LRT is slightly more extreme.
// Section 5 · Score Test

Score Test (Rao) — "How Steep Is the Slope at the Null?"

Score test
$$U(\theta) = \ell'(\theta), \qquad S = \frac{U(\theta_0)^2}{n I(\theta_0)} \;\xrightarrow{d}\; \chi^2_k$$

The score is the gradient of the log-likelihood. At the MLE, score is zero. Under $H_0$, the expected score is zero, so a large observed score at $\theta_0$ is evidence against $H_0$.

Kartify · score test — MLE never computed!
Score at null. For Bernoulli, $\ell'(\theta) = k/\theta - (n-k)/(1-\theta)$. At $\theta_0 = 0.035$: $U(0.035) = 489/0.035 - 11511/0.965 = 13971.4 - 11928.5 = 2042.9$.
Fisher info at null. $I(0.035) = 1/(0.035 \cdot 0.965) = 29.63$.
Score statistic. $S = (2042.9)^2 / (12000 \cdot 29.63) = 4{,}173{,}403 / 355{,}560 = 11.74$.
$p$-value. $P(\chi^2_1 > 11.74) = 0.00061$.
The magic. Score test gives a $p$-value (0.00061) that agrees with LRT (0.00091) and Wald (0.00145) — and critically, we never needed to compute the MLE. Just the score and Fisher info at the null. This is the score test's signature advantage.
// Section 6 · Three Tests Compared

Comparing LRT, Wald, and Score — The "Trinity"

TestUsesBest whenWeakness
Likelihood Ratio$\ell(\hat\theta)$ and $\ell(\theta_0)$Nested models; anytime both fits are cheapRequires fitting both full and restricted models
Wald$\hat\theta$, SE at MLEDefault in regression output tablesNot invariant to parameterization; misleading for skewed likelihoods
Score (Rao)Only the null modelMLE is expensive; hypothesis is at a boundarySlightly less powerful if MLE is easy to compute
The "trinity" — asymptotic equivalence, finite-sample differences
Under $H_0$, all three statistics converge to the same $\chi^2_k$ distribution as $n \to \infty$. They're three different ways of measuring the "distance" between the MLE and the null:
  • LRT — vertical drop in log-likelihood.
  • Wald — horizontal distance from $\hat\theta$ to $\theta_0$, scaled by SE.
  • Score — slope of log-likelihood at $\theta_0$.
When the log-likelihood is nearly quadratic (large $n$, well-behaved model), all three measure the "same" distance and agree. When it's skewed (small $n$, near parameter boundaries), they diverge. The LRT is usually recommended as the default — most invariant to reparameterization and generally most powerful.

// Section 7 · Fisher Information

Fisher Information — The Information Content of a Single Observation

Two equivalent definitions
$$I(\theta) = E\!\left[\left(\frac{\partial \log f(X; \theta)}{\partial \theta}\right)^2\right]$$
$$I(\theta) = -E\!\left[\frac{\partial^2 \log f(X; \theta)}{\partial \theta^2}\right] \;\;\text{(equivalent under regularity conditions)}$$
Why the two definitions agree — the "information identity"
1
Under regularity conditions, $E[U(\theta)] = E[\partial \log f / \partial \theta] = 0$ (score has mean zero). Follows from differentiating $\int f(x; \theta) dx = 1$ w.r.t. $\theta$ and interchanging integral and derivative.
2
Since $E[U] = 0$: $\mathrm{Var}(U) = E[U^2]$. This is the first definition of $I(\theta)$.
3
Differentiating $E[U(\theta)] = 0$ w.r.t. $\theta$ (and swapping integral/derivative): $E[\partial U/\partial \theta] + E[U^2] = 0$, so $E[\partial U/\partial \theta] = -E[U^2]$.
4
$\partial U/\partial\theta = \partial^2 \log f / \partial\theta^2$. Therefore $E[U^2] = -E[\partial^2 \log f/\partial\theta^2]$ — the two definitions match. $\blacksquare$
Observed vs expected Fisher information
$$I(\theta) = -E\!\left[\ell''(\theta)\right] \;\text{(expected)}, \qquad \hat I(\theta) = -\ell''(\theta) \;\text{(observed)}$$

In practice we compute the observed Fisher info at the MLE (evaluates $\ell''$ on the actual data). It's a consistent estimator of the expected Fisher info and has the practical advantage that you never need to take expectations analytically.

Cramér-Rao Lower Bound — revisited with full force
$$\mathrm{Var}(\hat\theta) \ge \frac{1}{n I(\theta)} \;\text{ for any unbiased } \hat\theta$$
⚡ Fisher information in multi-parameter models

For a vector $\boldsymbol\theta$, Fisher information is a matrix $\mathbf I(\boldsymbol\theta)$ with entries $I_{jk} = -E[\partial^2 \ell / \partial \theta_j \partial \theta_k]$. The CRLB becomes $\mathrm{Cov}(\hat{\boldsymbol\theta}) \succeq \mathbf I(\boldsymbol\theta)^{-1}/n$ in matrix ordering. For regression, this is exactly the covariance matrix of $\hat{\boldsymbol\beta}$ you get from statsmodels — the diagonal gives standard errors, off-diagonals give correlations between coefficient estimates.

// Section 8 · Profile Likelihood

Profile Likelihood — Inference for One Parameter When Others Are Nuisance

Real models have many parameters. To test or CI just one, we need to "get rid of" the nuisance parameters. Profile likelihood is the answer.

Profile likelihood
$$L_P(\theta_1) = \max_{\theta_2, \ldots, \theta_p} L(\theta_1, \theta_2, \ldots, \theta_p)$$

For each value of the parameter of interest $\theta_1$, maximize over the nuisance parameters. This collapses a $p$-dimensional likelihood to a 1-D curve — which you can then apply LRT, Wald, or score to.

Kartify · profile likelihood for the mobile coefficient in logistic regression
Setup. Kartify's logistic model: $\text{logit}(p) = \beta_0 + \beta_1 \text{time} + \beta_2 \text{pages} + \beta_3 \text{prior} + \beta_4 \text{mobile}$.
Question. Is $\beta_4 = 0$ (mobile has no effect)?
Profile likelihood approach. For each fixed value of $\beta_4$, refit the model estimating the other four coefficients. Record $\ell$ at each. Plot $\ell$ vs $\beta_4$.
Profile LRT. $-2[\ell_P(0) - \ell_P(\hat\beta_4)] \sim \chi^2_1$ under $H_0$.
Advantage over Wald. Profile LRT accounts for how the nuisance parameters "shift" to compensate when we fix $\beta_4$. The Wald test uses a Gaussian approximation centered on the full-model MLE — less accurate when the likelihood is non-quadratic in $\beta_4$.
// Section 9 · Model Selection Criteria

AIC and BIC from Likelihood — Model Selection as Penalized Likelihood

Module 5.2 introduced AIC and BIC briefly. Now we derive them from likelihood theory.

AIC and BIC
$$\text{AIC} = -2\ell(\hat{\boldsymbol\theta}) + 2k$$
$$\text{BIC} = -2\ell(\hat{\boldsymbol\theta}) + k \log n$$
AIC intuition
Estimate of expected Kullback-Leibler divergence
AIC asymptotically estimates the KL divergence between the fitted model and the true data-generating distribution. Minimizing AIC approximately minimizes expected prediction loss.
BIC intuition
Laplace approximation to Bayesian posterior
BIC approximates $-2 \log P(\text{data} \mid \text{model})$ under certain priors. Lowest BIC $\approx$ highest posterior probability. Grows with $n$ (log penalty), so it favors simpler models for large samples — "consistent" for the true model.
Both as penalized likelihood
$-2\ell + \text{penalty}$
Both start from the maximized log-likelihood (fit quality) and subtract a complexity penalty. AIC's penalty is $2k$; BIC's is $k \log n$. BIC penalty is larger once $n > e^2 \approx 7.4$.
Neither is "right"
Different goals, different winners
AIC targets prediction (picks denser models); BIC targets model identification (picks sparser). Report both; understand the trade-off. Cross-validation (Module 5.5) is a third, distribution-free alternative.
// Section 10 · Python

Python — Likelihood Inference Hands-On

python · LRT, Wald, and Score tests on Kartify Bernoulli data
import numpy as np
from scipy.stats import chi2

n, k = 12000, 489
theta_0 = 0.035
theta_hat = k / n

# Log-likelihood function
def log_lik(theta, n, k):
    return k * np.log(theta) + (n - k) * np.log(1 - theta)

# ─── Likelihood Ratio Test ───
ll_hat = log_lik(theta_hat, n, k)
ll_0 = log_lik(theta_0, n, k)
lr_stat = 2 * (ll_hat - ll_0)
lr_p = 1 - chi2.cdf(lr_stat, df=1)
print(f"LRT: -2 log Λ = {lr_stat:.3f}, p = {lr_p:.5f}")

# ─── Wald Test ───
fisher_info_mle = 1 / (theta_hat * (1 - theta_hat))
se_wald = 1 / np.sqrt(n * fisher_info_mle)
z_wald = (theta_hat - theta_0) / se_wald
wald_stat = z_wald ** 2
wald_p = 1 - chi2.cdf(wald_stat, df=1)
print(f"Wald: W = {wald_stat:.3f}, z = {z_wald:.2f}, p = {wald_p:.5f}")

# ─── Score Test ───
score_at_null = k / theta_0 - (n - k) / (1 - theta_0)
fisher_info_null = 1 / (theta_0 * (1 - theta_0))
score_stat = score_at_null ** 2 / (n * fisher_info_null)
score_p = 1 - chi2.cdf(score_stat, df=1)
print(f"Score: S = {score_stat:.3f}, p = {score_p:.5f}")

# All three reject H0 strongly. They agree asymptotically but differ in finite-sample values.
python · manual MLE via scipy.optimize, then profile likelihood
import numpy as np
from scipy.optimize import minimize
from scipy.stats import chi2

np.random.seed(42)
n = 200

# Simulated Kartify logistic data
X = np.column_stack([
    np.ones(n),
    np.random.normal(0, 1, n),                   # X1: time
    np.random.binomial(1, 0.6, n)                   # X2: mobile (focus parameter)
])
true_beta = [-1.0, 1.2, -0.5]
p_true = 1 / (1 + np.exp(-(X @ true_beta)))
y = np.random.binomial(1, p_true)

def neg_log_lik(beta, X, y):
    z = X @ beta
    return -np.sum(y * z - np.log1p(np.exp(z)))

# Full MLE
res_full = minimize(neg_log_lik, x0=np.zeros(3), args=(X, y))
beta_hat = res_full.x
ll_full = -res_full.fun
print(f"MLE: β̂ = {beta_hat.round(3)}, ℓ̂ = {ll_full:.2f}")

# Profile likelihood for β₂ (mobile coefficient)
# Fix β₂ at each candidate value, refit β₀, β₁
def profile_nll(b2_fixed, X, y):
    def nll_partial(b01):
        beta = np.array([b01[0], b01[1], b2_fixed])
        return neg_log_lik(beta, X, y)
    r = minimize(nll_partial, x0=[0, 0])
    return -r.fun

b2_grid = np.linspace(-2.5, 1.5, 40)
profile_ll = np.array([profile_nll(b2, X, y) for b2 in b2_grid])

# Profile LRT test for β₂ = 0
ll_null = profile_nll(0, X, y)
lrt = 2 * (ll_full - ll_null)
print(f"Profile LRT for β₂=0: {lrt:.3f}, p = {1-chi2.cdf(lrt, df=1):.4f}")

# Profile likelihood CI: all β₂ values where 2(ℓ̂ - ℓ_P(β₂)) ≤ χ²_{1, 0.95} = 3.841
ci_mask = 2 * (ll_full - profile_ll) <= 3.841
ci_b2 = b2_grid[ci_mask]
print(f"95% profile CI for β₂: [{ci_b2.min():.3f}, {ci_b2.max():.3f}]")
python · AIC and BIC for model comparison
import numpy as np
import statsmodels.api as sm

np.random.seed(42)
n = 500
X = np.random.normal(0, 1, (n, 5))
# Only first 2 predictors are truly active
y = 1.0 + 0.8*X[:, 0] + 0.5*X[:, 1] + np.random.normal(0, 1, n)

# Compare models with 1, 2, 3, 4, 5 predictors
print(f"{'Model':<10} {'params':>8} {'logL':>10} {'AIC':>10} {'BIC':>10}")
for p in range(1, 6):
    X_sub = sm.add_constant(X[:, :p])
    r = sm.OLS(y, X_sub).fit()
    print(f"p={p:<8}{p+1:>8} {r.llf:>10.2f} {r.aic:>10.2f} {r.bic:>10.2f}")

# AIC typically minimized at true model (p=2) or nearby.
# BIC's larger penalty makes it more aggressive at picking sparse models.

# LRT for nested models
from scipy.stats import chi2
r_reduced = sm.OLS(y, sm.add_constant(X[:, :2])).fit()
r_full = sm.OLS(y, sm.add_constant(X)).fit()
lrt = 2 * (r_full.llf - r_reduced.llf)
print(f"\nLRT (full vs 2-predictor): {lrt:.3f}, p = {1-chi2.cdf(lrt, df=3):.4f}")
# Small p → keep full; large p → parsimony
