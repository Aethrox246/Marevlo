The Normal Distribution
Deep Dive

One distribution deserves its own module. 80% of classical statistical inference runs through the Normal — every Z-score, every confidence interval, every linear regression, every Kalman filter. Standardization, the 68-95-99.7 rule, linear combinations, the multivariate Normal with its covariance geometry.

⚡ Kartify — Why Arjun Keeps Reaching for Normal
Thursday. Arjun has four unrelated tasks on his plate: (1) flag days where Mumbai revenue is "unusually high"; (2) compute a 95% confidence interval for the Delhi return rate; (3) model joint fluctuations of Mumbai × Delhi × Bengaluru revenue (correlated by shared marketing); (4) estimate the tail probability of total daily revenue exceeding ₹60 lakh.

Each of these uses the Normal distribution — not because the data is exactly Normal, but because the Normal is a powerful approximation whenever the quantity of interest is a sum or average of many independent contributions. Revenue is a sum across orders (CLT applies). Sample means are averages (CLT applies). Proportion estimates are scaled sums of Bernoullis (CLT applies). The Normal shows up everywhere because the machinery of adding independent things forces everything toward it.

This module drills into the Normal: its PDF and its closed-form percentiles; standardization (the Z-score, the single most-used statistical transform); linear combinations (sums, differences, scalar multiples — all stay Normal); and the multivariate Normal — where the covariance matrix becomes geometry, and Mahalanobis distance gives anomaly detection its mathematical backbone. Module 3.8 will finish the picture with the Central Limit Theorem — the reason the Normal shows up in the first place.
// Section 1

The Normal PDF — Bell, Symmetric, Infinite Support

Normal$(\mu, \sigma^2)$ · PDF, moments
$$f_X(x) = \frac{1}{\sigma \sqrt{2\pi}} \exp\!\left(-\frac{(x - \mu)^2}{2\sigma^2}\right), \quad x \in \mathbb{R}$$
$$E[X] = \mu, \quad \mathrm{Var}(X) = \sigma^2, \quad \text{median} = \text{mode} = \mu$$
Shape
Symmetric bell
Mean = median = mode. Symmetric around $\mu$. Inflection points at $\mu \pm \sigma$. No skew, no heavy tail — thin exponential decay both sides.
Support
All real numbers
$f_X(x) > 0$ for every $x \in \mathbb{R}$. Formally allows negative values — for revenue, this is a modeling approximation, acceptable only when $\mu - 3\sigma > 0$.
Closure
Linear combinations stay Normal
If $X \sim N(\mu_1, \sigma_1^2)$ and $Y \sim N(\mu_2, \sigma_2^2)$ independent, then $aX + bY \sim N(a\mu_1 + b\mu_2, a^2\sigma_1^2 + b^2\sigma_2^2)$. No other commonly-used family closes under all linear combinations.
Parameters
$\mu$ and $\sigma$ are sufficient
Two parameters describe the entire distribution. No higher moments needed — kurtosis is fixed at 3, skewness at 0. For any Normal inference, $\bar{X}$ and $s^2$ are all the data you need.
Why the strange constant $1/\sqrt{2\pi}$
It's the normalization factor. The integrand $e^{-x^2/2}$ doesn't have an elementary antiderivative, but its integral over $\mathbb{R}$ is exactly $\sqrt{2\pi}$ (Gaussian integral — standard trick uses polar coordinates on $\mathbb{R}^2$). Dividing by this makes the total area 1. Every time you see $\sqrt{2\pi}$ in statistics, that's this integral.

Standardization — Every Normal Becomes $Z$

The single most-used transform in statistics: given any $X \sim N(\mu, \sigma^2)$, the Z-score $Z = (X - \mu)/\sigma$ follows a standard Normal $N(0, 1)$. One table, one function, one tool — works for every Normal.

Standardization
$$X \sim N(\mu, \sigma^2) \;\;\Leftrightarrow\;\; Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$
$$P(X \le x) = \Phi\!\left(\frac{x - \mu}{\sigma}\right)$$
Why standardization works — change of variables
1
$Z = (X - \mu)/\sigma$ is a linear transformation with $a = 1/\sigma$, $b = -\mu/\sigma$.
2
By Normal closure under linear combinations: $E[Z] = (E[X] - \mu)/\sigma = 0$ and $\mathrm{Var}(Z) = \mathrm{Var}(X)/\sigma^2 = 1$.
3
Since linear-of-Normal is Normal: $Z \sim N(0, 1)$. $\blacksquare$
4
Corollary: $P(X \le x) = P(Z \le (x-\mu)/\sigma) = \Phi((x-\mu)/\sigma)$ where $\Phi$ is the standard Normal CDF.
Kartify · is today's Mumbai revenue "unusual"?
Setup. Historical Mumbai daily revenue $R \sim N(\mu = 10, \sigma = 1.2)$ (₹ lakh).
Today's observation. $R = 13.5$ lakh.
Z-score. $Z = (13.5 - 10) / 1.2 = 2.92$.
Tail probability. $P(R \ge 13.5) = 1 - \Phi(2.92) \approx 0.00175$.
Answer. A "13.5 or higher" day occurs about 1 in 570 days under the historical model. Flag it for investigation — is it a campaign success, a data glitch, or a genuine regime change?

⚡ The 1.96 that everyone uses

The "95% CI uses ±2σ" is a rough shortcut. The exact multiplier is 1.959964 — usually rounded to 1.96. Every Kartify CI built on Normal theory uses this number. Linear Combinations of Normals — Why Inference Uses Normal

Closure under linear combinations · independent Normals
$$X \sim N(\mu_1, \sigma_1^2), \; Y \sim N(\mu_2, \sigma_2^2), \; X \perp Y \;\;\Rightarrow\;\; aX + bY \sim N(a\mu_1 + b\mu_2, \; a^2\sigma_1^2 + b^2\sigma_2^2)$$
Proof via MGF (Module 2.7 preview)
1
MGF of $N(\mu, \sigma^2)$ is $M(t) = \exp(\mu t + \sigma^2 t^2 / 2)$.
2
$M_{aX}(t) = M_X(at) = \exp(a\mu t + a^2\sigma^2 t^2 / 2)$ — MGF of $N(a\mu, a^2\sigma^2)$. Scalar scaling works.
3
$M_{aX + bY}(t) = M_{aX}(t) \cdot M_{bY}(t)$ by independence $= \exp(a\mu_1 t + a^2 \sigma_1^2 t^2/2) \cdot \exp(b\mu_2 t + b^2\sigma_2^2 t^2/2)$.
4
$= \exp\!\left((a\mu_1 + b\mu_2) t + (a^2\sigma_1^2 + b^2\sigma_2^2) t^2/2\right)$ — exactly the MGF of $N(a\mu_1 + b\mu_2, a^2\sigma_1^2 + b^2\sigma_2^2)$. $\blacksquare$
Kartify · distribution of Mumbai + Delhi revenue
Setup. $R_M \sim N(10, 1.2^2)$, $R_D \sim N(8, 0.9^2)$, independent (simplifying assumption).
Total. $R_M + R_D \sim N(10 + 8, 1.2^2 + 0.9^2) = N(18, 2.25)$. $\sigma = 1.5$.
Difference. $R_M - R_D \sim N(10 - 8, 1.2^2 + 0.9^2) = N(2, 2.25)$. Note: variance adds even for differences — signs of coefficients square up.
95% CI for sum. $[18 - 1.96(1.5), 18 + 1.96(1.5)] = [15.06, 20.94]$ lakh.
Dependence matters. If $\mathrm{Cov}(R_M, R_D) > 0$ (shared marketing), variance of sum increases by $2\mathrm{Cov}$. Real Kartify model includes these — we come back to this in multivariate Normal.
◆ Why this closure underwrites all parametric inference

When you compute $\bar{X} = (X_1 + \ldots + X_n)/n$ for i.i.d. Normal$(\mu, \sigma^2)$: by closure, $\bar{X} \sim N(\mu, \sigma^2/n)$ — exact, not approximate. Every confidence interval for a Normal mean uses this. For non-Normal data, the CLT (Module 3.8) makes $\bar{X}$ approximately Normal — so Normal-based inference still applies asymptotically. Normal closure is why we have closed-form statistics; CLT is why we can use them even when data isn't Normal.

Multivariate Normal — The Joint-Distribution Workhorse

Extending Normal to a vector $\mathbf{X} = (X_1, \ldots, X_d)^T \in \mathbb{R}^d$. Replace mean with a vector $\boldsymbol{\mu}$, variance with a $d \times d$ covariance matrix $\boldsymbol\Sigma$:

Multivariate Normal $N_d(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ · PDF
$$f_{\mathbf{X}}(\mathbf{x}) = \frac{1}{(2\pi)^{d/2} |\boldsymbol\Sigma|^{1/2}} \exp\!\left(-\frac{1}{2}(\mathbf{x} - \boldsymbol\mu)^T \boldsymbol\Sigma^{-1} (\mathbf{x} - \boldsymbol\mu)\right)$$
Parameters
$\boldsymbol\mu \in \mathbb{R}^d$, $\boldsymbol\Sigma$ symmetric positive-definite
$\Sigma_{ii} = \mathrm{Var}(X_i)$, $\Sigma_{ij} = \mathrm{Cov}(X_i, X_j)$. Positive-definiteness ensures $\Sigma^{-1}$ exists and the quadratic form is valid.
Marginals
Every marginal is Normal
$X_i \sim N(\mu_i, \Sigma_{ii})$. Any linear combination $\mathbf{a}^T \mathbf{X} \sim N(\mathbf{a}^T \boldsymbol\mu, \mathbf{a}^T \boldsymbol\Sigma \mathbf{a})$. Closure extends fully.
Conditionals
Conditional of $X_2$ given $X_1 = x_1$ is Normal
$X_2 \mid X_1 = x_1 \sim N(\mu_2 + \Sigma_{21}\Sigma_{11}^{-1}(x_1 - \mu_1), \Sigma_{22} - \Sigma_{21}\Sigma_{11}^{-1}\Sigma_{12})$. Linear regression lives here.
Ellipsoid contours
Constant-density surfaces
$\{\mathbf{x}: (\mathbf{x} - \boldsymbol\mu)^T \boldsymbol\Sigma^{-1}(\mathbf{x} - \boldsymbol\mu) = c\}$ is an ellipsoid centered at $\boldsymbol\mu$, oriented by eigenvectors of $\boldsymbol\Sigma$, with axis lengths $\sqrt{c \lambda_i}$.
Kartify · joint model of Mumbai × Delhi × Bengaluru revenue
Setup. $\mathbf{R} = (R_M, R_D, R_B)^T \sim N_3(\boldsymbol\mu, \boldsymbol\Sigma)$ with $\boldsymbol\mu = (10, 8, 7)$ lakh, and correlations 0.4 (M↔D), 0.3 (M↔B), 0.2 (D↔B) from shared marketing.
Total revenue. $T = R_M + R_D + R_B = \mathbf{1}^T \mathbf{R} \sim N(\mathbf{1}^T \boldsymbol\mu, \mathbf{1}^T \boldsymbol\Sigma \mathbf{1}) = N(25, \text{sum of all } \Sigma_{ij})$.
Variance of total (with $\sigma$s 1.2, 0.9, 0.7). Diagonal: $1.44 + 0.81 + 0.49 = 2.74$. Off-diagonal (twice): $2[0.4(1.2)(0.9) + 0.3(1.2)(0.7) + 0.2(0.9)(0.7)] = 2[0.432 + 0.252 + 0.126] = 1.62$. Total $\mathrm{Var}(T) = 2.74 + 1.62 = 4.36$; $\sigma_T \approx 2.09$.
Check. Ignoring correlations (naive sum), $\sigma = \sqrt{2.74} = 1.66$ — understated by 26%. Correlation drives risk up; portfolio theory lives on this observation.

Mahalanobis Distance — Anomaly Detection's Backbone

Euclidean distance $\|\mathbf{x} - \boldsymbol\mu\|$ treats all dimensions equally. But Kartify's Mumbai revenue varies by $\sigma_M = 1.2$ while Pune varies by $\sigma_P = 0.4$ — a deviation of 2 lakh is routine in Mumbai and alarming in Pune. Mahalanobis distance fixes this by accounting for covariance structure.

Mahalanobis distance
$$D_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \boldsymbol\mu)^T \boldsymbol\Sigma^{-1} (\mathbf{x} - \boldsymbol\mu)}$$
What Mahalanobis actually measures
$D_M^2$ is the multivariate Z-score, squared. In 1D with scalar variance $\sigma^2$: $D_M^2 = (x-\mu)^2/\sigma^2 = Z^2$. In higher dimensions, $\Sigma^{-1}$ rescales each direction by its variance and rotates out correlations. A point is "far" in Mahalanobis distance if it sits outside the tight ellipsoid of typical observations — accounting for both spread and tilt. For multivariate Normal data, $D_M^2 \sim \chi^2_d$, which gives principled thresholds for "unusual."
Kartify · multivariate anomaly detection on (M, D, B) revenue
Today's observation. $\mathbf{r} = (11.5, 10.2, 6.8)$ lakh.
Per-city Z-scores. $Z_M = (11.5 - 10)/1.2 = 1.25$, $Z_D = (10.2 - 8)/0.9 = 2.44$, $Z_B = (6.8 - 7)/0.7 = -0.29$.
Per-city reading. Nothing individually extreme (Delhi is 2.4σ — notable but not alarming).
Mahalanobis $D_M^2$. Accounting for covariance matrix $\boldsymbol\Sigma$: computed $D_M^2 \approx 9.8$.
$\chi^2_3$ p-value. $P(\chi^2_3 > 9.8) \approx 0.020$ — ~1-in-50 day. Flag for investigation.
Why it matters. Individually each city looks fine-ish. But the joint configuration — Mumbai high AND Delhi high AND Bengaluru low — is unusual for Kartify because in normal times these cities co-vary. Mahalanobis catches structural anomalies that univariate rules miss. This is the core of every multivariate anomaly detector (one-class SVM, isolation forest, Gaussian-mixture-based outliers).

Python — Normal in Code, 1D to Multivariate

python · univariate Normal — Z-scores, CIs, tail tests
from scipy.stats import norm
import numpy as np

# Kartify Mumbai revenue ~ N(10, 1.2^2) ₹ lakh
mu, sig = 10, 1.2
R = norm(loc=mu, scale=sig)

# Today's observed revenue = 13.5 lakh. Is it unusual?
today = 13.5
z = (today - mu) / sig
p_tail = 1 - R.cdf(today)
print(f"Z = {z:.2f}σ  |  P(R ≥ {today}) = {p_tail:.4f}  |  ~1 in {int(1/p_tail)} days")

# 95% CI using the 1.96 multiplier
ci_low, ci_high = R.ppf(0.025), R.ppf(0.975)
print(f"95% CI: [{ci_low:.2f}, {ci_high:.2f}]")

# Verify 68-95-99.7 rule empirically
np.random.seed(42)
samples = R.rvs(100_000)
for k in [1, 2, 3]:
    inside = np.mean(np.abs(samples - mu) <= k * sig)
    print(f"Within ±{k}σ: {inside:.4f}  (theory: {2*norm.cdf(k) - 1:.4f})")
python · multivariate Normal — Kartify multi-city joint + Mahalanobis
import numpy as np
from scipy.stats import multivariate_normal, chi2

# Kartify multi-city revenue model — 3-dimensional Normal
mu = np.array([10, 8, 7])                         # means (lakh)
sigmas = np.array([1.2, 0.9, 0.7])                   # std devs
corr = np.array([[1.0, 0.4, 0.3],                      # correlation matrix
                 [0.4, 1.0, 0.2],
                 [0.3, 0.2, 1.0]])
Sigma = np.outer(sigmas, sigmas) * corr              # covariance matrix

print(f"Σ =\n{Sigma.round(3)}")

# Total revenue = sum of 3 Normals, still Normal
mu_total = mu.sum()
var_total = Sigma.sum()                          # 1^T Σ 1 for vector of ones
print(f"Total daily revenue: N({mu_total}, {var_total:.2f}), σ = {np.sqrt(var_total):.2f} lakh")

# Today's multivariate anomaly check
today = np.array([11.5, 10.2, 6.8])
diff = today - mu
D_sq = diff.T @ np.linalg.inv(Sigma) @ diff
print(f"Mahalanobis D² = {D_sq:.2f}, Mahalanobis distance = {np.sqrt(D_sq):.2f}")

# Chi-squared p-value — degrees of freedom = dimensionality
p_anomaly = 1 - chi2.cdf(D_sq, df=3)
print(f"P(χ²₃ ≥ {D_sq:.2f}) = {p_anomaly:.4f}  →  flag if small")

# Individual Z-scores (for comparison)
for city, i in zip(["Mumbai","Delhi","Bengaluru"], range(3)):
    z = (today[i] - mu[i]) / sigmas[i]
    print(f"  {city:10} Z = {z:+.2f}")
# Individually nothing is extreme, but the joint pattern is unusual — that's what Mahalanobis catches.
