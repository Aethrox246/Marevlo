ANOVA —
Analysis of Variance

Three or more groups, one continuous outcome. Running pairwise $t$-tests inflates Type I error — ANOVA tests "are all group means equal?" in one shot. Variance decomposition into between-group and within-group components, the $F$-statistic, post-hoc tests when you reject, and two-way factorial designs that handle interactions.

Module 4.6 SSB/SSW · $F$-test · Assumptions · Tukey HSD · Two-way ANOVA · Interaction Kartify: revenue by city, delivery by warehouse × category Montgomery Ch. 3 · Kutner et al. Ch. 16
⚡ Kartify — Saturday Sprint: Multi-City Revenue
Saturday. The CFO wants to know: "Does average daily revenue differ across Mumbai, Delhi, Bengaluru, and Chennai?" Four cities, continuous outcome. Running all six pairwise $t$-tests at $\alpha = 0.05$ gives a family-wise error rate of $1 - 0.95^6 \approx 26\%$ — far from the intended 5%. ANOVA solves this: one $F$-test at $\alpha = 0.05$ answers "at least one city is different" with controlled Type I error. If significant, post-hoc tests (Tukey HSD) identify which pairs differ, with multiplicity correction built in.

◆ ANOVA's promise: one test, controlled error

ANOVA tests $H_0: \mu_1 = \mu_2 = \ldots = \mu_k$ with a single $F$-test at $\alpha$. Type I error stays at $\alpha$ regardless of $k$. It's the correct first step — then post-hoc tests (which have their own multiplicity correction) find specific differences.

// Section 2

Variance Decomposition — SST = SSB + SSW

One-way ANOVA decomposition
$$\underbrace{\sum_{i,j} (X_{ij} - \bar X)^2}_{\text{SST (total)}} = \underbrace{\sum_{i} n_i (\bar X_i - \bar X)^2}_{\text{SSB (between)}} + \underbrace{\sum_{i,j} (X_{ij} - \bar X_i)^2}_{\text{SSW (within)}}$$
$F$-statistic
$$F = \frac{\text{SSB} / (k - 1)}{\text{SSW} / (N - k)} = \frac{\text{MSB}}{\text{MSW}} \;\sim\; F_{k-1, \; N-k} \text{ under } H_0$$
SSB / MSB
Between-group variability
How much group means differ from the grand mean. Large MSB = groups are "spread apart." Under $H_0$ (all means equal), this should be comparable to MSW.
SSW / MSW
Within-group variability
How much individual observations differ from their group mean. This is the "noise" — variation unexplained by group membership. MSW estimates $\sigma^2$ under $H_0$.
$F$ ratio
Signal / noise
$F \approx 1$ if groups don't differ. $F \gg 1$ if between-group variance dominates. One-sided test: only large $F$ provides evidence against $H_0$.
$\eta^2$
Effect size: SSB / SST
Proportion of total variance explained by group membership. $\eta^2 = 0.01$ (small), $0.06$ (medium), $0.14$ (large). Report alongside $F$ and $p$.
Kartify · one-way ANOVA for revenue by city
Data. Daily revenue (₹ lakh) over 30 days for 4 cities. $n_i = 30$ each, $N = 120$.
Group means. Mumbai: 48.2, Delhi: 44.5, Bengaluru: 46.1, Chennai: 43.8. Grand mean: 45.65.
SSB. $30[(48.2-45.65)^2 + (44.5-45.65)^2 + (46.1-45.65)^2 + (43.8-45.65)^2] = 30[6.50 + 1.32 + 0.20 + 3.42] = 343.4$.
SSW. Sum of within-group squared deviations $\approx 4200$ (from individual variation around city means).
$F$. $MSB = 343.4/3 = 114.5$. $MSW = 4200/116 = 36.2$. $F = 114.5/36.2 = 3.16$.
$p$-value. $P(F_{3, 116} > 3.16) \approx 0.028$. Reject $H_0$ at $\alpha = 0.05$.
$\eta^2$. $343.4 / (343.4 + 4200) = 0.076$ — medium effect. City explains ~8% of revenue variance.
Next step. ANOVA says "at least one city differs." Which ones? Tukey HSD (Section 5) pinpoints the pairs.

Assumptions of ANOVA — When $F$ Is Valid

Independence
Observations independent
Both within and between groups. Violated by repeated measures (use repeated-measures ANOVA or mixed models). Kartify: daily revenues across cities are independent.
Normality
Approximately Normal within groups
$F$-test is robust to moderate non-Normality for $n_i \ge 20$. For heavy-tailed data or small groups, use Kruskal-Wallis (Module 4.7).
Equal variances
Homoscedasticity
Groups should have similar variances. Rule of thumb: ratio of largest to smallest group variance $< 3$. If violated: use Welch's ANOVA (scipy.stats.alexandergovern or pingouin.welch_anova).
Diagnostics
Levene, Shapiro, residual plots
Levene's test for equal variances (less sensitive than Bartlett). Shapiro-Wilk per group for Normality. QQ plot of residuals. If assumptions fail → Kruskal-Wallis.
// Section 4

Post-Hoc Tests — Tukey HSD When $F$ Rejects

ANOVA says "at least one group differs" but not which. Post-hoc pairwise comparisons with multiplicity correction answer this.

Tukey's Honestly Significant Difference
$$\text{HSD} = q_{\alpha, k, N-k} \cdot \sqrt{\frac{\text{MSW}}{n_i}}, \qquad |\bar X_i - \bar X_j| > \text{HSD} \Rightarrow \text{significant}$$
Kartify · which cities differ? (Tukey HSD)
From ANOVA. MSW = 36.2, $n_i = 30$, $k = 4$, $N - k = 116$.
Studentized range. $q_{0.05, 4, 116} \approx 3.68$.
HSD threshold. $3.68 \cdot \sqrt{36.2/30} = 3.68 \cdot 1.099 = 4.04$ lakh.
Pairwise differences. Mumbai−Chennai: $|48.2 - 43.8| = 4.4 > 4.04$ ✓. Mumbai−Delhi: $|48.2 - 44.5| = 3.7 < 4.04$ ✗. Others are all below threshold.
Conclusion. Only Mumbai vs Chennai is significantly different after multiplicity correction. Mumbai−Delhi was close but not quite — more data might resolve it. Delhi, Bengaluru, and Chennai are statistically indistinguishable.
// Section 5

Two-Way ANOVA — Factorial Designs & Interactions

One-way ANOVA has one factor (city). Two-way adds a second factor (e.g., warehouse) and asks three questions simultaneously: main effect of Factor A, main effect of Factor B, and the interaction $A \times B$.

Two-way ANOVA decomposition
$$\text{SST} = \text{SS}_A + \text{SS}_B + \text{SS}_{AB} + \text{SSW}$$
What is an interaction?
An interaction means the effect of Factor A depends on the level of Factor B. Kartify example: delivery speed differs by warehouse (main effect of warehouse) and by category (main effect of category), but maybe Electronics ships fast from Warehouse 1 but slow from Warehouse 2, while Fashion shows the opposite pattern. This "crossed" effect is the interaction — the simple main effects don't tell the whole story. When interaction is significant: interpret main effects cautiously.
Kartify · two-way ANOVA: delivery time by warehouse × category
Design. 3 warehouses × 4 product categories = 12 cells. 50 orders per cell = 600 total.
Results. $F_{\text{warehouse}} = 8.2$ ($p = 0.0003$), $F_{\text{category}} = 3.1$ ($p = 0.026$), $F_{\text{interaction}} = 2.4$ ($p = 0.025$).
Interpretation. Both main effects are significant, and the interaction is borderline significant. The interaction tells Priya: the warehouse effect on delivery speed differs by category. A "warehouse is fast" generalization doesn't hold uniformly — some warehouse × category combinations are unexpectedly slow. Ops needs to investigate specific cells, not just warehouse averages.

Python — ANOVA from Scratch to Production

python · one-way ANOVA + Tukey HSD
import numpy as np
from scipy import stats

np.random.seed(42)
# Kartify revenue by city (₹ lakh, 30 days each)
mumbai = np.random.normal(48.2, 6.0, 30)
delhi = np.random.normal(44.5, 6.0, 30)
bengaluru = np.random.normal(46.1, 6.0, 30)
chennai = np.random.normal(43.8, 6.0, 30)

# One-way ANOVA
F_stat, p_val = stats.f_oneway(mumbai, delhi, bengaluru, chennai)
print(f"F = {F_stat:.2f}, p = {p_val:.4f}")

# Effect size: eta-squared
all_data = np.concatenate([mumbai, delhi, bengaluru, chennai])
grand_mean = all_data.mean()
SSB = 30 * sum((g.mean() - grand_mean)**2 for g in [mumbai,delhi,bengaluru,chennai])
SST = ((all_data - grand_mean)**2).sum()
print(f"η² = {SSB/SST:.3f}")

# Tukey HSD — requires statsmodels
from statsmodels.stats.multicomp import pairwise_tukeyhsd
labels = np.repeat(["Mumbai", "Delhi", "Bengaluru", "Chennai"], 30)
tukey = pairwise_tukeyhsd(all_data, labels, alpha=0.05)
print(tukey)
python · two-way ANOVA with interaction
import numpy as np
import pandas as pd
from statsmodels.formula.api import ols
from statsmodels.stats.anova import anova_lm

np.random.seed(42)
n_per_cell = 50

# Build balanced factorial design: 3 warehouses × 4 categories
rows = []
for wh in ["W1", "W2", "W3"]:
    for cat in ["Elec", "Fashion", "Home", "Sports"]:
        mu = 24 + (3 if wh == "W1" else -2 if wh == "W3" else 0)
        mu += (2 if cat == "Elec" else -1)
        # Interaction: W3 + Fashion is extra slow
        if wh == "W3" and cat == "Fashion":
            mu += 5
        vals = np.random.normal(mu, 4, n_per_cell)
        for v in vals:
            rows.append({"warehouse": wh, "category": cat, "delivery_hours": v})

df = pd.DataFrame(rows)
model = ols("delivery_hours ~ C(warehouse) * C(category)", data=df).fit()
table = anova_lm(model, typ=2)
print(table.round(3))
# Look for significant interaction — if present, main effects require careful interpretation
