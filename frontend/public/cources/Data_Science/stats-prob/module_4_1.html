Point Estimation —
MLE & Method of Moments

The first serious question of inference: given data, what's our best single-number estimate of the unknown parameter? Two answers — Method of Moments (simpler, consistent) and Maximum Likelihood (asymptotically optimal). Both give you $\hat\theta$; evaluating estimators requires the vocabulary of bias, variance, consistency, and efficiency.

⚡ Kartify — The Week Numbers Started Meaning Something
Monday, week 5. Priya sends Arjun a Slack message: "Growth team says the festive ad campaign is converting at 4.2%. We need to report this to the board on Friday. What's our estimate, how confident are we, and is 4.2% really different from our 3.5% baseline?"

Three questions, three modules. 4.1 answers estimate. Given $n = 12{,}000$ campaign exposures and $k = 489$ conversions, what's the best single-number estimate $\hat\theta$ of the true conversion rate? The naive answer $k/n = 0.04075$ is the MLE — but why is it optimal? When is it biased? How much variability does it have? What if the data were richer — a heavy-tailed revenue distribution instead of binary conversions? This module builds the framework for constructing and evaluating estimators, using Kartify's conversion-rate problem as the running example.

Two recipes dominate. Method of Moments, which we previewed in Track 3.5: match sample moments to theoretical moments, solve for parameters. Simple; always consistent; not always efficient. Maximum Likelihood Estimation (MLE): pick the $\theta$ that makes the observed data most probable. Usually efficient asymptotically; a bit harder to compute; deeper connections to information theory via the Fisher information and the Cramér-Rao lower bound. After this module, we'll have $\hat\theta$ for any reasonable model; Module 4.2 will wrap that $\hat\theta$ in a confidence interval.
// Section 1

What Is an Estimator? — The Vocabulary of Evaluation

Estimator
$$\hat\theta = \hat\theta(X_1, \ldots, X_n) \text{ — a function of the data used to estimate } \theta$$

An estimator is a recipe; an estimate is its output on one dataset. $\bar X$ is an estimator; "47.3" is an estimate. Because $\hat\theta$ depends on random data, $\hat\theta$ is itself a random variable — it has a distribution (the sampling distribution from Module 3.7), which is what we use to evaluate it.

Bias
$\mathrm{Bias}(\hat\theta) = E[\hat\theta] - \theta$
Systematic error. Unbiased: $E[\hat\theta] = \theta$. $\bar X$ is unbiased for $\mu$; the MLE $\hat\sigma^2_{\text{MLE}}$ for Normal variance is biased (factor $(n-1)/n$).
Variance
$\mathrm{Var}(\hat\theta) = E[(\hat\theta - E[\hat\theta])^2]$
Random fluctuation. Precision = inverse of variance. Standard error is $\sqrt{\mathrm{Var}(\hat\theta)}$ — the denominator in z/t statistics.
MSE
$E[(\hat\theta - \theta)^2] = \mathrm{Var} + \mathrm{Bias}^2$
Mean squared error combines both sources. The bias-variance decomposition. Minimizing MSE is the classical criterion for "best" estimator.
Consistency
$\hat\theta_n \xrightarrow{p} \theta$
Converges to truth as $n \to \infty$. Necessary bar for any serious estimator. Implied by unbiased + variance $\to 0$ via Chebyshev.
Bias-variance trade-off — the defining tension
Low-bias estimators often have high variance; low-variance estimators often pay bias to achieve it. The MLE for Normal variance has minimal variance but is biased. The unbiased $s^2$ corrects the bias but has slightly higher variance. James-Stein shrinkage estimators deliberately accept bias to dramatically reduce variance. Ridge regression, LASSO, regularization, Bayes with weak priors — all exploit this. "Unbiased" is not automatically "best"; MSE is the honest criterion.
Kartify · why $\bar X$ is the natural estimator of conversion rate
Data. $X_i \in \{0, 1\}$, where $X_i = 1$ means conversion, $X_i = 0$ else. $P(X_i = 1) = \theta$ — unknown.
Natural estimator. $\hat\theta = \bar X = k/n$ (fraction of conversions).
Bias. $E[\hat\theta] = E[\bar X] = \theta$ — unbiased.
Variance. $\mathrm{Var}(\hat\theta) = \theta(1-\theta)/n$. For Kartify ($n = 12000$, $\theta \approx 0.04$): $\mathrm{Var} = 0.04 \cdot 0.96 / 12000 \approx 3.2 \cdot 10^{-6}$. SE $\approx 0.00179$.
MSE. Variance + 0 = $3.2 \cdot 10^{-6}$. Consistent: $\mathrm{Var} \to 0$ as $n \to \infty$.
Priya's estimate. $\hat\theta = 489/12000 = 0.04075$, SE $\approx 0.00181$. "~4.08% ± 0.18% at 1 SE." The CI layer comes in Module 4.2.

Method of Moments — Match Sample Moments to Population Moments

Track 3.5 previewed this. Now we formalize. To estimate a $p$-parameter model: compute the first $p$ sample moments, set them equal to the corresponding population moments, solve for the parameters.

Method of Moments (MoM) recipe
$$\text{Solve } \; m_k = \mu_k(\theta) \text{ for } k = 1, 2, \ldots, p \; \text{ where } m_k = \frac{1}{n} \sum X_i^k$$
Worked example — MoM for a Gamma$(k, \lambda)$ model of delivery spread
1
Gamma has $E[X] = k/\lambda$, $\mathrm{Var}(X) = k/\lambda^2$. Two unknowns, two equations — good.
2
Set $\bar X = \hat k / \hat\lambda$ and $s^2 = \hat k / \hat\lambda^2$ (using sample variance as second moment about the mean).
3
Divide the two: $s^2 / \bar X = 1/\hat\lambda$, so $\hat\lambda = \bar X / s^2$.
4
Substitute back: $\hat k = \bar X \cdot \hat\lambda = \bar X^2 / s^2$.
5
Kartify data: $\bar X = 25$, $s^2 = 250$. Then $\hat\lambda = 25/250 = 0.1$, $\hat k = 625/250 = 2.5$. Done — two-parameter estimate in a few lines of algebra.
Strengths of MoM
Simple, consistent, closed-form
Usually just algebra — match sample means and variances, invert. Consistent under mild regularity conditions. Doesn't require numerical optimization. Great as a starting value for MLE.
Weaknesses
Not efficient; sensitive to outliers
Higher moments (3rd, 4th) are noisy; MoM using them is unstable. Can give nonsensical values (e.g., negative variance). Asymptotically worse than MLE.
When to use
Quick first-pass or MLE initialization
Kartify production workflow: MoM for a quick estimate, then numerical MLE (which needs an initial guess — use MoM). Two-phase estimation is common in fitting GLMs and mixture models.
Generalized MoM
GMM — econometrics workhorse
Generalized Method of Moments: use more moment conditions than parameters; weight them optimally. Used heavily in economics and finance. Beyond this module's scope; know it exists.

Maximum Likelihood — The Central Idea

Given data $x_1, \ldots, x_n$ from a parametric family $f(x; \theta)$, the likelihood $L(\theta)$ is the probability of the observed data as a function of $\theta$. MLE picks the $\theta$ that maximizes this.

Likelihood and log-likelihood
$$L(\theta \mid x_1, \ldots, x_n) = \prod_{i=1}^n f(x_i; \theta), \quad \ell(\theta) = \log L(\theta) = \sum_{i=1}^n \log f(x_i; \theta)$$
$$\hat\theta_{\text{MLE}} = \arg\max_\theta L(\theta) = \arg\max_\theta \ell(\theta)$$
Why log-likelihood, not likelihood
Two reasons. Numerical: $L$ is a product of $n$ probabilities — often $< 10^{-100}$ for reasonable $n$. Underflow. Log turns products into sums, keeping values representable. Analytical: $\ell = \sum \log f(x_i; \theta)$ is easy to differentiate (derivative of sum is sum of derivatives). The $\arg\max$ is preserved since $\log$ is monotone. Every MLE in practice is computed by maximizing $\ell$, not $L$.

Kartify — deriving the MLE for conversion rate

Bernoulli MLE — the canonical derivation
1
Model: $X_i \stackrel{\text{iid}}{\sim}$ Bernoulli$(\theta)$. PMF: $f(x; \theta) = \theta^x (1-\theta)^{1-x}$.
2
Likelihood: $L(\theta) = \prod \theta^{x_i}(1-\theta)^{1-x_i} = \theta^k (1-\theta)^{n-k}$, where $k = \sum x_i$.
3
Log-likelihood: $\ell(\theta) = k \log\theta + (n-k) \log(1-\theta)$.
4
First-order condition: $\ell'(\theta) = k/\theta - (n-k)/(1-\theta) = 0$.
5
Solve: $k(1-\theta) = (n-k)\theta \Rightarrow k = n\theta \Rightarrow \hat\theta_{\text{MLE}} = k/n$. Same as the MoM estimate — no coincidence; Bernoulli has one parameter.
6
Check second-order: $\ell''(\theta) = -k/\theta^2 - (n-k)/(1-\theta)^2 < 0$. Maximum, not minimum. $\blacksquare$
Kartify · applying Bernoulli MLE to the conversion data
Data. $n = 12{,}000$, $k = 489$ conversions.
MLE. $\hat\theta = 489/12000 = 0.04075$.
Property. Maximum likelihood is the "most plausible" conversion rate that generated these data under Bernoulli.
Note. For a single proportion, MLE = MoM. They diverge for richer models — where MLE's efficiency advantage starts to matter.

MLE for Normal — Two Parameters, Two First-Order Conditions

Normal$(\mu, \sigma^2)$ MLE — derivation
1
Log-likelihood: $\ell(\mu, \sigma^2) = -\frac{n}{2} \log(2\pi) - \frac{n}{2} \log \sigma^2 - \frac{1}{2\sigma^2} \sum (x_i - \mu)^2$.
2
$\partial \ell / \partial \mu = \frac{1}{\sigma^2} \sum (x_i - \mu) = 0 \Rightarrow \hat\mu_{\text{MLE}} = \bar X$. The sample mean, unsurprisingly.
3
$\partial \ell / \partial \sigma^2 = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4} \sum (x_i - \mu)^2 = 0 \Rightarrow \hat\sigma^2_{\text{MLE}} = \frac{1}{n} \sum (x_i - \bar X)^2$.
4
Note the divisor $n$ (not $n - 1$) — MLE of variance is biased. $E[\hat\sigma^2_{\text{MLE}}] = (n-1)\sigma^2/n$. The unbiased $s^2$ divides by $n - 1$. For large $n$ the difference vanishes.
⚠ MLE can be biased — Normal variance is the classic example

MLE isn't automatically unbiased. For Normal variance: MLE underestimates $\sigma^2$ by factor $(n-1)/n$. This is a finite-sample effect; $\hat\sigma^2_{\text{MLE}} \to \sigma^2$ as $n \to \infty$ (consistent). For $n = 100$, the bias is 1%; for $n = 10$, it's 10%. In practice, use the unbiased $s^2$ for reporting variance estimates.

MLE Properties — Consistency, Asymptotic Normality, Efficiency

Asymptotic behavior of MLE (under regularity conditions)
$$\hat\theta_{\text{MLE}} \xrightarrow{p} \theta_0 \quad (\text{consistent})$$
$$\sqrt n \, (\hat\theta_{\text{MLE}} - \theta_0) \xrightarrow{d} N\!\left(0, I(\theta_0)^{-1}\right) \quad (\text{asymptotically Normal and efficient})$$

$I(\theta)$ is the Fisher information — a measure of how much information a single observation carries about $\theta$.

Fisher information
$$I(\theta) = E\!\left[\left(\frac{\partial \log f(X; \theta)}{\partial \theta}\right)^2\right] = -E\!\left[\frac{\partial^2 \log f(X; \theta)}{\partial \theta^2}\right]$$
Interpretation
Curvature of log-likelihood
A sharp peak in $\ell(\theta)$ means the data strongly pin down $\theta$ — high Fisher information. Flat $\ell$ means loose identification — low information.
Cramér-Rao lower bound
$\mathrm{Var}(\hat\theta) \ge 1/(n I(\theta))$
The minimum possible variance for any unbiased estimator. MLE asymptotically achieves this bound — nothing else can be more efficient (in the limit).
Kartify Bernoulli
$I(\theta) = 1/[\theta(1-\theta)]$
Information per observation for Bernoulli. Max at $\theta = 0.5$; low near $\theta = 0$ or $1$ (need more data to pin down rare-event rates).
Practical takeaway
$\mathrm{SE}(\hat\theta_{\text{MLE}}) \approx 1/\sqrt{n I(\hat\theta)}$
Wald-based CI in Module 4.2 uses exactly this: $\hat\theta \pm z \cdot 1/\sqrt{nI(\hat\theta)}$. Information + MLE = asymptotic inference machinery.
Deriving Fisher information for Bernoulli$(\theta)$
1
$\log f(x; \theta) = x \log\theta + (1-x)\log(1-\theta)$.
2
Second derivative: $\partial^2/\partial\theta^2 = -x/\theta^2 - (1-x)/(1-\theta)^2$.
3
$I(\theta) = -E[\cdot] = \theta/\theta^2 + (1-\theta)/(1-\theta)^2 = 1/\theta + 1/(1-\theta) = 1/[\theta(1-\theta)]$.
4
CRLB for $\hat\theta$: $\mathrm{Var}(\hat\theta) \ge \theta(1-\theta)/n$. But $\mathrm{Var}(\bar X) = \theta(1-\theta)/n$ exactly — MLE hits the bound in finite samples here, not just asymptotically. $\bar X$ is efficient for Bernoulli $\theta$.

Sufficient Statistics — Compression Without Loss

A statistic $T(X_1, \ldots, X_n)$ is sufficient for $\theta$ if the conditional distribution of the data given $T$ does not depend on $\theta$. In practical terms: once you know $T$, the raw data tells you nothing more about $\theta$.

Factorization theorem (Neyman–Fisher)
$$T \text{ sufficient for } \theta \;\;\Leftrightarrow\;\; f(x_1, \ldots, x_n; \theta) = g(T(x), \theta) \cdot h(x_1, \ldots, x_n)$$
Kartify · the sufficient statistic for conversion rate
Data. $X_1, \ldots, X_n$ iid Bernoulli$(\theta)$.
Joint PMF. $\prod \theta^{x_i}(1-\theta)^{1-x_i} = \theta^{\sum x_i}(1-\theta)^{n - \sum x_i}$.
Factorization. Depends on $x$ only through $T = \sum x_i$. Set $g(T, \theta) = \theta^T (1-\theta)^{n-T}$, $h(x) = 1$. Sufficiency established.
Practical meaning. To estimate Kartify's conversion rate, you only need the total count of conversions — not the individual sequence of 1s and 0s. This is why the MLE depends only on $k$: the sequence has been losslessly compressed into a single number. Sufficient statistics are the reason we can summarize gigabytes of raw data with a handful of numbers for inference.
⚡ Minimal sufficient statistics — the most compressed summary

A minimal sufficient statistic cannot be further compressed without losing information. For iid data, the order statistics $(X_{(1)}, \ldots, X_{(n)})$ are always sufficient (trivially — they contain all the data). More interesting: for Bernoulli, $\sum X_i$ is minimal sufficient (one number). For Normal, $(\bar X, s^2)$ is minimal sufficient (two numbers). The exponential family is exactly the class of models with finite-dimensional sufficient statistics — the reason GLMs and many ML models are analytically tractable.

Python — Estimators, MLE, and Diagnostics

python · MLE for Bernoulli from Kartify data
import numpy as np
from scipy.stats import bernoulli

# Kartify campaign conversion data
np.random.seed(42)
n, true_theta = 12_000, 0.04
data = bernoulli.rvs(true_theta, size=n)
k = data.sum()
print(f"Observed: {k} conversions out of {n} exposures")

# MLE: closed-form, same as MoM
theta_hat = k / n
print(f"θ̂ (MLE) = {theta_hat:.5f}  (true θ = {true_theta})")

# Standard error via Fisher information
fisher_info_per_obs = 1 / (theta_hat * (1 - theta_hat))
se = 1 / np.sqrt(n * fisher_info_per_obs)
print(f"SE(θ̂) = {se:.5f}  (CRLB-achieved by MLE)")

# Also: via direct variance formula (equivalent)
se_direct = np.sqrt(theta_hat * (1 - theta_hat) / n)
print(f"SE direct = {se_direct:.5f}  (identical)")
python · numerical MLE for Gamma — when closed-form gets painful
import numpy as np
from scipy.stats import gamma
from scipy.optimize import minimize

# Simulate Kartify delivery times as Gamma
np.random.seed(42)
k_true, lam_true = 2.5, 0.1
data = np.random.gamma(shape=k_true, scale=1/lam_true, size=5000)

# MoM — closed-form initial estimate (Module 3.5 recipe)
xbar, var = data.mean(), data.var(ddof=1)
k_mom = xbar**2 / var
lam_mom = xbar / var
print(f"MoM: k̂ = {k_mom:.3f}, λ̂ = {lam_mom:.4f}")

# MLE — numerical optimization on the log-likelihood
def neg_log_lik(params):
    k_p, lam_p = params
    if k_p <= 0 or lam_p <= 0:
        return np.inf
    return -gamma.logpdf(data, a=k_p, scale=1/lam_p).sum()

result = minimize(neg_log_lik, x0=[k_mom, lam_mom], method="Nelder-Mead")
k_mle, lam_mle = result.x
print(f"MLE: k̂ = {k_mle:.3f}, λ̂ = {lam_mle:.4f}")

# MoM gave us a good starting point → MLE converges fast
# Asymptotically MLE is more efficient; MoM differs in small samples
python · illustrating Cramér-Rao lower bound via Monte Carlo
import numpy as np

np.random.seed(42)
true_theta = 0.04
n = 12_000
n_trials = 5_000

# Sampling distribution of MLE via simulation
estimates = [np.random.binomial(n, true_theta) / n for _ in range(n_trials)]
empirical_var = np.var(estimates, ddof=1)

# Cramér-Rao lower bound
crlb = true_theta * (1 - true_theta) / n

print(f"Empirical Var(θ̂): {empirical_var:.3e}")
print(f"CRLB:              {crlb:.3e}")
print(f"Ratio:             {empirical_var / crlb:.4f}  (1.0 = MLE hits CRLB)")

# For Bernoulli, MLE achieves CRLB exactly (finite-sample, not just asymptotic).
# Other models: MLE hits CRLB only as n → ∞. Finite-sample MLE is near-optimal but not exact.
