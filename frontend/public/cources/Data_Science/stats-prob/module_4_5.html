Chi-Square
Tests

Beyond "is A different from B?" — categorical data with more than two levels. The $\chi^2$ goodness-of-fit test asks "does the data follow this distribution?" The $\chi^2$ test of independence asks "are these two categorical variables related?" Both are special cases of comparing observed counts to expected counts.

⚡ Kartify — Friday's Multi-Category Questions
Friday. Two new questions land on Priya's desk that the tests from Module 4.4 cannot answer.

Marketing: "We designed the ad mix to hit 40% Electronics, 25% Fashion, 20% Home, 15% Sports. Are actual orders matching this target?" — five categories, not two. The two-proportion $z$-test handles two categories; this needs a goodness-of-fit test across all five.

Operations: "Is the return rate related to product category? Fashion has high returns; Electronics low. Is this real or just noise?" — two categorical variables (category × returned), each with multiple levels. This needs a test of independence on the full cross-tabulation.

Both reduce to the same machinery: compare observed cell counts to what you'd expect under a specific null hypothesis, then measure the total discrepancy with a $\chi^2$ statistic. Large discrepancy → reject the null. The $\chi^2$ distribution (sum of squared standard Normals, from Module 3.7) provides the reference distribution.
// Section 1

The $\chi^2$ Statistic — Observed vs Expected

Pearson's chi-squared statistic
$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}$$
$O_i$
Observed count in cell $i$
What the data actually shows. Always an integer (count).
$E_i$
Expected count under $H_0$
What you'd expect if $H_0$ were true. Computed from null probabilities × total $n$. Does not need to be an integer.
Distribution
$\chi^2 \approx \chi^2_\nu$ for large $n$
Asymptotically $\chi^2$ with $\nu$ degrees of freedom. The approximation requires $E_i \ge 5$ in all cells (Cochran's rule). For small expected counts, use Fisher's exact or simulation.
Interpretation
Large $\chi^2$ → data deviates from null
Reject $H_0$ if $\chi^2 > \chi^2_{\nu, \alpha}$ (upper $\alpha$ critical value). Always one-sided — only large values provide evidence against the null.
// Section 2

Goodness-of-Fit — Does the Data Follow This Distribution?

$\chi^2$ goodness-of-fit test
$$H_0: p_i = p_{i,0} \text{ for } i = 1, \ldots, k, \qquad \nu = k - 1$$
$$E_i = n \cdot p_{i,0}, \qquad \chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}$$
Kartify · does the order category mix match the ad target?
Null. $H_0$: orders follow (Electronics 40%, Fashion 25%, Home 20%, Sports 15%).
Data. $n = 2000$ orders. Observed: Electronics 850, Fashion 480, Home 370, Sports 300.
Expected. 800, 500, 400, 300.
$\chi^2$. $(850-800)^2/800 + (480-500)^2/500 + (370-400)^2/400 + (300-300)^2/300 = 3.125 + 0.800 + 2.250 + 0.000 = 6.175$.
df. $k - 1 = 3$.
$p$-value. $P(\chi^2_3 > 6.175) \approx 0.103$.
Decision. $p = 0.103 > 0.05$. Fail to reject $H_0$. Data is consistent with the target distribution at 5% significance. The slight over-index in Electronics (42.5% vs 40%) and under-index in Home (18.5% vs 20%) are within sampling noise.
// Section 3

Test of Independence — Are Two Categorical Variables Related?

$\chi^2$ test of independence for $r \times c$ table
$$H_0: p_{ij} = p_{i \cdot} \cdot p_{\cdot j} \text{ for all } i, j \qquad (\text{independence})$$
$$E_{ij} = \frac{(\text{row } i \text{ total}) \times (\text{col } j \text{ total})}{n}, \qquad \nu = (r - 1)(c - 1)$$
Kartify · is return rate related to product category?

Kartify · computing the independence test
Expected counts under $H_0$. Overall return rate: $320/5000 = 6.4\%$. $E_{\text{Elec, Ret}} = 2000 \cdot 0.064 = 128$. Fashion: $1250 \cdot 0.064 = 80$. Home: $64$. Sports: $48$.
$\chi^2$. $(60-128)^2/128 + (180-80)^2/80 + (50-64)^2/64 + (30-48)^2/48 + \ldots$ (non-returned columns contribute too). Total $\chi^2 \approx 237.1$.
df. $(4-1)(2-1) = 3$.
$p$-value. $P(\chi^2_3 > 237.1) < 10^{-50}$. Reject overwhelmingly.
Conclusion. Return rate and category are strongly dependent. Fashion returns at 14.4% vs Electronics at 3% — the test confirms what the numbers suggest. Where the dependence lives: the standardized residuals $r_{ij} = (O_{ij} - E_{ij})/\sqrt{E_{ij}}$ show Fashion returns drive the signal (residual $\approx +11.2$).
// Section 4

Effect Size — Cramér's V

Cramér's V — normalized $\chi^2$ effect size
$$V = \sqrt{\frac{\chi^2}{n \cdot (\min(r, c) - 1)}}, \qquad V \in [0, 1]$$
Cramér's VInterpretationKartify example
$< 0.1$NegligibleReturn rate vs payment method (minimal relationship)
$0.1 - 0.3$Small to moderateReturn rate vs device type (mobile returns slightly more)
$0.3 - 0.5$Moderate to strongReturn rate vs product category (strongly different rates)
$> 0.5$StrongRare — near-deterministic relationship between categories
Kartify · Cramér's V for category × returned
Computation. $V = \sqrt{237.1 / (5000 \cdot (2-1))} = \sqrt{0.0474} = 0.218$.
Interpretation. Small-to-moderate effect. Statistically significant (huge $\chi^2$) but the overall association is moderate — category explains some return variation but far from all of it.
// Section 5

Special Cases & Corrections — Small Counts, 2×2, Yates

Small expected counts
$E_i < 5$ → use exact tests
Cochran's rule: $\chi^2$ approximation is unreliable when any expected count is below 5. Use Fisher's exact test (2×2) or simulation-based $p$-values for larger tables.
Yates continuity correction
$\sum (|O_i - E_i| - 0.5)^2/E_i$
For 2×2 tables: subtracts 0.5 from each $|O - E|$ to better approximate the discrete binomial. Conservative — modern practice often skips this and uses Fisher's exact instead.
2×2 equivalence
$\chi^2 = z^2$ for 2×2
A 2×2 $\chi^2$ independence test is mathematically equivalent to the two-proportion $z$-test from Module 4.4. $\chi^2 = z^2$; same $p$-value. One test, two names.
Standardized residuals
$(O_{ij} - E_{ij})/\sqrt{E_{ij}}$
After rejecting independence, inspect residuals to see which cells drive the effect. Kartify: Fashion returned has residual +11.2 (the biggest driver). Electronics returned has -6.0 (fewer returns than expected).
// Section 6

Python — Chi-Square in Practice

python · goodness-of-fit test — Kartify category distribution
from scipy.stats import chisquare
import numpy as np

# Kartify: observed orders by category
observed = np.array([850, 480, 370, 300])
n = observed.sum()

# Expected under target: 40% Elec, 25% Fashion, 20% Home, 15% Sports
expected_fracs = np.array([0.40, 0.25, 0.20, 0.15])
expected = n * expected_fracs

chi2, p = chisquare(observed, f_exp=expected)
print(f"χ² = {chi2:.3f}, df = {len(observed)-1}, p = {p:.4f}")
# p ≈ 0.103 → fail to reject at 5%. Data consistent with ad target mix.
python · test of independence — category × returned
import numpy as np
from scipy.stats import chi2_contingency

# Kartify 4×2 contingency table (category × returned)
table = np.array([
    [60,  1940],   # Electronics
    [180, 1070],   # Fashion
    [50,  950],    # Home
    [30,  720],    # Sports
])

chi2, p, dof, expected = chi2_contingency(table)
print(f"χ² = {chi2:.1f}, df = {dof}, p = {p:.2e}")

# Cramér's V
n = table.sum()
min_dim = min(table.shape) - 1
V = np.sqrt(chi2 / (n * min_dim))
print(f"Cramér's V = {V:.3f}")

# Standardized residuals — which cells drive the effect?
residuals = (table - expected) / np.sqrt(expected)
labels = ["Elec", "Fashion", "Home", "Sports"]
print("\nStandardized residuals (Returned column):")
for i, lab in enumerate(labels):
    print(f"  {lab:10}: {residuals[i, 0]:+.1f}")
# Fashion: large positive residual → far more returns than expected
