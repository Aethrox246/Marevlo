⚡ Kartify — The Question That Starts Every Regression
Week 6. Priya's CMO asks three related questions that sound different but share one shape:

"If we spend ₹10 lakh more on ads, how many more conversions do we get?"
"If delivery time increases by 1 hour, how much does the return rate go up?"
"For every additional minute a user spends browsing, how much more are they likely to spend?"

Each question is asking the same thing: for a unit change in $X$, what is the expected change in $Y$? This is what regression answers. The answer comes in the form of a slope $\beta_1$ — the average change in $Y$ per unit change in $X$, with uncertainty attached.

Module 5.1 builds simple linear regression (one predictor, one outcome) from scratch — starting from why before any math. We derive the slope and intercept formulas by calculus. We see geometrically why least squares is a projection. We build intuition for $R^2$, for the $t$-test on $\hat\beta_1$, for confidence intervals on predictions versus on the regression line, and for every residual plot you'll ever see.

The running example. Kartify daily data: ad spend $X$ (₹ lakh) vs conversions $Y$ (count). 90 days. Scatterplot shows an upward trend. We fit $\hat Y = \hat\beta_0 + \hat\beta_1 X$ and interpret every piece of the output.
// Section 1 · Intuition

Why Regression Exists — The Problem It Solves

You have paired data: $(X_1, Y_1), (X_2, Y_2), \ldots, (X_n, Y_n)$. You want to summarize the relationship. Three questions any data analyst faces:

Question 1
Is there a relationship?
Does $Y$ tend to change when $X$ changes? Correlation answers "is there some relationship" (Module 3.6). Regression answers "what is the relationship, quantitatively?"
Question 2
How strong is it?
Given $X$, how precisely can we predict $Y$? If all points lie exactly on a line, perfect prediction. If points scatter widely, weak relationship. $R^2$ quantifies this between 0 and 1.
Question 3
What's the exact form?
Can we write $Y$ as a function of $X$? The simplest answer: $Y \approx \beta_0 + \beta_1 X$. Regression finds the best-fitting line through the data, with uncertainty quantified.
The simple linear regression model
$$Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i, \quad i = 1, 2, \ldots, n$$
$$\varepsilon_i \stackrel{\mathrm{iid}}{\sim} N(0, \sigma^2) \quad (\text{classical assumption})$$

Every piece of this model has a name and a meaning. Read it once more, then break it down:

SymbolNameWhat it representsKartify interpretation
$Y_i$Response (dependent variable)The thing you want to predict or explainConversions on day $i$
$X_i$Predictor (independent variable)The thing you control or observeAd spend on day $i$
$\beta_0$InterceptExpected $Y$ when $X = 0$Baseline conversions with zero ad spend
$\beta_1$SlopeChange in expected $Y$ per unit change in $X$Additional conversions per ₹1 lakh of ad spend
$\varepsilon_i$Error (noise)Everything that causes $Y_i$ to deviate from $\beta_0 + \beta_1 X_i$Day-to-day randomness, unobserved factors
$\sigma^2$Noise varianceTypical spread of $Y$ around the lineHow noisy the relationship is
The deep meaning of "linear model" (and what it is NOT)
"Linear" refers to being linear in the parameters $\beta_0, \beta_1$, not in $X$. The model $Y = \beta_0 + \beta_1 X^2 + \varepsilon$ is still a linear regression — the coefficients enter linearly, even though $X$ is squared. What would NOT be a linear model: $Y = \beta_0 + e^{\beta_1 X}$. Here $\beta_1$ is inside a non-linear function — that's non-linear regression, fit differently.

This matters because it means linear regression can capture many non-linear shapes (polynomials, log-terms, interactions) as long as we stay linear in the coefficients. We'll use this flexibility in Module 5.2.

// Section 2 · The Least Squares Criterion

How Do We Pick "The Best Line"? — The Least Squares Criterion

Given a scatter of $n$ points, infinitely many lines pass through or near them. We need a principled way to pick one. The idea: pick the line that minimizes total prediction error. But what do we measure?

Three candidate loss functions — and why we pick squared error

Sum of residuals
$\sum (Y_i - \hat Y_i)$
Minimize the signed error. Fails. Positive and negative errors cancel — any horizontal line through $\bar Y$ gives sum zero. Many lines are "equally good."
Sum of absolute residuals
$\sum |Y_i - \hat Y_i|$
L1 loss. Used in robust regression (quantile regression, LAD). Not differentiable at zero → harder to optimize. Gives the median relationship — robust to outliers but less analytically tractable.
Sum of squared residuals
$\sum (Y_i - \hat Y_i)^2$
L2 loss (OLS). Differentiable everywhere, closed-form solution, maximum-likelihood optimal when errors are Normal, gives the mean relationship. This is what we use.
Other losses
Huber, Tukey, $\epsilon$-insensitive
Various compromises used when data has outliers. OLS is the default; these are tools for specific robustness needs. Beyond this module's scope.
The OLS (Ordinary Least Squares) objective
$$\text{RSS}(\beta_0, \beta_1) = \sum_{i=1}^n (Y_i - \beta_0 - \beta_1 X_i)^2$$
$$(\hat\beta_0, \hat\beta_1) = \arg\min_{\beta_0, \beta_1} \text{RSS}(\beta_0, \beta_1)$$
⚡ Why squared errors = maximum likelihood under Normal noise

Here's a beautiful coincidence: under the assumption $\varepsilon_i \sim N(0, \sigma^2)$, the log-likelihood of the data is $\ell = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum (Y_i - \beta_0 - \beta_1 X_i)^2$. Maximizing $\ell$ with respect to $(\beta_0, \beta_1)$ is the same as minimizing $\sum(Y_i - \beta_0 - \beta_1 X_i)^2$ — i.e., the OLS objective. Under Normal noise, OLS is the MLE. This is not a coincidence — it's why OLS has such clean statistical properties. Module 4.1's MLE machinery applies directly.

// Section 3 · Derivation

Deriving $\hat\beta_0$ and $\hat\beta_1$ — The Full Calculus

We minimize RSS by calculus. Two parameters → two partial derivatives, set each to zero, solve the system.

Step-by-step derivation of the OLS estimators
1
Objective. $\text{RSS}(\beta_0, \beta_1) = \sum_{i=1}^n (Y_i - \beta_0 - \beta_1 X_i)^2$.
2
Partial wrt $\beta_0$. By chain rule: $\dfrac{\partial \text{RSS}}{\partial \beta_0} = \sum 2(Y_i - \beta_0 - \beta_1 X_i)(-1) = -2\sum(Y_i - \beta_0 - \beta_1 X_i)$.
3
Set to zero. $\sum(Y_i - \hat\beta_0 - \hat\beta_1 X_i) = 0$, i.e., $\sum Y_i = n\hat\beta_0 + \hat\beta_1 \sum X_i$.
4
Divide by $n$. $\bar Y = \hat\beta_0 + \hat\beta_1 \bar X$. Rearrange: $\boxed{\hat\beta_0 = \bar Y - \hat\beta_1 \bar X}$. The intercept formula. Key property: the OLS line always passes through $(\bar X, \bar Y)$.
5
Partial wrt $\beta_1$. $\dfrac{\partial \text{RSS}}{\partial \beta_1} = \sum 2(Y_i - \beta_0 - \beta_1 X_i)(-X_i) = -2\sum X_i(Y_i - \beta_0 - \beta_1 X_i)$.
6
Set to zero. $\sum X_i Y_i = \hat\beta_0 \sum X_i + \hat\beta_1 \sum X_i^2$.
7
Substitute $\hat\beta_0 = \bar Y - \hat\beta_1 \bar X$. $\sum X_i Y_i = (\bar Y - \hat\beta_1 \bar X) \sum X_i + \hat\beta_1 \sum X_i^2 = n\bar X\bar Y - \hat\beta_1 n\bar X^2 + \hat\beta_1 \sum X_i^2$.
8
Collect $\hat\beta_1$ terms. $\sum X_i Y_i - n\bar X \bar Y = \hat\beta_1 \left(\sum X_i^2 - n\bar X^2\right)$.
9
Recognize the pieces. $\sum X_i Y_i - n\bar X \bar Y = \sum(X_i - \bar X)(Y_i - \bar Y)$ (algebraic identity). Similarly $\sum X_i^2 - n\bar X^2 = \sum(X_i - \bar X)^2$.
10
The slope formula. $\boxed{\hat\beta_1 = \dfrac{\sum(X_i - \bar X)(Y_i - \bar Y)}{\sum(X_i - \bar X)^2} = \dfrac{\widehat{\mathrm{Cov}}(X,Y)}{\widehat{\mathrm{Var}}(X)}}$. $\blacksquare$
Summary: OLS closed-form solutions
$$\hat\beta_1 = \frac{\widehat{\mathrm{Cov}}(X, Y)}{\widehat{\mathrm{Var}}(X)} = \frac{\sum(X_i - \bar X)(Y_i - \bar Y)}{\sum(X_i - \bar X)^2}, \qquad \hat\beta_0 = \bar Y - \hat\beta_1 \bar X$$
What the slope formula actually says
The slope is covariance divided by variance of $X$. This is profound:
  • If $\mathrm{Cov}(X, Y) = 0$ → $\hat\beta_1 = 0$ → no linear relationship.
  • If $\mathrm{Cov}(X, Y) > 0$ → positive slope; $X$ and $Y$ move together.
  • Large $\mathrm{Var}(X)$ (spread out predictors) → smaller slope for the same covariance. This is why predictors with little variation give small coefficients.
  • The relationship $\hat\beta_1 = r_{XY} \cdot s_Y / s_X$ where $r_{XY}$ is the Pearson correlation — slope and correlation are linked but not identical.

// Section 4 · Geometric View

The Geometry of Least Squares — Regression as Projection

The algebra gives the formulas. The geometry explains why they work. Think of $\mathbf Y = (Y_1, \ldots, Y_n)^T$ as a single point (a vector) in $n$-dimensional space. Then:

The data vector
$\mathbf Y \in \mathbb R^n$
All $n$ observed responses. One point in $n$-space.
The design matrix
$\mathbf X = [\mathbf 1, \mathbf x]$
An $n \times 2$ matrix: column of 1s (for intercept), column of $X_i$ values. Columns span a 2D subspace (plane) of $\mathbb R^n$.
The fitted vector
$\hat{\mathbf Y} = \mathbf X \hat{\boldsymbol\beta}$
Lives in the 2D plane spanned by the design matrix columns. It's the point in that plane closest to $\mathbf Y$.
The residual vector
$\mathbf e = \mathbf Y - \hat{\mathbf Y}$
The "error" vector — what $\mathbf Y$ is not explained by the plane. Perpendicular to the plane. That's what OLS does.
Matrix form of the OLS solution (preview of 5.2)
$$\hat{\boldsymbol\beta} = (\mathbf X^T \mathbf X)^{-1} \mathbf X^T \mathbf Y$$
Regression = orthogonal projection
Geometrically, $\hat{\mathbf Y}$ is the orthogonal projection of $\mathbf Y$ onto the subspace spanned by the columns of $\mathbf X$. The residual $\mathbf e$ is orthogonal to that subspace — which means $\mathbf X^T \mathbf e = \mathbf 0$. That's a key identity: the residuals are orthogonal to every predictor (and to the column of 1s). Translation:
  • $\sum e_i = 0$ (residuals orthogonal to the 1-vector → they sum to zero)
  • $\sum X_i e_i = 0$ (residuals orthogonal to $X$ → uncorrelated with the predictor)
These aren't coincidences — they're geometric consequences of least squares. Any OLS fit satisfies them exactly.

// Section 5 · Goodness of Fit

$R^2$ — What "Variance Explained" Actually Means

Once we have the fitted line, we want to quantify how good the fit is. $R^2$ is the classical answer. Its formula is simple, but what it means takes derivation.

The variance decomposition — SST = SSR + SSE
$$\underbrace{\sum(Y_i - \bar Y)^2}_{\text{SST — total}} = \underbrace{\sum(\hat Y_i - \bar Y)^2}_{\text{SSR — regression}} + \underbrace{\sum(Y_i - \hat Y_i)^2}_{\text{SSE — residual (error)}}$$
Proving the SST = SSR + SSE decomposition
1
Write $Y_i - \bar Y = (Y_i - \hat Y_i) + (\hat Y_i - \bar Y)$. Add and subtract $\hat Y_i$.
2
Square both sides and sum: $\sum(Y_i - \bar Y)^2 = \sum(Y_i - \hat Y_i)^2 + 2\sum(Y_i - \hat Y_i)(\hat Y_i - \bar Y) + \sum(\hat Y_i - \bar Y)^2$.
3
The cross-product term: $\sum(Y_i - \hat Y_i)(\hat Y_i - \bar Y) = \sum e_i (\hat Y_i - \bar Y)$. Since $\hat Y_i = \hat\beta_0 + \hat\beta_1 X_i$, this becomes $\hat\beta_1 \sum e_i X_i + (\hat\beta_0 - \bar Y)\sum e_i$.
4
By the geometric identities from Section 4: $\sum e_i = 0$ and $\sum e_i X_i = 0$. So the cross-product is zero.
5
Therefore SST = SSE + SSR. $\blacksquare$. This decomposition is why $R^2$ has a "variance-explained" interpretation.
$R^2$ — coefficient of determination
$$R^2 = \frac{\text{SSR}}{\text{SST}} = 1 - \frac{\text{SSE}}{\text{SST}}$$
$R^2 = 0$
No variance explained
The regression line is flat — $\hat\beta_1 = 0$. Predictions equal $\bar Y$ for everyone. Knowing $X$ tells you nothing new about $Y$.
$R^2 = 1$
Perfect fit
All points lie exactly on the fitted line. SSE = 0. Reality check: outside of noise-free physical laws, this basically never happens.
$R^2 = 0.7$
$X$ explains 70% of variance in $Y$
Moderate-strong fit. 30% of $Y$'s variability comes from factors not in the model. Typical for "good" real-world regressions in noisy domains.
Simple case
$R^2 = r_{XY}^2$
For simple regression (one $X$), $R^2$ equals the squared Pearson correlation between $X$ and $Y$. This is why correlation and regression are "two views of the same thing" in the univariate case.
Kartify · computing $R^2$ from the 5-day example
From before. $\hat Y = -3.6 + 5.8 X$. $\bar Y = 66$.
Fitted values. $\hat Y_i$ for $X_i = 8, 10, 12, 14, 16$: $42.8, 54.4, 66.0, 77.6, 89.2$.
SST. $\sum(Y_i - 66)^2 = (-24)^2 + (-11)^2 + 2^2 + 9^2 + 24^2 = 576 + 121 + 4 + 81 + 576 = 1358$.
SSR. $\sum(\hat Y_i - 66)^2 = (-23.2)^2 + (-11.6)^2 + 0 + (11.6)^2 + (23.2)^2 = 538.24 + 134.56 + 0 + 134.56 + 538.24 = 1345.6$.
SSE. SST − SSR = $1358 - 1345.6 = 12.4$. Cross-check: residuals are $-0.8, 0.6, 2.0, -2.6, 0.8$; sum of squares = $0.64 + 0.36 + 4 + 6.76 + 0.64 = 12.4$ ✓.
$R^2$. $R^2 = 1345.6 / 1358 = 0.9909$.
Interpretation. Ad spend explains 99.1% of the variance in daily conversions — an unusually high $R^2$ because we hand-picked a tidy example. Real Kartify 90-day regression would show $R^2 \approx 0.6$–$0.75$ — still strong, but with substantial unexplained day-to-day noise.
⚠ Three things $R^2$ does NOT tell you

1. Whether the model is correct. A linear fit to non-linear data can give high $R^2$ while fitting poorly in the tails. Always check residual plots.
2. Whether predictions are accurate for new data. High $R^2$ on training data can coexist with terrible test-set performance (overfitting). Cross-validation (Module 5.5) is the fix.
3. Whether $X$ causes $Y$. $R^2$ measures association, not causation. A high $R^2$ between ice cream sales and drowning rates in summer doesn't mean ice cream causes drowning — both are driven by temperature.

// Section 6 · Inference

Inference for the Coefficients — Is the Slope Real?

$\hat\beta_1$ is an estimate. Like every estimate in Track 4, it has a sampling distribution, a standard error, a confidence interval, and a hypothesis test. The test $H_0: \beta_1 = 0$ is the most important: does $X$ actually predict $Y$?

Sampling distribution of $\hat\beta_1$ under classical assumptions
$$\hat\beta_1 \sim N\!\left(\beta_1, \; \frac{\sigma^2}{\sum (X_i - \bar X)^2}\right)$$
$$\mathrm{SE}(\hat\beta_1) = \frac{\sigma}{\sqrt{\sum(X_i - \bar X)^2}}, \quad \hat\sigma^2 = \frac{\text{SSE}}{n - 2}$$
Why $\hat\beta_1$ has this distribution
1
From the slope formula: $\hat\beta_1 = \sum(X_i - \bar X)(Y_i - \bar Y) / \sum(X_i - \bar X)^2$.
2
Substitute $Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i$ and simplify: $\hat\beta_1 = \beta_1 + \sum w_i \varepsilon_i$ where $w_i = (X_i - \bar X)/\sum(X_i - \bar X)^2$.
3
Under $\varepsilon_i \stackrel{\mathrm{iid}}{\sim} N(0, \sigma^2)$: $\hat\beta_1$ is $\beta_1$ plus a linear combination of independent Normals — which is itself Normal.
4
$E[\hat\beta_1] = \beta_1$ (unbiased). $\mathrm{Var}(\hat\beta_1) = \sigma^2 \sum w_i^2 = \sigma^2 / \sum(X_i - \bar X)^2$.
5
In practice $\sigma$ is unknown; we estimate it by $\hat\sigma = \sqrt{\text{SSE}/(n-2)}$. The $n - 2$ comes from estimating two parameters ($\beta_0, \beta_1$). This makes the statistic follow $t_{n-2}$:
6
$\boxed{\dfrac{\hat\beta_1 - \beta_1}{\hat{\mathrm{SE}}(\hat\beta_1)} \sim t_{n-2}}$
$t$-test and confidence interval for $\beta_1$
$$t = \frac{\hat\beta_1}{\hat{\mathrm{SE}}(\hat\beta_1)}, \quad \text{reject } H_0: \beta_1 = 0 \text{ if } |t| > t_{n-2, \alpha/2}$$
$$\text{CI}_{1-\alpha}(\beta_1) = \hat\beta_1 \pm t_{n-2, \alpha/2} \cdot \hat{\mathrm{SE}}(\hat\beta_1)$$
Kartify · is the slope significant? (5-day example)
From before. $\hat\beta_1 = 5.8$, SSE = 12.4, $n = 5$.
Residual variance. $\hat\sigma^2 = 12.4 / (5 - 2) = 4.133$; $\hat\sigma = 2.033$.
$\sum(X_i - \bar X)^2 = 40$ (from earlier).
SE. $\hat{\mathrm{SE}}(\hat\beta_1) = 2.033 / \sqrt{40} = 0.3215$.
$t$-statistic. $t = 5.8 / 0.3215 = 18.04$. Against $t_3$ distribution.
$p$-value (two-sided). $p = 2 \cdot P(T_3 > 18.04) \approx 3.7 \cdot 10^{-4}$. Reject $H_0$ overwhelmingly.
95% CI for $\beta_1$. $t_{3, 0.025} = 3.182$. CI = $5.8 \pm 3.182 \cdot 0.3215 = 5.8 \pm 1.023 = [4.78, 6.82]$.
Interpretation. Kartify is 95% confident the true effect of ₹1 lakh additional ad spend is between 4.78 and 6.82 additional conversions. Zero is well outside the CI — the relationship is real.
⚡ The F-test — testing the whole model at once

For simple regression, the $F$-test ($H_0$: all slopes are zero) reduces to the slope's $t$-test: $F = t^2$. But in multiple regression (Module 5.2), the $F$-test becomes important in its own right — it tests "does any predictor matter?" while individual $t$-tests check each predictor. Here, with one predictor, they're equivalent: $F = 18.04^2 = 325.4$ on $(1, 3)$ df, giving the same $p = 3.7 \cdot 10^{-4}$.

// Section 7 · Prediction

Confidence vs Prediction Intervals — Two Different Questions

After fitting the model, you want to predict $Y$ at some new $X^*$. But there are two different questions you might be asking, and they have different answers:

QuestionInterval typeWhat's being estimated
"What's the average $Y$ at $X^*$?"Confidence interval for $E[Y \mid X^*]$The true regression line at $X^*$ — a parameter
"What $Y$ will this next observation be?"Prediction interval for $Y^*$A future single outcome — a random variable
CI for the mean response vs PI for a new observation
$$\text{CI: } \hat Y^* \pm t_{n-2, \alpha/2} \cdot \hat\sigma \sqrt{\frac{1}{n} + \frac{(X^* - \bar X)^2}{\sum(X_i - \bar X)^2}}$$
$$\text{PI: } \hat Y^* \pm t_{n-2, \alpha/2} \cdot \hat\sigma \sqrt{1 + \frac{1}{n} + \frac{(X^* - \bar X)^2}{\sum(X_i - \bar X)^2}}$$
The extra "1" in the PI formula
Compare the two formulas. The PI has an additional "$1$" inside the square root. That's the $\mathrm{Var}(\varepsilon) = \sigma^2$ of an individual observation — the noise a new observation would experience, on top of uncertainty in the line itself.

CI: uncertainty only about where the line is. With infinite data, CI shrinks to a point (no uncertainty).
PI: uncertainty about where the line is, PLUS the irreducible individual-observation noise. Even with infinite data, the PI has width $\approx 2 \cdot 1.96 \cdot \sigma$ (about $\pm 2$SD of individual noise).

PIs are always wider than CIs. Use CIs when asked "what's the average?". Use PIs when asked "what will happen next?"

// Section 8 · Diagnostics

Residual Plots — Every Plot Is Asking a Question

The fitted model's numerical output (slope, $R^2$, $t$-statistic) tells you how well the line fits the data. But it can't tell you if the assumptions are satisfied. For that you need residual plots. Each plot asks a specific question, and has a specific "good" look.

Residuals vs fitted
"Is the relationship actually linear?"
Good. Random scatter around zero, no pattern. Bad. Curved pattern → non-linearity. Funnel shape → heteroscedasticity. The most important diagnostic plot; look at this first.
Normal Q-Q plot
"Are the residuals Normal?"
Good. Points fall close to the diagonal line. Bad. S-shape → heavy tails. Concave/convex → skew. Extreme deviations in tails → outliers. Matters most for small $n$ inference.
Scale-location
"Is the variance constant?"
Plot $\sqrt{|e_i|}$ vs $\hat Y_i$. Good. Flat trend. Bad. Rising trend → heteroscedasticity (variance grows with $\hat Y$). Fix: log-transform $Y$, use weighted least squares.
Leverage / Cook's D
"Are any points overly influential?"
Leverage: how extreme $X_i$ is. Cook's D: combines leverage and residual. Points with Cook's D > 1 deserve investigation — they may be dragging the regression line. Module 5.2 covers this.
Four residual-plot patterns — see what good and bad look like
Switch between good (ideal fit), non-linear (curved residual pattern), heteroscedastic (funnel), outlier (one bad point)

⚠ The residuals-vs-fitted plot is your best friend

If you only look at one diagnostic, make it residuals vs fitted. Problems it catches:

  • Curved pattern: model is mis-specified — try adding $X^2$ or transforming variables.
  • Funnel shape: variance isn't constant — try log-transforming $Y$, or use WLS/robust SEs.
  • Outliers: points far from the cloud — investigate, maybe remove if mechanically wrong.
  • Time-ordered trend: if residuals show serial correlation → violations of independence (Module 5.2 Durbin-Watson).

// Section 9 · Python

Python — sklearn vs statsmodels

Two libraries, two philosophies. sklearn for prediction-focused ML pipelines — fit, predict, score. statsmodels for full statistical inference — SEs, CIs, $t$-tests, diagnostics. Use both.

python · sklearn — prediction-focused
import numpy as np
from sklearn.linear_model import LinearRegression

# Kartify: 90 days of ad spend vs conversions
np.random.seed(42)
n = 90
X = np.random.uniform(5, 20, n)             # ad spend (₹ lakh)
Y = -3.6 + 5.8 * X + np.random.normal(0, 8, n)  # conversions with noise

model = LinearRegression().fit(X.reshape(-1, 1), Y)
print(f"Slope:     {model.coef_[0]:.3f}")
print(f"Intercept: {model.intercept_:.3f}")
print(f"R²:        {model.score(X.reshape(-1, 1), Y):.3f}")

# Prediction for new ad spend
new_spend = np.array([[11]])
print(f"Predicted conversions at ₹11 lakh: {model.predict(new_spend)[0]:.1f}")

# sklearn gives you the fitted model. It does NOT give standard errors,
# t-statistics, p-values, or CIs out of the box. For inference, use statsmodels.
python · statsmodels — full inference output
import numpy as np
import statsmodels.api as sm

np.random.seed(42)
n = 90
X = np.random.uniform(5, 20, n)
Y = -3.6 + 5.8 * X + np.random.normal(0, 8, n)

# statsmodels requires explicit intercept column
X_design = sm.add_constant(X)
result = sm.OLS(Y, X_design).fit()
print(result.summary())

# Extract individual quantities

python · residual diagnostics
import numpy as np
import statsmodels.api as sm
import matplotlib.pyplot as plt
from scipy import stats

np.random.seed(42)
X = np.random.uniform(5, 20, 90)
Y = -3.6 + 5.8 * X + np.random.normal(0, 8, 90)
X_design = sm.add_constant(X)
result = sm.OLS(Y, X_design).fit()

resid = result.resid
fitted = result.fittedvalues

fig, ax = plt.subplots(2, 2, figsize=(11, 8))

# 1. Residuals vs fitted — linearity, homoscedasticity
ax[0, 0].scatter(fitted, resid, alpha=0.6)
ax[0, 0].axhline(0, color="red", ls="--")
ax[0, 0].set_title("Residuals vs Fitted")

# 2. Q-Q plot — normality
sm.qqplot(resid, line="s", ax=ax[0, 1])
ax[0, 1].set_title("Normal Q-Q")

# 3. Scale-location — heteroscedasticity
ax[1, 0].scatter(fitted, np.sqrt(np.abs(resid)), alpha=0.6)
ax[1, 0].set_title("Scale-Location")

# 4. Residual histogram — normality visual
ax[1, 1].hist(resid, bins=20, density=True, alpha=0.7)
x_range = np.linspace(resid.min(), resid.max(), 100)
ax[1, 1].plot(x_range, stats.norm.pdf(x_range, 0, resid.std()), "r--")
ax[1, 1].set_title("Residual Distribution")

plt.tight_layout()
plt.show()

# Formal normality test
print(f"Shapiro-Wilk p-value: {stats.shapiro(resid).pvalue:.4f}")

BSeveral reasons: (1) differentiable everywhere → closed-form solution via calculus. (2) Equivalent to MLE under Normal noise. (3) Gives the mean relationship. Absolute residuals (L1) give the median, aren't differentiable at zero, and don't have clean closed-form solutions.
CL1 is mathematically invalid
DOnly squared errors can be statistically analyzed
