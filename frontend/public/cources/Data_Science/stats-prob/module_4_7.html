Non-Parametric
Tests

When the Normal assumption fails — heavy tails, ordinal data, small samples, outlier-contaminated observations — rank-based non-parametric tests provide valid inference without distributional assumptions. Every parametric test has a non-parametric cousin: Mann-Whitney for two-sample, Wilcoxon signed-rank for paired, Kruskal-Wallis for multi-group, plus the universal permutation test.

⚡ Kartify — Sunday Fallback: When Assumptions Break
Sunday. Arjun reviews the week's analyses. One dataset raises a red flag: order-value comparisons between Standard and Premium tiers. The Premium tier has extreme outliers (₹500K+ orders) that make the distribution wildly right-skewed. Shapiro-Wilk rejects normality ($p < 10^{-12}$). The $t$-test on these raw values is unreliable — its assumptions are violated.

The fix is a non-parametric test. Instead of comparing raw means, rank-based tests convert all values to ranks (1st smallest, 2nd smallest, ...) and test whether one group's ranks tend to be higher. Ranks are invariant to monotone transformations (same ranks whether you measure in ₹, log-₹, or percentiles), immune to outliers, and require no distributional assumption beyond continuity.

Module 4.7 covers the five core non-parametric tools: Mann-Whitney U (two independent groups), Wilcoxon signed-rank (paired), Kruskal-Wallis (multi-group), rank correlations (Spearman/Kendall from Module 3.6, now with hypothesis tests), and the permutation test (the universal non-parametric tool that works for any test statistic).
// Section 1

When to Go Non-Parametric — Decision Rules

Use non-parametric when
Normality fails and can't be fixed
Heavy tails, strong skew, outlier-contaminated data. Log-transform first — if residuals still aren't Normal, go non-parametric. Also for ordinal data (ratings, Likert scales) where mean is not meaningful.
Use parametric when
Assumptions hold, even approximately
Parametric tests are more powerful (detect smaller effects). For $n \ge 30$ with moderate skew, CLT makes $t$-tests robust. If both give the same answer, the parametric test is preferred.
Cost of non-parametric
Lower power when parametric is valid
If data IS Normal, Mann-Whitney has 95.5% of the power of $t$-test (asymptotic relative efficiency = $3/\pi$). For heavy-tailed data, it can be more powerful than $t$.
What they test
Stochastic ordering, not means
Mann-Whitney tests $P(X > Y) = 0.5$, not $\mu_X = \mu_Y$. With equal distributions, this implies equal means, but with unequal shapes, the tests answer different questions. Be clear about the null.
// Section 2

Mann-Whitney U — Two Independent Groups, No Assumptions

Mann-Whitney U test
$$U = \sum_{i=1}^{n_1} \sum_{j=1}^{n_2} \mathbb{1}[X_i > Y_j], \quad H_0: P(X > Y) = 0.5$$

Equivalent to: rank all $N = n_1 + n_2$ observations; sum the ranks in group 1. Under $H_0$, the rank-sum follows a known null distribution (exact for small samples, Normal approximation for large).

Kartify · Standard vs Premium tier order values (heavy-tailed)
Data. Standard: 200 orders, median ₹1,200. Premium: 150 orders, median ₹3,800. Both heavily right-skewed.
Why not $t$-test. Skewness $> 4$ in both groups. Outliers ($> ₹200K$) inflate the mean and SE; $t$-test unreliable.
Mann-Whitney. $U = 22{,}450$, $p < 10^{-15}$. Premium orders are stochastically larger.
Rank-biserial correlation. $r_{rb} = 2U/(n_1 n_2) - 1 \approx 0.50$ — medium-to-large effect. "A randomly selected Premium order exceeds a Standard order 75% of the time."
// Section 3

Wilcoxon Signed-Rank — Paired Non-Parametric

Wilcoxon signed-rank test
$$W^+ = \sum_{\{i : D_i > 0\}} R_i, \quad D_i = X_{A,i} - X_{B,i}, \quad R_i = \text{rank of } |D_i|$$
Kartify · user satisfaction before vs after redesign (ordinal 1–5 scale)
Data. 80 users rated both designs. Differences $D_i$ are integers $\in \{-4, \ldots, 4\}$.
Why not paired $t$. Ordinal data — 1-5 Likert scale. Mean of ratings has debatable meaning. Wilcoxon works on ranks of absolute differences.
Result. $W^+ = 2450$, $p = 0.003$. The redesign tends to receive higher ratings.
Interpretation. Among users who changed their rating, significantly more improved than worsened. Effect size (matched-pairs rank-biserial): $r = 0.35$, moderate.
// Section 4

Kruskal-Wallis — Multi-Group Non-Parametric ANOVA

Kruskal-Wallis H test
$$H = \frac{12}{N(N+1)} \sum_{i=1}^{k} \frac{R_i^2}{n_i} - 3(N+1)$$
$$H \approx \chi^2_{k-1} \text{ under } H_0$$
Kartify · order value across 4 product categories (heavy-tailed)
Data. Electronics (500 orders), Fashion (400), Home (300), Sports (200). All right-skewed.
Kruskal-Wallis. $H = 45.3$, $df = 3$, $p < 10^{-9}$. At least one category has a different order-value distribution.
Post-hoc. Dunn's test with Bonferroni correction identifies Electronics as having significantly higher order values than Sports and Home.
Relationship to ANOVA. Kruskal-Wallis is the non-parametric version of one-way ANOVA. Uses ranks instead of raw values. If data were Normal, ANOVA would be slightly more powerful; for heavy-tailed data, Kruskal-Wallis can be more powerful.
// Section 5

Rank Correlations — Hypothesis Tests for Monotone Association

Module 3.6 introduced Spearman and Kendall as estimators. Here we add the hypothesis test: $H_0: \rho_S = 0$ (no monotonic association).

Spearman correlation test
$$T = r_S \sqrt{\frac{n - 2}{1 - r_S^2}} \sim t_{n-2} \text{ under } H_0$$
Kartify · is delivery time monotonically related to order value?
Data. 500 orders. $r_S = 0.34$, $p < 10^{-6}$.
Interpretation. Moderate positive monotonic association — higher-value orders tend to take longer (heavier items? more careful packaging?). Pearson on raw data was 0.12 (suppressed by outliers); Spearman captures the true monotone relationship.
When to use. Use Spearman/Kendall tests when you want to test for any monotonic association (not just linear), when data has outliers, or when variables are ordinal.
// Section 6

Permutation Testing — The Universal Non-Parametric Tool

All previous non-parametric tests use rank-based statistics. The permutation test is more general: it works with any test statistic. The idea: under $H_0$ (no group difference), the group labels are exchangeable. Randomly reassign labels many times, compute the test statistic each time, and see where the observed statistic falls in this permutation distribution.

Permutation test algorithm
$$p\text{-value} = \frac{\#\{T_{\pi} \ge T_{\text{obs}}\}}{B}$$
Permutation test — step by step
1
Compute observed test statistic $T_{\text{obs}}$ (difference in means, medians, ratios, anything).
2
For $b = 1, \ldots, B$: randomly permute group labels across all $N$ observations. Compute $T_{\pi}^{(b)}$.
3
$p$-value = fraction of permutation statistics $\ge T_{\text{obs}}$.
4
Under $H_0$ (labels don't matter), $T_{\text{obs}}$ is just one draw from the permutation distribution. If it's in the tail → reject $H_0$.
Why permutation tests are "exact"
No distributional assumptions. No asymptotics. The permutation distribution is the null distribution by construction. For small samples where Normal or $\chi^2$ approximations are questionable, permutation gives exact $p$-values (up to Monte Carlo error, which decreases as $B \to \infty$). The trade-off: computational cost — but with modern hardware, $B = 10{,}000$ permutations of $N = 1{,}000$ takes milliseconds.
Kartify · permutation test for median difference (no closed-form test exists)
Question. Is the median order value different between Standard and Premium tiers?
Observed. Median difference = ₹2,600.
Permutation. $B = 10{,}000$ random relabelings. Permuted median differences range from −₹800 to ₹900. Observed ₹2,600 exceeds all 10,000 permutations → $p < 0.0001$.
Power of the framework. Any statistic — trimmed mean, ratio of IQRs, Gini coefficient, custom business metric — can be tested this way. No formula derivation needed.

Python — All Non-Parametric Tests

python · Mann-Whitney, Wilcoxon, Kruskal-Wallis
import numpy as np
from scipy import stats

np.random.seed(42)

# 1. Mann-Whitney U — Standard vs Premium order values
standard = np.random.lognormal(7.1, 1.2, 200)
premium = np.random.lognormal(8.2, 1.3, 150)
U, p = stats.mannwhitneyu(premium, standard, alternative="greater")
r_rb = 2 * U / (200 * 150) - 1     # rank-biserial effect size
print(f"Mann-Whitney: U = {U:.0f}, p = {p:.2e}, r_rb = {r_rb:.3f}")

# 2. Wilcoxon signed-rank — paired satisfaction ratings
before = np.random.choice([1,2,3,4,5], size=80, p=[.05,.15,.40,.30,.10])
after = np.clip(before + np.random.choice([-1,0,0,1,1], size=80), 1, 5)
w_stat, p = stats.wilcoxon(after, before, alternative="greater")
print(f"\nWilcoxon signed-rank: W = {w_stat:.0f}, p = {p:.4f}")

# 3. Kruskal-Wallis — order values across 4 categories
elec = np.random.lognormal(7.8, 1.0, 500)
fash = np.random.lognormal(7.2, 1.1, 400)
home = np.random.lognormal(7.0, 0.9, 300)
sport = np.random.lognormal(6.8, 1.0, 200)
H, p = stats.kruskal(elec, fash, home, sport)
print(f"\nKruskal-Wallis: H = {H:.1f}, p = {p:.2e}")

# Post-hoc: Dunn's test (via scikit-posthocs)
# pip install scikit-posthocs; import scikit_posthocs as sp

python · permutation test — universal framework
import numpy as np
from scipy import stats

np.random.seed(42)
standard = np.random.lognormal(7.1, 1.2, 200)
premium = np.random.lognormal(8.2, 1.3, 150)

# Test: is the median difference real?
obs_diff = np.median(premium) - np.median(standard)
print(f"Observed median difference: {obs_diff:,.0f}")

# Permutation null distribution
combined = np.concatenate([standard, premium])
B = 10_000
perm_diffs = np.empty(B)
for b in range(B):
    np.random.shuffle(combined)
    perm_diffs[b] = np.median(combined[:150]) - np.median(combined[150:])

p_perm = (perm_diffs >= obs_diff).mean()
print(f"Permutation p-value: {p_perm:.4f} (B = {B})")

# scipy also has a built-in permutation_test (since 1.8)
result = stats.permutation_test(
    (premium, standard),
    lambda x, y, axis: np.median(x, axis=axis) - np.median(y, axis=axis),
    n_resamples=9999, alternative="greater"
)
print(f"scipy permutation_test p: {result.pvalue:.4f}")
