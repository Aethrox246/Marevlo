The summary statistics that run every model. Linearity of expectation is the quiet hero of half the proofs in probability. Conditional expectation is regression, literally. And moment-generating functions are the algebraic machine that proves distribution identities in one line.

⚡ Kartify — The Question That Needs Algebra, Not Just Simulation
Monday of week two. Priya wants to model tomorrow's total revenue. She has 8 city-level daily revenues $R_1, \ldots, R_8$ — each with its own mean and variance, some correlated (marketing campaigns hit multiple cities). She doesn't want a simulation estimate; she wants exact formulas for the total's mean, variance, and the 95% confidence band.

Two tools do this cleanly. Linearity of expectation: $E[\sum R_i] = \sum E[R_i]$ — always, no independence needed. Variance of a sum: $\mathrm{Var}(\sum R_i) = \sum \mathrm{Var}(R_i) + 2 \sum_{i < j} \mathrm{Cov}(R_i, R_j)$ — independence drops the cov terms.

This module builds the algebra of expectation and variance; introduces conditional expectation ($E[Y \mid X]$ is literally the regression function); proves the Law of Total Variance (the bias-variance decomposition's ancestor); and closes with moment-generating functions — the most powerful compact tool for analytic probability.
// Section 1

Linearity of Expectation — The Quietly Powerful Rule

Linearity — holds always, independence not required
$$E[aX + bY] = aE[X] + bE[Y], \qquad E\!\left[\sum_{i=1}^n X_i\right] = \sum_{i=1}^n E[X_i]$$
◆ Why this is so useful — no independence needed

Linearity is unique: it holds for any random variables, whether independent or not, discrete or continuous, light-tailed or heavy-tailed. Most other identities (variance of sum, MGF of sum) need independence. Linearity is the one you can always reach for.

Proof of linearity — discrete case
1
$E[aX + bY] = \sum_{x, y} (ax + by) p_{X,Y}(x, y)$ — definition with joint PMF.
2
Split the sum: $= a \sum_{x, y} x \, p_{X,Y}(x, y) + b \sum_{x, y} y \, p_{X,Y}(x, y)$.
3
First sum: $\sum_x x \left(\sum_y p_{X,Y}(x, y)\right) = \sum_x x \, p_X(x) = E[X]$. Similarly for the second.
4
$\therefore E[aX + bY] = aE[X] + bE[Y]$. $\blacksquare$ At no step did we need independence.

Kartify — the elegant Binomial mean proof

Proving $E[\text{Binomial}(n, p)] = np$ in one line
Setup. $X \sim$ Binomial$(n, p)$. Write $X = X_1 + X_2 + \ldots + X_n$, where each $X_i \sim$ Bernoulli$(p)$ — the trial $i$ indicator.
Per-trial mean. $E[X_i] = p$ (direct from Bernoulli PMF).
By linearity. $E[X] = E[\sum X_i] = \sum E[X_i] = np$. Done.
Compare to the PMF-summation proof (computing $E[X] = \sum_{k} k \binom{n}{k} p^k (1-p)^{n-k}$ — needs algebraic manipulation and derivatives). Linearity turns it into a one-liner. This is the pattern: decompose into indicators, sum means.
Kartify · expected revenue across 8 cities (even with correlations)
Setup. $R = R_1 + \ldots + R_8$ where $E[R_i]$ ranges ₹4–12 lakh/day by city.
By linearity. $E[R] = \sum E[R_i]$ — even if $R_i$ are correlated. Marketing spillovers between Mumbai and Delhi don't change the mean.
Sum the city means. Suppose $E[R] = 10 + 8 + 7 + 5 + 4 + 4.5 + 3.5 + 3 = 45$ (₹ lakh). Total expected daily revenue.
Key insight. The mean is easy — linearity hides correlations. The variance is where correlations bite. That's the next section.

Variance Algebra — The Rules of Spread

Variance transformations
$$\mathrm{Var}(aX + b) = a^2\, \mathrm{Var}(X), \qquad \mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) + 2\,\mathrm{Cov}(X, Y)$$
Proof of $\mathrm{Var}(aX + b) = a^2 \mathrm{Var}(X)$
1
$\mathrm{Var}(aX + b) = E[((aX + b) - E[aX + b])^2]$ — definition.
2
$= E[(aX + b - aE[X] - b)^2] = E[(aX - a E[X])^2] = E[a^2 (X - E[X])^2]$ — the $b$ cancels.
3
$= a^2 E[(X - E[X])^2] = a^2 \mathrm{Var}(X)$. $\blacksquare$ Constants shift but don't spread. Scaling by $a$ scales variance by $a^2$.
Proof of variance of a sum
1
$\mathrm{Var}(X + Y) = E[(X + Y - E[X] - E[Y])^2]$.
2
Let $U = X - E[X]$, $V = Y - E[Y]$. Then $\mathrm{Var}(X + Y) = E[(U + V)^2] = E[U^2] + 2E[UV] + E[V^2]$.
3
$E[U^2] = \mathrm{Var}(X)$, $E[V^2] = \mathrm{Var}(Y)$, $E[UV] = \mathrm{Cov}(X, Y)$.
4
$\therefore \mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) + 2\mathrm{Cov}(X, Y)$. $\blacksquare$
⚡ Independence special case

If $X \perp Y$: $\mathrm{Cov}(X, Y) = 0$, so $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$. Variances add for independent sums. This is the formula used in ~80% of introductory stats courses — but only valid under independence. More generally:

$\mathrm{Var}\!\left(\sum_{i=1}^n X_i\right) = \sum_{i=1}^n \mathrm{Var}(X_i) + 2 \sum_{i < j} \mathrm{Cov}(X_i, X_j)$
Kartify · the Binomial variance proof
Setup. $X = \sum X_i$ for i.i.d. Bernoulli$(p)$ indicators. Independent by definition of Binomial.
Per-trial variance. $\mathrm{Var}(X_i) = p(1-p)$.
By independence. $\mathrm{Var}(X) = \sum \mathrm{Var}(X_i) = np(1-p)$.
Same trick as the mean proof. Indicator decomposition + sum rule. For the Delhi case: $\mathrm{Var}(X) = 3000 \cdot 0.08 \cdot 0.92 = 220.8$, $\sigma = 14.86$, so the observed 420 is $12.1\sigma$ from the mean — the "12-sigma event" number we kept quoting is exactly $np(1-p)$ in action.
Kartify · variance of total daily revenue
Setup. $R = \sum R_i$, 8 cities, with city-level variances and some correlations from shared marketing campaigns.
Individual variances (illustrative): $\mathrm{Var}(R_i)$ varies ₹(0.3 lakh)² to ₹(1.2 lakh)² — sum to 4.0 (lakh)².
Pairwise covariances. For a campaign hitting Mumbai and Delhi: $\mathrm{Cov}(R_{\text{MU}}, R_{\text{DEL}}) = 0.4$ (lakh)². Sum of $2 \sum_{i < j} \mathrm{Cov}(R_i, R_j) \approx 2.0$ (lakh)².
Total. $\mathrm{Var}(R) = 4.0 + 2.0 = 6.0$ (lakh)². $\sigma \approx 2.45$ lakh.
Lesson. If we naively summed variances only (treating cities as independent), we'd estimate $\sigma = 2.0$ — understating risk by 20%. Correlations inflate variance. This is why portfolio risk models care about covariance.

Conditional Expectation — Regression, Formalized

$E[Y \mid X = x]$ is the mean of $Y$'s distribution given we know $X = x$. As $x$ varies, $E[Y \mid X]$ becomes a function of $X$ — itself a random variable.

Conditional expectation
$$E[Y \mid X = x] = \sum_y y \, p_{Y \mid X}(y \mid x) \quad (\text{discrete}), \qquad E[Y \mid X = x] = \int y \, f_{Y \mid X}(y \mid x)\, dy \quad (\text{continuous})$$
The ML translation — conditional expectation IS regression
When you "fit a regression of $Y$ on $X$," you're estimating the function $x \mapsto E[Y \mid X = x]$. Linear regression assumes this function is $\beta_0 + \beta_1 x$; neural networks don't restrict its form. Regression is function estimation of conditional expectation. Mean-squared-error loss is the right loss function because it is minimized exactly when the model equals $E[Y \mid X]$ — a fact proved by variance decomposition (Section 5).

Kartify — conditional expected revenue given city

$E[R \mid \text{city}]$ — city-level expected revenue
Per-city expected values. $E[R \mid \text{Mumbai}] = 10$, $E[R \mid \text{Delhi}] = 8$, $E[R \mid \text{Bengaluru}] = 7$, ... (₹ lakh/day)
As a function. "city" is the predictor; the conditional expectation is a piecewise-constant function over cities — the simplest possible regression model.
Every day's revenue is drawn from the conditional distribution given its city. The city-conditional mean is the regression prediction; the residual variance (difference from the per-city mean) is what a more complex model could try to explain with additional features.
// Section 4

Law of Iterated Expectation (LIE) — Averaging the Average

Law of Total / Iterated Expectation
$$E[Y] = E_X\!\big[E[Y \mid X]\big]$$
Proof — discrete
1
$E_X[E[Y \mid X]] = \sum_x E[Y \mid X=x] \, p_X(x) = \sum_x \left(\sum_y y \, p_{Y \mid X}(y \mid x)\right) p_X(x)$.
2
Multiply in: $p_{Y|X}(y|x) p_X(x) = p_{X,Y}(x, y)$ — the definition of joint PMF from conditional.
3
$= \sum_{x, y} y \, p_{X,Y}(x, y) = \sum_y y \left(\sum_x p_{X,Y}(x, y)\right) = \sum_y y \, p_Y(y) = E[Y]$. $\blacksquare$
Kartify · total expected revenue via LIE
Setup. Let $R$ = daily revenue, $C$ = city of random order. $E[R \mid C] = \mu_C$ — city-specific mean.
Apply LIE. $E[R] = \sum_c \mu_c \cdot p_C(c)$ — weighted average of city means by order share.
This is the Law of Total Probability applied to expectation. Every time you compute a weighted average, you're using LIE. Every forest classifier averaging tree predictions: LIE. Every bagging estimator: LIE.

Law of Total Variance — The Bias-Variance Decomposition's Ancestor

Law of Total Variance
$$\mathrm{Var}(Y) = \underbrace{E_X\!\big[\mathrm{Var}(Y \mid X)\big]}_{\text{within-group variance}} + \underbrace{\mathrm{Var}_X\!\big[E[Y \mid X]\big]}_{\text{between-group variance}}$$
The ML insight — this is bias-variance, re-labeled
In ML parlance with $X$ = features, $Y$ = label:
  • $E_X[\mathrm{Var}(Y \mid X)]$ = irreducible error (noise) — variation in $Y$ even if $X$ is fully known.
  • $\mathrm{Var}_X[E[Y \mid X]]$ = explained variance — how much the feature reduces uncertainty about $Y$.
$R^2$ in regression is exactly $\mathrm{Var}_X[E[Y \mid X]] / \mathrm{Var}(Y)$ — the fraction of total variance explained by the conditional mean. This one identity powers half of statistical learning theory.
Kartify · decomposing revenue variance by city
Within-city variance (avg). $E_C[\mathrm{Var}(R \mid C)] \approx 0.5$ (lakh)² — daily fluctuation within a single city.
Between-city variance. $\mathrm{Var}_C[E[R \mid C]]$ — how much the city means vary; ~0.8 (lakh)².
Total. $\mathrm{Var}(R) \approx 0.5 + 0.8 = 1.3$ (lakh)².
R² from using city as a predictor. $0.8 / 1.3 \approx 0.615$ — city alone explains ~62% of total revenue variance. Any model using only city is capped at 62% explanation. Features beyond city must tap into the 38% within-city residual.

Moment-Generating Functions — The Algebraic Machine

Moment-Generating Function (MGF)
$$M_X(t) = E[e^{tX}] = \sum_k e^{tk} p_X(k) \; (\text{discrete}) \;\;\text{or}\;\; \int e^{tx} f_X(x)\, dx \; (\text{continuous})$$
Why "moment-generating" — the Taylor expansion
$$M_X(t) = 1 + tE[X] + \frac{t^2}{2!} E[X^2] + \frac{t^3}{3!} E[X^3] + \ldots \;\;\Rightarrow\;\; E[X^k] = \left.\frac{d^k}{dt^k} M_X(t)\right|_{t=0}$$
Bernoulli
$M(t) = 1 - p + pe^t$
Two terms: $e^{t \cdot 0}(1-p) + e^{t \cdot 1}p$. Derivative at 0: $pe^t|_{t=0} = p = E[X]$. ✓
Binomial
$M(t) = (1 - p + pe^t)^n$
Product of $n$ Bernoulli MGFs — because MGF of independent sum is product of MGFs. Proof in one line.
Poisson
$M(t) = e^{\lambda(e^t - 1)}$
Adding independent Poissons: $M_X M_Y = e^{\lambda_1(e^t - 1)} \cdot e^{\lambda_2(e^t - 1)} = e^{(\lambda_1 + \lambda_2)(e^t - 1)}$ → Poisson($\lambda_1 + \lambda_2$). Poisson additivity proved.
Normal
$M(t) = e^{\mu t + \sigma^2 t^2 / 2}$
Linear combination of independent normals: multiply MGFs, exponents add → $N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$. The Normal family's closure under sums, in one line.
MGF key property — independent sums multiply
$$X \perp Y \;\Rightarrow\; M_{X+Y}(t) = M_X(t) \cdot M_Y(t)$$
Proof — one line
1
$M_{X+Y}(t) = E[e^{t(X+Y)}] = E[e^{tX} e^{tY}]$. For independent $X, Y$: $E[e^{tX} e^{tY}] = E[e^{tX}] E[e^{tY}] = M_X(t) M_Y(t)$. $\blacksquare$
◆ Why MGFs matter — uniqueness and identification

Uniqueness theorem: if two distributions have the same MGF (and it exists in some neighborhood of 0), they are the same distribution. So proving an MGF matches a named form identifies the distribution. Example: sum of two independent Normals has MGF of Normal form → sum is Normal. No need to convolve densities directly. MGFs turn probability into algebra.

Python — Expectation, Variance, MGFs in Code

python · variance decomposition — Kartify revenue by city
import numpy as np
import pandas as pd

np.random.seed(42)

# Simulate 10,000 Kartify daily observations across 8 cities
cities   = ["Mumbai","Delhi","Bengaluru","Chennai","Kolkata","Hyderabad","Pune","Ahmedabad"]
shares   = [0.22,0.18,0.16,0.11,0.09,0.10,0.08,0.06]
mu_city  = [10,  8,   7,   5,   4,   4.5, 3.5, 3]          # ₹ lakh/day mean by city
sig_city = [0.8, 0.9, 0.7, 0.5, 0.5, 0.6, 0.4, 0.4]

N = 10_000
city_idx = np.random.choice(len(cities), size=N, p=shares)
R = np.array([np.random.normal(mu_city[c], sig_city[c]) for c in city_idx])

df = pd.DataFrame({"city": [cities[c] for c in city_idx], "R": R})

# Total variance
total_var = df["R"].var()
print(f"Total Var(R)              = {total_var:.3f}")

# Within-city variance — E_X[Var(Y | X)]
within = df.groupby("city")["R"].var().mean()    # simple unweighted; can be weighted
print(f"Within-city Var avg       = {within:.3f}")

# Between-city variance — Var_X[E[Y | X]]
between = df.groupby("city")["R"].mean().var()
print(f"Between-city Var of means = {between:.3f}")

print(f"Within + Between = {within + between:.3f}  (~= total, law of total variance)")

# R² from using city alone as a predictor
r2 = between / total_var
print(f"R² (city only) = {r2:.3f}")
python · MGF-based proofs — Binomial mean, Poisson additivity
import sympy as sp

# Binomial MGF: M(t) = (1 - p + p*e^t)^n
t, p, n = sp.symbols("t p n", positive=True)
M_binom = (1 - p + p * sp.exp(t))**n

# Mean = M'(0)
E_X = sp.diff(M_binom, t).subs(t, 0).simplify()
print(f"E[Binomial(n,p)] = {E_X}")          # n*p

# E[X²] = M''(0), then Var = E[X²] − (E[X])²
E_X2 = sp.diff(M_binom, t, 2).subs(t, 0).simplify()
Var_X = sp.simplify(E_X2 - E_X**2)
print(f"Var[Binomial(n,p)] = {Var_X}")        # n*p*(1-p)

# Poisson additivity — MGF product
lam1, lam2 = sp.symbols("lambda_1 lambda_2", positive=True)
M1 = sp.exp(lam1 * (sp.exp(t) - 1))
M2 = sp.exp(lam2 * (sp.exp(t) - 1))
M_sum = sp.simplify(M1 * M2)
print(f"M_(X+Y)(t) = {M_sum}")
# = e^((lambda_1 + lambda_2)(e^t - 1)) — MGF of Poisson(lambda_1 + lambda_2). QED.
