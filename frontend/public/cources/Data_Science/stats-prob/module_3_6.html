⚡ Kartify — The Feature Matrix Arjun Couldn't Untangle
Monday, week 4. Arjun is building a return-prediction model. His raw feature matrix has 40 columns: delivery time, price, discount, city, category, weight, session duration, time-of-day, payment method, device type, prior-order-count, ... His training runs but the model performance is mediocre. A colleague suggests: "run PCA on the features."

PCA is just the eigendecomposition of the sample covariance matrix $\hat\Sigma$. That sample covariance matrix is an estimator of the population covariance. Understanding how well $\hat\Sigma$ represents the true $\Sigma$ — when to trust it, when it's shaky, what the eigenvalue structure tells you — is the difference between applying PCA blindly and using it intelligently.

Module 3.6 builds the bridge from Module 2.6's algebraic joint distributions to their estimators from data. Empirical joint PMFs, empirical covariance matrices, Pearson vs Spearman correlation (and when to use which), independence tests, and the PCA preview. This is the module that makes the difference between "I know what Cov(X, Y) means" and "I can read a covariance matrix for signal vs noise."

Empirical Joint Distribution — From Data to Joint

Empirical joint CDF / PMF
$$\hat F_{X,Y}(x, y) = \frac{1}{n} \sum_{i=1}^n \mathbb{1}[X_i \le x, Y_i \le y]$$

Kartify — (late, returned) as an empirical joint PMF

Building the joint from raw data
Raw data. 10,000 Kartify orders. Each row: (late$_i$, returned$_i$) — both binary.
Count the four combinations. Say the counts are: (1,1) = 350, (1,0) = 1,150, (0,1) = 450, (0,0) = 8,050.
Empirical joint PMF. Divide each by 10,000: $\hat p(1,1) = 0.035$, $\hat p(1,0) = 0.115$, $\hat p(0,1) = 0.045$, $\hat p(0,0) = 0.805$.
Sum check. $0.035 + 0.115 + 0.045 + 0.805 = 1.000$. ✓
This is the same joint PMF we used in Module 2.6. The theoretical object was this empirical estimate's target — and the data gave us 2-digit agreement with the theoretical model. In real work, you always start here: raw data → empirical joint, then decide if a parametric model fits.
Dimension scaling — why joint PMFs break down in high dimensions
For $d$ binary features, the joint PMF has $2^d$ cells. With $d = 40$, that's $10^{12}$ cells — you'd need astronomical data to fill even a fraction of them. This is the curse of dimensionality. In practice, we estimate marginals and low-order joints (pairs, triples) plus assume independence or factor structure for the rest. Graphical models, Naive Bayes, copulas — all are ways of estimating joint structure with fewer-than-exponential parameters.

Sample Covariance & Correlation — Estimators of Linear Dependence

Sample covariance and Pearson correlation
$$\widehat{\mathrm{Cov}}(X, Y) = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar X)(Y_i - \bar Y)$$
$$\hat\rho_{X,Y} = \frac{\widehat{\mathrm{Cov}}(X, Y)}{s_X s_Y}, \qquad \hat\rho \in [-1, 1]$$
Kartify · sample correlation between Late and Returned
From the 10,000-order data (with two Bernoulli features):
Means. $\bar X_{\text{late}} = 0.150$, $\bar X_{\text{ret}} = 0.080$.
Sample variances (Bernoulli). $s^2_{\text{late}} \approx 0.1275$, $s^2_{\text{ret}} \approx 0.0736$. Stds: 0.357, 0.271.
Covariance. $\widehat{\mathrm{Cov}} \approx 0.023$ (via the joint PMF calculation from Module 2.6).
Pearson correlation. $\hat\rho = 0.023 / (0.357 \cdot 0.271) \approx 0.237$.
Interpretation. Moderate positive linear association. Late and returned co-vary, but the relationship is not deterministic. Useful as a feature; not a guaranteed predictor. Matches the 2.92× ratio from independence-check.

Pearson vs Spearman — Which Correlation for Which Data?

Pearson $\rho$
Linear association, requires finite variance
Classical correlation. Detects linear relationships. Sensitive to outliers — one extreme point can dominate. Requires $\mathrm{Var}(X), \mathrm{Var}(Y)$ finite (fails for very heavy-tailed distributions).
Spearman $\rho_S$
Monotonic association, rank-based
Pearson correlation computed on ranks of data, not raw values. Detects any monotonic relationship, including non-linear ones. Robust to outliers. Invariant under monotone transformations.
Kendall $\tau$
Fraction of concordant pairs
Alternative rank-based measure — counts pairs where relative order of $X$ agrees with relative order of $Y$. More robust than Spearman under heavy contamination. Widely used in copula modeling.
Mutual information $I(X; Y)$
Any dependence, non-linear included
Information-theoretic measure of dependence. Zero iff $X \perp Y$. Nonzero for any dependence, linear or not. Harder to estimate accurately from data than correlations.
Kartify · Pearson vs Spearman for Order-Value vs Delivery-Time
Data. 10,000 orders. Order value $X$ (Log-normal, very heavy-tailed), delivery time $Y$ (Exp-like).
Pearson $\hat\rho$. Computed: $\approx 0.12$. But one ₹200,000 order with a 60h delivery dominated the covariance — sensitive to the outlier.
Spearman $\hat\rho_S$. On ranks: $\approx 0.34$. The monotonic relationship is real and stronger than Pearson suggests.
Recommendation. For heavy-tailed or potentially non-linear data, report both. If Pearson $\ll$ Spearman, the raw-scale correlation is being masked by outliers or non-linearity. For Kartify planning, Spearman = 0.34 is the honest figure.

Independence Testing — Are Two Variables Actually Independent?

We know: $X \perp Y \Rightarrow \mathrm{Cov}(X, Y) = 0$. The converse fails in general. To test independence from data, we need tests that detect any dependence, not just linear.

TestNullPower againstBest for
$\chi^2$ test of independence$X \perp Y$Any marginal-product violationBoth categorical; count data
Pearson correlation $t$-test$\rho = 0$Linear dependence onlyBoth continuous, approximately Normal
Spearman correlation test$\rho_S = 0$Any monotonic dependenceContinuous, non-Normal or with outliers
Distance correlation$X \perp Y$Any dependence — linear, non-linear, high-DModern go-to for general independence
Mutual information$I(X;Y) = 0$Any dependenceWhen you need an information-theoretic measure
Kartify · chi-squared test for (Late, Returned)
Observed counts. (1,1) = 350; (1,0) = 1,150; (0,1) = 450; (0,0) = 8,050.
Expected under independence. Use marginal products times $n$: $p_X(1) p_Y(1) \cdot 10000 = 0.15 \cdot 0.08 \cdot 10000 = 120$. Similarly 1380, 1380, 7120.
$\chi^2$ statistic. $\sum (\text{obs} - \text{exp})^2 / \text{exp} = (350-120)^2/120 + (1150-1380)^2/1380 + (450-1380)^2/1380 + (8050-7120)^2/7120 \approx 441 + 38 + 627 + 121 = 1227$.
$p$-value. Degrees of freedom = $(2-1)(2-1) = 1$. $P(\chi^2_1 > 1227) < 10^{-200}$. Reject independence overwhelmingly.
Conclusion. The $\chi^2$ test quantifies what the correlation suggested: (late, returned) are strongly non-independent. This is a powerful test for any categorical joint structure.

The Sample Covariance Matrix — Estimating $\Sigma$ from Data

Sample covariance matrix
$$\hat\Sigma = \frac{1}{n-1} \sum_{i=1}^n (\mathbf{X}_i - \bar{\mathbf{X}})(\mathbf{X}_i - \bar{\mathbf{X}})^T$$

For a $d$-dimensional data matrix $\mathbf{X} \in \mathbb{R}^{n \times d}$: $\hat\Sigma$ is $d \times d$ with:

  • $\hat\Sigma_{ii} = s^2_i$ — sample variance of feature $i$
  • $\hat\Sigma_{ij} = \widehat{\mathrm{Cov}}(X_i, X_j)$ — sample covariance
  • Symmetric and positive-semi-definite (always)
  • Invertible iff $n > d$ and no linearly-dependent columns
⚠ High-dimensional instability — the classic pitfall

When $d$ is large relative to $n$, $\hat\Sigma$ has high variance, often near-singular. Example: Kartify's 40-feature matrix on 100 orders — $d/n = 0.4$ — the sample covariance matrix is wildly unstable. Fixes: shrinkage ($\hat\Sigma_{\text{shrunk}} = (1 - \alpha)\hat\Sigma + \alpha \cdot \mathrm{diag}(\hat\Sigma)$), regularization ($\hat\Sigma + \lambda I$), or factor models (approximate with low-rank + diagonal). Getting covariance estimation right in high dimensions is a research field of its own.

PCA Preview — Eigendecomposition of $\hat\Sigma$

Principal Component Analysis is the most famous application of the sample covariance matrix. Mechanically, PCA is just eigendecomposition:

PCA via eigendecomposition of $\hat\Sigma$
$$\hat\Sigma = U \Lambda U^T, \qquad \Lambda = \mathrm{diag}(\lambda_1, \lambda_2, \ldots, \lambda_d), \quad \lambda_1 \ge \lambda_2 \ge \ldots \ge \lambda_d \ge 0$$
Eigenvectors
$u_1, u_2, \ldots$
Orthogonal directions in feature space. The $i$-th principal component is the $i$-th column of $U$. Ordered by variance captured.
Eigenvalues
$\lambda_i$ = variance along $u_i$
$\sum \lambda_i = \mathrm{trace}(\hat\Sigma) = $ total variance. $\lambda_1 / \sum \lambda_i$ is the fraction of variance explained by the first PC.
Scree plot
Eigenvalues, sorted
Elbow = natural cutoff for dimensionality reduction. Kartify: if first 5 eigenvalues capture 90% of variance, reducing from 40 features to 5 principal components retains most information.
Projection
$Z = \mathbf{X} U_k$
Project features onto the top $k$ eigenvectors. The projected coordinates are uncorrelated by construction — useful as preprocessing for algorithms sensitive to redundant features.
Kartify · PCA on 4 order features
Features. price, delivery time, session duration, coupon discount applied (4 columns).
$\hat\Sigma$ eigenvalues. Illustrative: (2.1, 1.4, 0.3, 0.2).
Variance explained. PC1: $2.1/4.0 = 52.5\%$. PC2: $1.4/4.0 = 35\%$. PC1+PC2: 87.5%.
Interpretation. First two principal components capture most structure. Projecting to 2D gives a nearly-lossless representation. Plot the 2D projection — look for clusters, outliers.
Business use. Plotting the projected data often reveals latent segments (power users, one-time buyers, high-value customers) even when no single feature clearly separates them. PCA is a diagnostic first, a preprocessing second.

Python — Joint Structure from Data

python · empirical joint + marginal + conditional from Kartify data
import numpy as np
import pandas as pd

np.random.seed(42)
n = 10_000

# Kartify simulated joint (late, returned) with dependence
joint = np.array([0.035, 0.115, 0.045, 0.805])   # (1,1),(1,0),(0,1),(0,0)
idx = np.random.choice(4, p=joint, size=n)
late = np.isin(idx, [0, 1]).astype(int)
ret = np.isin(idx, [0, 2]).astype(int)

# Empirical joint — via pandas crosstab
df = pd.DataFrame({"late": late, "ret": ret})
ct = pd.crosstab(df["late"], df["ret"], normalize=True)
print("Empirical joint PMF:")
print(ct.round(4))

# Marginals
print(f"\nMarginal P(late=1): {df.late.mean():.4f}")
print(f"Marginal P(ret=1):  {df.ret.mean():.4f}")

# Conditionals — P(ret | late)
p_ret_given_late = df[df.late == 1].ret.mean()
p_ret_given_ontime = df[df.late == 0].ret.mean()
print(f"P(ret | late=1)   = {p_ret_given_late:.4f}")   # ≈ 0.23
print(f"P(ret | late=0)   = {p_ret_given_ontime:.4f}") # ≈ 0.05
python · Pearson vs Spearman correlation + chi-squared test
import numpy as np
from scipy.stats import pearsonr, spearmanr, chi2_contingency

# Heavy-tailed Kartify data: order value vs delivery time
np.random.seed(42)
n = 5_000
latent = np.random.normal(0, 1, n)
price = np.exp(6 + 1.4*latent + 0.3*np.random.normal(0, 1, n))   # Log-normal
deliv = np.exp(2.5 + 0.4*latent + 0.3*np.random.normal(0, 1, n))   # also skewed, correlated

pearson_r, p_pearson = pearsonr(price, deliv)
spearman_r, p_spearman = spearmanr(price, deliv)
print(f"Pearson ρ  = {pearson_r:.3f}  (p = {p_pearson:.2e})")
print(f"Spearman ρ = {spearman_r:.3f}  (p = {p_spearman:.2e})")
# Spearman usually larger because it captures the full monotone relation, not linear only.

# Chi-squared test for independence (Late × Returned)
observed = np.array([[350, 1150], [450, 8050]])
chi2_stat, p_val, dof, expected = chi2_contingency(observed)
print(f"\nχ² statistic = {chi2_stat:.1f}, df = {dof}, p = {p_val:.2e}")
# p essentially zero → reject independence.
python · sample covariance matrix + PCA eigendecomposition
import numpy as np

np.random.seed(42)
n = 1_000

# 4 Kartify features: price, delivery, session_dur, coupon_disc
# Built with a 2-factor latent structure — should show 2 dominant PCs
latent = np.random.normal(0, 1, (n, 2))
A = np.array([[1.2, 0.4], [0.5, 0.9], [0.8, 0.6], [0.3, 0.7]])
noise = np.random.normal(0, 0.3, (n, 4))
X = latent @ A.T + noise

# Sample covariance matrix (with n-1 divisor = ddof=1)
Sigma_hat = np.cov(X, rowvar=False)                   # numpy defaults to unbiased
print("Σ̂:")
print(Sigma_hat.round(3))

# Eigendecomposition = PCA
eigvals, eigvecs = np.linalg.eigh(Sigma_hat)    # eigh for symmetric matrix
eigvals = eigvals[::-1]
print(f"\nEigenvalues (variance captured): {eigvals.round(3)}")
print(f"Explained variance ratio:        {(eigvals / eigvals.sum()).round(3)}")

# First two PCs should explain > 80% if the 2-factor structure is real
pct = eigvals[:2].sum() / eigvals.sum()
print(f"PC1 + PC2 variance explained: {pct*100:.1f}%")
