⚡ Kartify — Thursday's Analyst Decision Tree
Thursday. Four different stakeholders hit Priya's inbox, each with a testing question.

Ops Lead: "Our SLA target is 4-hour delivery. Are we hitting it on average?" → one-sample $t$-test ($\bar X$ vs $\mu_0$).
Growth: "Does the new app design convert better than the old one? Users are different people." → two-sample $t$-test or two-proportion $z$-test (independent samples).
Product: "For users who tried both versions, do they rate the new one higher?" → paired $t$-test (same users, before/after).
CFO (again): "Does our campaign conversion beat the 3.5% baseline?" → one-proportion $z$-test.

Four different tests for four structurally different questions. The choice matters — applying a two-sample $t$-test to paired data misses the pairing information and throws away power; applying an independent-samples test to paired data gives the wrong SE. Module 4.4 walks through each test: formula, when to use it, Kartify worked example, and Python. The goal: you see a scenario, you know exactly which test to reach for and why.

Two questions that determine every test choice
Question 1: continuous or binary outcome? Continuous → $t$-test family. Binary (yes/no, convert/no-convert) → proportion $z$-test family.

Question 2: structure of comparison? One-sample (vs a fixed value), two-sample independent (two different groups), or paired (same units, two conditions). The three shapes of every "is A different from B?" question.

Two binary choices = 6 combinations covering 95% of real-world testing. The remaining 5% (Chi-square, ANOVA, non-parametric) gets its own modules.

One-Sample $t$-Test — Sample Mean vs a Target

One-sample $t$-test · testing $H_0: \mu = \mu_0$
$$T = \frac{\bar X - \mu_0}{s / \sqrt n} \;\sim\; t_{n - 1} \text{ under } H_0$$
Kartify · is average delivery time at the 4-hour SLA target?
Data. 50 randomly sampled orders, delivery times in hours. $\bar X = 4.3$ h, $s = 0.8$ h.
Hypotheses. $H_0: \mu = 4$. $H_1: \mu \ne 4$ (two-sided — overrun OR underrun would matter).
Test statistic. $T = (4.3 - 4)/(0.8/\sqrt{50}) = 0.3 / 0.1131 = 2.65$.
$p$-value. $t_{49}$ distribution: $p = 2 \cdot P(T_{49} \ge 2.65) \approx 0.0108$.
Decision. $p = 0.011 < \alpha = 0.05$. Reject $H_0$. Evidence that average delivery time differs from the 4-hour target.
Direction. $\bar X = 4.3 > 4$ — we're overrunning the SLA. Ops lead gets the flag. Module 4.2's CI would show the plausible range for the true mean (e.g., [4.07, 4.53] hours) — reinforcing the decision.
⚡ When to use $z$ instead of $t$ for a one-sample test

Use $z$ only when $\sigma$ is known (rare) or when $n$ is very large (hundreds+) and $t_{n-1}$ is numerically indistinguishable from Normal. In practice: always use $t$ for continuous data with an estimated $\sigma$. The correction is automatic and harmless for large $n$.

Two-Sample Tests & Welch's Correction — Comparing Independent Groups

Two groups, independently sampled, continuous outcome. The canonical A/B test for a continuous metric. Two flavors: pooled $t$ (assumes equal variances), Welch's $t$ (does not).

Pooled two-sample $t$-test (equal variances assumed)
$$T = \frac{\bar X_A - \bar X_B}{s_p \sqrt{\frac{1}{n_A} + \frac{1}{n_B}}}, \quad s_p^2 = \frac{(n_A - 1)s_A^2 + (n_B - 1)s_B^2}{n_A + n_B - 2}$$
$$T \sim t_{n_A + n_B - 2} \text{ under } H_0$$
Welch's $t$-test (unequal variances OK)
$$T = \frac{\bar X_A - \bar X_B}{\sqrt{\frac{s_A^2}{n_A} + \frac{s_B^2}{n_B}}}, \quad \text{df} = \frac{(s_A^2/n_A + s_B^2/n_B)^2}{\frac{(s_A^2/n_A)^2}{n_A - 1} + \frac{(s_B^2/n_B)^2}{n_B - 1}}$$
⚠ Modern recommendation: use Welch by default

Welch's $t$-test is nearly as powerful as pooled-$t$ when variances ARE equal, and dramatically more robust when they're not. The older "first test for equal variances, then choose" is outdated — that pre-test inflates Type I error. Always use Welch unless you have a strong prior reason to assume equal variances. Python's scipy.stats.ttest_ind(..., equal_var=False) is the modern default; R has defaulted to Welch since version 1.6.

Kartify · does the new app design convert better? (Welch's $t$)
Data. Group A (old design): $n_A = 2000$, $\bar X_A = 1840$ (₹/order), $s_A = 2400$. Group B (new design): $n_B = 1800$, $\bar X_B = 1980$, $s_B = 2200$.
Hypotheses. $H_0: \mu_A = \mu_B$ (no design effect). $H_1: \mu_A \ne \mu_B$ (two-sided).
Welch statistic. $T = (1840 - 1980) / \sqrt{2400^2/2000 + 2200^2/1800} = -140 / \sqrt{2880 + 2689} = -140 / 74.6 = -1.88$.
df (Welch). Using the Welch-Satterthwaite formula: approximately 3775.
$p$-value. $p = 2 \cdot P(T_{3775} \le -1.88) \approx 0.061$.
Decision. $p = 0.061 > 0.05$. Fail to reject $H_0$. Evidence is borderline — new design might increase per-order value, but the data at this sample size can't confirm it. More data needed.

Paired $t$-Test — Matched Pairs Capture More Information

When the same units are measured under two conditions (before/after training, left-right matched pairs, users rating two product versions), the observations are dependent across conditions. The paired test exploits this by looking at within-unit differences.

Paired $t$-test
$$D_i = X_{A,i} - X_{B,i}, \quad T = \frac{\bar D}{s_D / \sqrt n} \sim t_{n - 1}$$
Why pairing increases power
If we measure user $i$'s rating under both conditions A and B, much of the between-user variability ($\sigma_{\text{user}}^2$) cancels out in $D_i = X_{A,i} - X_{B,i}$. The effective variance in the difference is much smaller than the between-group variance of $\bar X_A - \bar X_B$. Typical result: paired test detects an effect at half the sample size of an unpaired test. When units are matched, always use the paired test — throwing away pairing information is a power leak.
Kartify · users rating old vs new design (paired)
Data. $n = 200$ users each rated both designs. Differences $D_i = \text{new} - \text{old}$: $\bar D = 0.35$ (rating points), $s_D = 1.8$.
Hypotheses. $H_0: \mu_D = 0$ (no within-user difference). $H_1: \mu_D \ne 0$.
Test statistic. $T = 0.35 / (1.8/\sqrt{200}) = 0.35 / 0.127 = 2.75$.
$p$-value. $p = 2 \cdot P(T_{199} \ge 2.75) \approx 0.0065$.
Decision. Reject $H_0$. Users rate the new design significantly higher than the old — by an estimated 0.35 points on average.
Contrast with unpaired. If we treated these as independent groups (ignoring pairing) using $s$ of all 400 observations (say $s = 1.1$): $T \approx 0.35 / (1.1 \sqrt{1/200 + 1/200}) = 3.18$ but with much larger effective noise. Actually — unpaired would usually lose significance here because between-user variance dominates. Paired is the right test.

Proportion Tests & McNemar — For Binary Outcomes

One-proportion $z$-test · $H_0: p = p_0$
$$Z = \frac{\hat p - p_0}{\sqrt{p_0 (1 - p_0) / n}} \;\sim\; N(0, 1) \text{ under } H_0$$
Two-proportion $z$-test · $H_0: p_A = p_B$
$$Z = \frac{\hat p_A - \hat p_B}{\sqrt{\hat p(1 - \hat p)\left(\frac{1}{n_A} + \frac{1}{n_B}\right)}}, \quad \hat p = \frac{k_A + k_B}{n_A + n_B}$$
Kartify · two-proportion test — conversion A vs conversion B
Data. Group A (old funnel): $n_A = 8000$, $k_A = 280$, $\hat p_A = 0.035$. Group B (new funnel): $n_B = 8000$, $k_B = 340$, $\hat p_B = 0.0425$.
Pooled rate. $\hat p = 620 / 16000 = 0.03875$.
Test statistic. $Z = (0.0425 - 0.035) / \sqrt{0.03875 \cdot 0.96125 \cdot (1/8000 + 1/8000)} = 0.0075 / 0.003054 = 2.46$.
$p$-value. Two-sided: $p = 2 \cdot (1 - \Phi(2.46)) = 0.0139$.
Decision. $p = 0.014 < 0.05$. Reject $H_0$. Evidence that the new funnel converts better; estimated lift = 0.75 percentage points (or +21% relative).
For CI. Module 4.2's Wald / Wilson CI on the difference gives the range of plausible lifts. Business decision uses both: significance of the effect AND its practical magnitude.
When Wald $z$ works
$n p \ge 10$ AND $n(1-p) \ge 10$
Standard sample-size rule. Both proportions' count estimates should be at least 10 (some sources say 5). Kartify's counts (280, 340) are well above — $z$-test fine.
When Wald $z$ fails
Rare events, small samples
For rare events or small samples, use Fisher's exact test (scipy fisher_exact) or a continuity-corrected test. Gives exact $p$-values without Normal approximation.
McNemar's test
Paired proportions
Same users tested under two conditions, binary outcome each. Tests based on discordant pairs only: $\chi^2 = (b - c)^2 / (b + c)$ where $b, c$ are the asymmetric counts. Paired analog of 2-prop $z$.
Choosing
Match structure to data
Two independent groups → 2-prop $z$ (or chi-squared). Same subjects twice → McNemar. Fixed-value comparison → 1-prop $z$. Structure of the data always dictates structure of the test.

Kartify · effect size accompanying each test
One-sample $t$ (delivery times). Cohen's $d = (4.3 - 4)/0.8 = 0.375$ — small-to-medium effect. Not trivial; worth Ops attention.
Two-sample $t$ (order value A vs B). $d = (1980 - 1840)/s_{\text{pooled}} \approx 0.06$ — tiny effect. Even if $p$ were small at larger $n$, the magnitude is modest.
Paired $t$ (ratings). $d_z = 0.35/1.8 = 0.19$ — small effect. Statistically significant but modest in magnitude. Expected at $n = 200$ with paired design.
Two-proportion (funnel A vs B). Risk difference: $0.0425 - 0.035 = 0.0075$. Relative lift: $0.0075/0.035 = 21\%$. Both reported — absolute matters for revenue modeling, relative for comparison to peer tests.
Rule. Every test result gets a $p$-value, an effect size, and a CI on the effect. Three numbers; complete picture. Reporting just $p$ is insufficient in modern practice.

Python — Running Each Test

python · one-sample, two-sample, paired $t$-tests
import numpy as np
from scipy import stats

np.random.seed(42)

# 1. One-sample t-test — delivery times vs 4-hour target
deliv = np.random.normal(4.3, 0.8, 50)
t_stat, p_val = stats.ttest_1samp(deliv, popmean=4)
print(f"One-sample t: T = {t_stat:.2f}, p = {p_val:.4f}")
effect_d = (deliv.mean() - 4) / deliv.std(ddof=1)
print(f"  Cohen's d: {effect_d:.3f}")

# 2. Two-sample Welch's t-test — order value by design
group_A = np.random.normal(1840, 2400, 2000)
group_B = np.random.normal(1980, 2200, 1800)
t_stat, p_val = stats.ttest_ind(group_A, group_B, equal_var=False)    # Welch
print(f"\nTwo-sample (Welch) t: T = {t_stat:.2f}, p = {p_val:.4f}")

# 3. Paired t-test — user ratings old vs new
ratings_old = np.random.normal(3.2, 1.2, 200)
ratings_new = ratings_old + np.random.normal(0.35, 1.0, 200)
t_stat, p_val = stats.ttest_rel(ratings_new, ratings_old)                   # paired
print(f"\nPaired t: T = {t_stat:.2f}, p = {p_val:.4f}")
diff = ratings_new - ratings_old
effect_dz = diff.mean() / diff.std(ddof=1)
print(f"  Cohen's d_z: {effect_dz:.3f}")
python · one- and two-proportion $z$-tests
import numpy as np
from statsmodels.stats.proportion import proportions_ztest, confint_proportions_2indep

# 1. One-proportion z-test — Kartify campaign conversion vs 3.5% baseline
n, k = 12000, 489
z_stat, p_val = proportions_ztest(k, n, value=0.035, alternative="larger")
print(f"1-prop z: Z = {z_stat:.2f}, p = {p_val:.5f}")

# 2. Two-proportion z-test — funnel A vs funnel B
k_A, n_A = 280, 8000
k_B, n_B = 340, 8000
z_stat, p_val = proportions_ztest([k_A, k_B], [n_A, n_B])
print(f"\n2-prop z: Z = {z_stat:.2f}, p = {p_val:.4f}")

# CI for the difference in proportions
ci_low, ci_high = confint_proportions_2indep(k_B, n_B, k_A, n_A, method="wald")
print(f"95% CI for p_B - p_A: [{ci_low:.4f}, {ci_high:.4f}]")
# Note the effect size: difference is about 0.75 pp, or ~21% relative lift

# 3. For rare events or small samples — Fisher's exact
from scipy.stats import fisher_exact
small_table = [[2, 48], [8, 42]]                 # 2x2 contingency
odds_ratio, p_val = fisher_exact(small_table)
print(f"\nFisher exact: OR = {odds_ratio:.2f}, p = {p_val:.4f}")

# 4. McNemar (paired proportions)
from statsmodels.stats.contingency_tables import mcnemar
# Same users rated old vs new design as like/dislike. b=27 switched old→new, c=13 new→old
table = np.array([[45, 13], [27, 115]])
result = mcnemar(table, exact=False, correction=True)
print(f"\nMcNemar χ²: {result.statistic:.2f}, p = {result.pvalue:.4f}")
