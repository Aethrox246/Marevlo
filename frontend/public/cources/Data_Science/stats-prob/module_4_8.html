Track 4 · Statistical Inference

Multiple Testing
& Corrections

Testing 20 hypotheses at $\alpha = 0.05$ gives a 64% chance of at least one false positive. This module covers the problem and the solutions: Bonferroni (simple, conservative), Holm (uniformly more powerful), and Benjamini-Hochberg (controls false discovery rate, the modern default for large-scale testing).

Module 4.8 FWER · Bonferroni · Holm step-down · FDR · Benjamini-Hochberg · Case study Kartify: the 20-test Monday retrospective Wasserman Ch. 10.7 · Benjamini & Hochberg 1995
⚡ Kartify — Monday Retrospective: How Many Tests Did We Actually Run?
Monday, week 6. Priya audits the previous week's analysis. The team ran: 1 one-proportion $z$-test (campaign conversion), 1 goodness-of-fit (category mix), 1 independence test (category × returns), 1 ANOVA + 6 Tukey pairwise comparisons (4-city revenue), 2 two-sample tests (A/B design), 1 paired test (ratings), 3 non-parametric tests (premium vs standard, Kruskal-Wallis, permutation). Grand total: 16 tests from one week's data.

Under the null (all 16 effects are zero), the probability of at least one false positive at $\alpha = 0.05$ each: $1 - 0.95^{16} \approx 56\%$. More than coin-flip! The team has been running a multiple-testing inflation machine. If they publish all 16 results naively, roughly half the time some finding is a false positive — and they don't know which one.

Module 4.8 introduces three corrections, ordered from most conservative to most permissive: Bonferroni ($\alpha/m$ per test — simple, often too strict), Holm (step-down — always more powerful than Bonferroni, same FWER control), and Benjamini-Hochberg (controls false discovery rate instead of FWER — the standard for genomics, A/B testing at scale, any setting with many hypotheses).

The Multiple-Testing Problem — Inflation by Accumulation

Family-wise error rate (FWER)
$$\text{FWER} = P(\text{at least one false rejection}) = 1 - (1 - \alpha)^m \approx m\alpha \text{ for small } \alpha$$

⚠ This is not hypothetical — it's the default in applied research

Most data-science teams run many tests without correction. Genomics papers test 20,000 genes; A/B testing platforms run hundreds of metrics. Without correction, the "discoveries" are dominated by noise. The replication crisis in psychology and biomedical research is substantially a multiplicity problem.

// Section 2

Bonferroni Correction — Simple and Conservative

Bonferroni correction
$$\text{Reject } H_{0,i} \text{ if } p_i < \alpha / m$$
Mechanism
Divide $\alpha$ equally among $m$ tests
Each test gets budget $\alpha/m$. For $m = 16$, $\alpha = 0.05$: each test must hit $p < 0.003125$. Guarantees FWER $\le \alpha$ by Boole's inequality.
Strength
No assumptions needed
Works for any dependence structure between tests. No need to know correlations. Universal applicability.
Weakness
Conservative — loses power
With 1,000 tests, each needs $p < 0.00005$. Real effects with moderate evidence ($p = 0.001$) get missed. The "price" of simplicity is lost discoveries.
Adjusted $p$-value
$\tilde p_i = \min(m \cdot p_i, 1)$
Equivalently: multiply each raw $p$ by $m$, reject if $\tilde p_i < \alpha$. Easier to interpret — adjusted $p$-values are directly comparable to $\alpha$.
// Section 3

Holm Step-Down — Uniformly Better Than Bonferroni

Holm's procedure (1979)
$$\text{Order } p_{(1)} \le p_{(2)} \le \ldots \le p_{(m)}. \text{ Reject } H_{0,(j)} \text{ while } p_{(j)} < \frac{\alpha}{m - j + 1}$$
Holm step-down — worked example
1
Sort $p$-values: $p_{(1)} = 0.0002$, $p_{(2)} = 0.003$, $p_{(3)} = 0.012$, $p_{(4)} = 0.045$, $p_{(5)} = 0.22$. ($m = 5$, $\alpha = 0.05$.)
2
Test 1: $p_{(1)} = 0.0002 < 0.05/5 = 0.01$? Yes → reject.
3
Test 2: $p_{(2)} = 0.003 < 0.05/4 = 0.0125$? Yes → reject.
4
Test 3: $p_{(3)} = 0.012 < 0.05/3 = 0.0167$? Yes → reject.
5
Test 4: $p_{(4)} = 0.045 < 0.05/2 = 0.025$? No → stop. Don't reject this or any remaining.
6
Result: reject first 3 hypotheses. Bonferroni would have required $p < 0.01$ for all — would have rejected only 2. Holm recovered one more discovery.
◆ Always use Holm over Bonferroni

Holm is uniformly more powerful than Bonferroni (rejects everything Bonferroni rejects, plus sometimes more) while controlling the same FWER. Same assumptions (none). No reason to ever use Bonferroni when Holm is available. Python: statsmodels.stats.multitest.multipletests(pvals, method="holm").

// Section 4

False Discovery Rate & Benjamini-Hochberg — The Modern Default

FWER controls the probability of any false positive. But at scale (1,000+ tests), this is too strict — you'd need overwhelming evidence for each. A more practical question: "of the tests I call significant, what fraction are false?" That's the false discovery rate (FDR).

False Discovery Rate
$$\text{FDR} = E\!\left[\frac{\text{false discoveries}}{\text{total discoveries}} \right], \quad \text{with } 0/0 := 0$$
Benjamini-Hochberg (BH) procedure
$$\text{Order } p_{(1)} \le \ldots \le p_{(m)}. \text{ Find largest } j \text{ such that } p_{(j)} \le \frac{j}{m} \alpha. \text{ Reject } H_{0,(1)}, \ldots, H_{0,(j)}.$$
FWER vs FDR — which to control?
FWER (Bonferroni, Holm): no false positives allowed. Appropriate when each false positive has high cost — drug approval, safety claims, legal decisions. Very conservative.

FDR (BH): some false positives are tolerable if we know the rate. Appropriate when you're screening many hypotheses — genomics, A/B feature rollouts, exploratory analysis. FDR = 0.05 means "5% of my discoveries are expected to be false." If you discover 100 genes, ~5 are false positives. Often acceptable; vastly more powerful than FWER control.

Kartify: for 16 tests from one week's analysis, Holm is natural. For a platform running 500 A/B metrics, BH is the right tool.
Kartify · BH procedure on the week's 16 tests
Sorted $p$-values (illustrative). $0.0001, 0.0003, 0.0014, 0.003, 0.011, 0.014, 0.028, 0.045, 0.061, 0.08, 0.103, 0.15, 0.22, 0.45, 0.67, 0.89$.
BH threshold at $j$. $j\alpha/m = j \cdot 0.05/16$. At $j = 1$: 0.003125; $j = 5$: 0.01563; $j = 8$: 0.025; $j = 10$: 0.03125.
Comparison. $p_{(8)} = 0.045$ vs threshold $0.025$: fails. $p_{(7)} = 0.028$ vs threshold $0.02188$: fails. $p_{(6)} = 0.014$ vs threshold $0.01875$: passes! Largest passing $j = 6$.
Result. BH rejects tests 1-6 (those with $p \le 0.014$). FDR $\le 5\%$. At most 5% of these 6 rejections are expected to be false (roughly 0.3 false discoveries).
Compare. Bonferroni: needs $p < 0.003125$ → rejects 4 tests. Holm: rejects 5 tests. BH: rejects 6 tests. The FDR approach recovers one more discovery — the cost is accepting a small expected false-discovery rate.

Python — All Corrections in One Call

python · Bonferroni, Holm, and BH in one call
import numpy as np
from statsmodels.stats.multitest import multipletests

# Kartify's 16 p-values from the week's analysis
pvals = np.array([
    0.0001, 0.0003, 0.0014, 0.003, 0.011, 0.014, 0.028, 0.045,
    0.061,  0.080,  0.103,  0.15,  0.22,  0.45,  0.67,  0.89
])

# Run all three corrections
for method in ["bonferroni", "holm", "fdr_bh"]:
    reject, adj_p, _, _ = multipletests(pvals, alpha=0.05, method=method)
    n_reject = reject.sum()
    print(f"\n{method:<12}: {n_reject} rejections")
    for i in range(min(10, len(pvals))):
        flag = " *" if reject[i] else ""
        print(f"  p[{i:2}] = {pvals[i]:.4f} → adj = {adj_p[i]:.4f}{flag}")
python · simulation: FWER inflation + correction in action
import numpy as np
from statsmodels.stats.multitest import multipletests

np.random.seed(42)
m = 20            # number of tests
n_sims = 10_000

# Under the null: ALL tests are from N(0,1) vs N(0,1) — no true effect
fwer_naive, fwer_bonf, fwer_holm, fdr_bh = 0, 0, 0, 0
for _ in range(n_sims):
    pvals = []
    for _ in range(m):
        x = np.random.normal(0, 1, 30)
        y = np.random.normal(0, 1, 30)
        from scipy.stats import ttest_ind
        _, p = ttest_ind(x, y)
        pvals.append(p)
    pvals = np.array(pvals)
    if (pvals < 0.05).any(): fwer_naive += 1
    if multipletests(pvals, method="bonferroni")[0].any(): fwer_bonf += 1
    if multipletests(pvals, method="holm")[0].any(): fwer_holm += 1
    if multipletests(pvals, method="fdr_bh")[0].any(): fdr_bh += 1

print(f"Naive (no correction):  FWER = {fwer_naive/n_sims*100:.1f}%  (should be ~64%)")
print(f"Bonferroni:             FWER = {fwer_bonf/n_sims*100:.1f}%  (should be ≤5%)")
print(f"Holm:                   FWER = {fwer_holm/n_sims*100:.1f}%  (should be ≤5%)")
print(f"BH (FDR control):       any  = {fdr_bh/n_sims*100:.1f}%  (may exceed 5% for FWER; FDR controlled)")
