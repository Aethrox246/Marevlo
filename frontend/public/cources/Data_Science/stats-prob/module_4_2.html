Confidence
Intervals

A point estimate is a promise of precision the data cannot keep. A confidence interval is a promise the data can keep — a range where the parameter plausibly lives, with a calibrated long-run coverage guarantee. Wald, $z$, $t$, Wilson, bootstrap — one framework, many flavors.

⚡ Kartify — Tuesday's CFO Meeting
Tuesday. Priya has $\hat\theta = 0.04075$ — the MLE from Module 4.1. The CFO asks: "How confident? Are we sure it's above the 3.5% baseline?"

Priya can't just say "4.08%." The number is noisy. What she can say: "We are 95% confident the true conversion rate is in the interval $[0.0373, 0.0442]$ — and because 0.035 is below this interval, the data is consistent with 'true rate > 3.5%' at the 95% level." That second statement is a confidence interval, and it's the natural uncertainty quantification to pair with any point estimate.

Four common CI types cover 95% of real-world needs. The $z$-interval — for large-sample means with known $\sigma$, or for proportions (Wald style). The $t$-interval — for means with unknown $\sigma$; the default for "I have a sample of continuous data." Wilson's score interval — the proportion CI that works when Wald breaks (low event counts, $p$ near 0 or 1). Bootstrap CIs — for anything where closed forms are painful or impossible: ratios, medians, correlations. Each has its regime; picking the wrong one means reporting the wrong uncertainty. Module 4.2 walks through all four, plus the inverse question: "how much data do I need to guarantee a given precision?"
// Section 1

What Is a Confidence Interval? — Procedure, Not Probability

Confidence interval — operational definition
$$C_n = [L(X_1, \ldots, X_n), \; U(X_1, \ldots, X_n)] \text{ is a } 1 - \alpha \text{ CI for } \theta \text{ if}$$
$$P(\theta \in C_n) \ge 1 - \alpha \text{ for all } \theta$$
The frequentist interpretation — crisply
The parameter $\theta$ is fixed but unknown. The interval $C_n$ is random (it depends on the sample). The probability statement is about the procedure: "if we repeated the experiment many times, 95% of the constructed intervals would contain the true $\theta$." Once you've computed a specific CI — say $[0.0373, 0.0442]$ — saying "there's a 95% probability $\theta \in [0.0373, 0.0442]$" is technically wrong under frequentist interpretation. $\theta$ either is in that specific interval or it isn't (a binary fact). The 95% is a long-run property of the CI construction, not a probability about any one interval. Bayesian credible intervals do allow the direct probability statement, but under a prior (Track 4.5+).
⚠ The most common CI misinterpretation

"There is a 95% probability the true value lies in [L, U]." False under frequentist definition. Correct: "95% of intervals constructed this way contain the true value." This distinction is central for statistically literate reporting. Most consumers of CIs don't care — and often the Bayesian credible interval (which does permit the direct interpretation) gives a numerically similar range. But the formal distinction matters in high-stakes inference and forms the dividing line between frequentist and Bayesian schools.

The $z$-Interval — Known $\sigma$ or Large Sample Proportions

$z$-interval for a mean (large sample)
$$\bar X \pm z_{\alpha/2} \cdot \frac{\sigma}{\sqrt n}$$

Used when $\sigma$ is known (rare in practice) or when $n$ is large enough that estimated $\sigma$ (via $s$) is effectively indistinguishable from the true $\sigma$. Common threshold: $n > 30$.

The Wald interval for a proportion — the default for $p$

Wald CI for a proportion
$$\hat p \pm z_{\alpha/2} \cdot \sqrt{\frac{\hat p(1 - \hat p)}{n}}$$
Kartify · Wald 95% CI for conversion rate
Data. $n = 12{,}000$, $k = 489$, $\hat p = 0.04075$.
SE. $\sqrt{0.04075 \cdot 0.95925 / 12000} = 0.00181$.
Margin. $1.96 \cdot 0.00181 = 0.00355$.
95% CI. $[0.04075 - 0.00355, \; 0.04075 + 0.00355] = [0.0372, 0.0443]$.
CFO answer. Priya is 95% confident the true conversion rate lies in $[3.72\%, 4.43\%]$. The 3.5% baseline is below this interval — consistent with the campaign-is-working story. (Module 4.3 formalizes the hypothesis-test equivalent.)
⚠ Wald interval breaks for small $n$ or extreme $p$

Wald assumes $\hat p$ is approximately Normal — fine for large $n$ and moderate $p$. For small counts or $p$ near 0 or 1, Wald gives intervals that include values below 0 or above 1. Example: $n = 20$, $k = 0$ → $\hat p = 0$, Wald CI = $[0, 0]$. Obviously wrong — we have no evidence that $p = 0$ exactly. Use Wilson's score interval instead for these cases (next section).

The $t$-Interval — Unknown $\sigma$, Normal Data, Any $n$

$t$-interval for a mean (unknown $\sigma$)
$$\bar X \pm t_{n-1, \; \alpha/2} \cdot \frac{s}{\sqrt n}$$

Module 3.7 built this. The key fact: when $\sigma$ is estimated by $s$, the pivot $(\bar X - \mu)/(s/\sqrt n)$ follows $t_{n-1}$, not Normal. For $n > 30$ the difference is small; for $n = 12$ it's material.

Wilson's Score Interval — The Right Way for Proportions

Wald's failure mode — intervals outside $[0, 1]$ or of zero width for $k = 0$ — motivates Wilson's score interval. Instead of centering around $\hat p$ with $\hat p$-based SE, Wilson inverts the hypothesis test: find the range of null values $p_0$ for which $\hat p$ is not "extreme."

Wilson score interval (1927)
$$\frac{1}{1 + z^2/n} \left[ \hat p + \frac{z^2}{2n} \pm z \sqrt{\frac{\hat p(1-\hat p)}{n} + \frac{z^2}{4n^2}} \right]$$
Coverage
Near nominal even for small $n$
Wilson targets 95% coverage well for $n$ as small as 10 and $p$ near 0 or 1. Wald undercovers badly in these regimes.
Boundaries
Always within $[0, 1]$
By construction — no nonsensical intervals. Handles $k = 0$ and $k = n$ correctly (gives asymmetric non-zero intervals).
Asymmetric
Center is not exactly $\hat p$
Effective center shifts toward $0.5$ — Wilson "regularizes" toward the uniform prior. Visible effect for small $n$; negligible for large $n$.
Modern recommendation
Use Wilson as the default
Statistical best practice since 2000s. Python: statsmodels.stats.proportion.proportion_confint(k, n, method="wilson"). R: binom::binom.wilson.
Kartify · when Wald fails and Wilson saves the day
Scenario. A small campaign: $n = 50$ exposures, $k = 1$ conversion.
Wald. $\hat p = 0.02$, SE $= \sqrt{0.02 \cdot 0.98 / 50} = 0.0198$. Wald 95% CI: $[-0.019, 0.059]$. Negative lower bound — nonsensical.
Wilson. $[0.0035, 0.1061]$. Positive lower bound; more honest reflection of uncertainty.
Degenerate case. If $k = 0$: Wald gives $[0, 0]$ (zero-width, zero-coverage). Wilson gives $[0, 0.071]$ — correctly reports "we have data consistent with $p$ up to ~7%."
Rule. For any proportion CI in production: use Wilson. For $n > 1000$ and $p$ in $[0.05, 0.95]$, Wald and Wilson agree to 3 decimals; outside this regime, Wilson is materially better.
// Section 5

Bootstrap CIs — CIs for Anything

Sometimes the statistic of interest has no convenient closed-form sampling distribution. Median, IQR, correlation, ratio of means, 95th percentile, a custom business KPI — all hard to derive CIs for analytically. The bootstrap solves this by simulating the sampling distribution from the data itself.

Bootstrap CI algorithm
$$\text{(1) Draw } B \text{ resamples } X^{*(b)} \text{ from data with replacement. (2) Compute } \hat\theta^{*(b)} \text{ for each. (3) Use the distribution of } \hat\theta^{*(b)} \text{ to build a CI.}$$
Three common bootstrap CI variants
1
Percentile. The $2.5$th and $97.5$th percentiles of $\{\hat\theta^{*(b)}\}$. Simple; works when the bootstrap distribution is roughly symmetric around $\hat\theta$.
2
Pivotal (basic). $[2\hat\theta - \hat\theta^{*(97.5)}, \; 2\hat\theta - \hat\theta^{*(2.5)}]$ — reflects the bootstrap percentiles around the point estimate. Better for skewed bootstrap distributions.
3
BCa (bias-corrected and accelerated). Adjusts for both bias and skew in the bootstrap distribution. Generally the most accurate; harder to compute.
Kartify · bootstrap CI for median order value
Data. 10,000 Kartify orders, heavy-tailed Log-normal. Sample median $= ₹720$.
No closed form. Median's sampling distribution depends on the unknown density at the median — intractable. Bootstrap bypasses this.
$B = 2000$ resamples give median estimates from ₹685 to ₹758.
Percentile 95% CI. $[₹697, ₹744]$ — from the 2.5th and 97.5th percentiles of the $\hat\theta^{*(b)}$s.
Power. Bootstrap gives you CIs for any statistic you can compute. Ratios of means, trimmed means, Gini coefficients, fitted model parameters — all accessible.
⚡ Why the bootstrap works — the plug-in principle

The empirical CDF $\hat F_n$ converges uniformly to the true $F$ (Glivenko-Cantelli, Module 3.1). Resampling from $\hat F_n$ is a consistent proxy for sampling from $F$. The bootstrap distribution of $\hat\theta^{*}$ around $\hat\theta$ approximates the true sampling distribution of $\hat\theta$ around $\theta$. Under regularity conditions (finite variance, continuity of the target functional), this approximation is asymptotically exact. The bootstrap is the plug-in principle applied to sampling distributions.

Sample Size Calculation — How Much Data Do You Need?

The inverse question: you want a CI of a given width. How large must $n$ be?

Required sample size for a given precision (mean)
$$\text{Margin } m = z_{\alpha/2} \cdot \frac{\sigma}{\sqrt n} \; \Rightarrow \; n = \left(\frac{z_{\alpha/2} \sigma}{m}\right)^2$$
Required sample size for a given precision (proportion)
$$n = \frac{z_{\alpha/2}^2 \cdot p(1-p)}{m^2}, \qquad \text{with } p = 0.5 \text{ for the conservative worst case}$$
Kartify · how many impressions to estimate conversion rate within ±0.5%
Target. 95% CI with margin of error $m = 0.005$ (half-width of 0.5 percentage points).
Known rough $p$. Campaign expected to convert around 4%. Use $p = 0.04$ for SE estimate.
Calculation. $n = 1.96^2 \cdot 0.04 \cdot 0.96 / 0.005^2 = 3.8416 \cdot 0.0384 / 2.5 \cdot 10^{-5} \approx 5{,}900$.
Conservative (if $p$ is uncertain). Use $p = 0.5$: $n = 1.96^2 \cdot 0.25 / 0.005^2 \approx 38{,}400$ — guaranteed to hit precision regardless of $p$.
Takeaway. Kartify's $n = 12{,}000$ easily exceeds the $\approx 5{,}900$ needed for ±0.5% precision at $p \approx 0.04$. The CFO-desired precision is already achieved.
The $1/\sqrt n$ cost of precision — why experiments are expensive
Halving the CI width requires quadrupling $n$. Reducing margin from 1% to 0.1% (10× tighter) requires 100× the data. This is the fundamental reason large-scale online experiments run for days or weeks even at high traffic sites — precision gains are $O(1/\sqrt n)$, a stubborn scaling that dominates experimental design. Rule: set your margin first, compute $n$, and if $n$ is infeasible, accept a wider CI. Don't squeeze the math to make a small sample seem more precise.

Python — All Four CI Types

python · $z$-, $t$-, Wald, and Wilson intervals
import numpy as np
from scipy.stats import norm, t
from statsmodels.stats.proportion import proportion_confint

# Kartify conversion: n=12000, k=489
n, k = 12000, 489
p_hat = k / n
print(f"p̂ = {p_hat:.5f} ({k}/{n})")

# Wald CI (quick, but can misbehave for small n)
se_wald = np.sqrt(p_hat * (1 - p_hat) / n)
ci_wald = (p_hat - 1.96 * se_wald, p_hat + 1.96 * se_wald)
print(f"Wald 95%:   [{ci_wald[0]:.4f}, {ci_wald[1]:.4f}]")

# Wilson CI (modern default for proportions)
ci_wilson = proportion_confint(k, n, alpha=0.05, method="wilson")
print(f"Wilson 95%: [{ci_wilson[0]:.4f}, {ci_wilson[1]:.4f}]")

# For Kartify scale, Wald ≈ Wilson. Difference matters for small n or extreme p.
# Demo with small-n extreme case:
small_n, small_k = 50, 1
p_small = small_k / small_n
print(f"\nSmall-n case: n={small_n}, k={small_k}, p̂={p_small}")
print(f"Wald:   {proportion_confint(small_k, small_n, method='normal')}  ← negative lower bound!")
print(f"Wilson: {proportion_confint(small_k, small_n, method='wilson')}  ← sensible")
python · bootstrap CI for Kartify median order value
import numpy as np

np.random.seed(42)

# Simulated Kartify order values: heavy-tailed Log-normal
orders = np.random.lognormal(mean=6.58, sigma=1.37, size=10_000)
point_median = np.median(orders)
print(f"Sample median: ₹{point_median:,.0f}")

# Bootstrap the sampling distribution of the median
B = 2000
boot_medians = np.empty(B)
for b in range(B):
    resample = np.random.choice(orders, size=len(orders), replace=True)
    boot_medians[b] = np.median(resample)

# Percentile CI
ci_pct = np.percentile(boot_medians, [2.5, 97.5])
print(f"Percentile 95% CI: [₹{ci_pct[0]:,.0f}, ₹{ci_pct[1]:,.0f}]")

# Pivotal (basic) CI
ci_pivot = (2 * point_median - ci_pct[1], 2 * point_median - ci_pct[0])
print(f"Pivotal 95%   CI:  [₹{ci_pivot[0]:,.0f}, ₹{ci_pivot[1]:,.0f}]")

# Bootstrap is the go-to when no closed-form SE exists (medians, quantiles, ratios, correlations)
python · sample size calculation
import numpy as np

# Kartify: what n for 95% CI with ±0.5% margin at expected p=0.04?
z = 1.96
margin = 0.005

# Using expected p
p_expected = 0.04
n_expected = (z**2 * p_expected * (1 - p_expected)) / margin**2
print(f"n for ±0.5% at p=0.04:  {np.ceil(n_expected):.0f}")

# Conservative (p=0.5 maximizes p(1-p))
n_conservative = (z**2 * 0.25) / margin**2
print(f"n for ±0.5% conservative: {np.ceil(n_conservative):.0f}")

# What if we want tighter precision — ±0.1%?
tight_margin = 0.001
n_tight = (z**2 * p_expected * (1 - p_expected)) / tight_margin**2
print(f"n for ±0.1% at p=0.04:  {np.ceil(n_tight):.0f} ({n_tight/n_expected:.0f}x the easier target)")

# Quartic cost: 5x tighter precision → 25x more data. Bitter reality of CI scaling.
