Label Smoothing

Standard cross-entropy trains the model towards one-hot targets [0, 0, 1, 0]. Label smooth- ing uses soft targets [0.05, 0.05, 0.85, 0.05] — prevents the model from becoming over- confident.

Code Example
  1. # Label smoothing is built into CrossEntropyLoss since PyTorch 1.10
  2. criterion_smooth = nn.CrossEntropyLoss(label_smoothing=0.1)
  3.  
  4. logits = torch.randn(16, 5)
  5. targets = torch.randint(0, 5, (16,))
  6.  
  7. loss_hard = nn.CrossEntropyLoss()(logits, targets)
  8. loss_soft = criterion_smooth(logits, targets)
  9.  
  10. print(f"Hard label CE loss: {loss_hard.item():.4f}")
  11. print(f"Smooth label CE loss: {loss_soft.item():.4f}")

3. Augmentations: Mixup for Tabular / Time-Series

Mixup creates new training samples by linearly interpolating between two real samples. Origi- nally proposed for images, it works well for tabular and time-series data too.

Code Example
  1. def mixup_batch(X: torch.Tensor, y: torch.Tensor, alpha: float = 0.4):
"""
    Apply mixup augmentation to a batch.
    Creates convex combinations of pairs of samples.

    Returns:
        X_mixed: interpolated features
        y_a, y_b: original labels
        lam:      mixing coefficient
    """
Code Example
  1. lam = np.random.beta(alpha, alpha) if alpha > 0 else 1.0
  2. idx = torch.randperm(len(X))
  3.  
  4. X_mixed = lam * X + (1 - lam) * X[idx]
  5. y_a = y
  6. y_b = y[idx]
  7. return X_mixed, y_a, y_b, lam
  8.  
  9.  
  10. def mixup_criterion(criterion, pred, y_a, y_b, lam):
"""Loss for mixup-augmented samples."""
Code Example
  1. return lam * criterion(pred, y_a) + (1 - lam) * criterion(pred, y_b)

4. Class Imbalance: Focal Loss + Weighted Sampling

Focal Loss

Focal loss down-weights easy, well-classified examples so the model focuses on hard ones. Originally designed for object detection, it’s highly useful for anomaly detection and fraud.

Code Example
  1. class FocalLoss(nn.Module):
"""
    Focal Loss: FL(p_t) = -alpha_t * (1 - p_t)^gamma * log(p_t)
gamma > 0 reduces loss for well-classified examples.
    alpha balances class importance.
    """
Code Example
  1. def __init__(self, alpha: float = 0.25, gamma: float = 2.0,
                 reduction: str = 'mean'):
super().__init__()
Code Example
  1. self.alpha = alpha
  2. self.gamma = gamma
  3. self.reduction = reduction
  4.  
  5. def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
  6. ce_loss = nn.functional.cross_entropy(logits, targets, reduction='none')
  7. pt = torch.exp(-ce_loss) # p_t = probability of correct class
  8. focal = self.alpha * (1 - pt) ** self.gamma * ce_loss
  9.  
  10. if self.reduction == 'mean': return focal.mean()
Key Takeaway

Module Summary

Concept Key Takeaway

Dropout                                 Add after activations in hidden layers. Never after the
                                        final layer.
Label smoothing                         CrossEntropyLoss(label_smoothing=0.1).
                                        Prevents overconfidence.
Weight decay                            Use AdamW. Apply to weights, not biases or norm
                                        parameters.
Focal loss                              Best for imbalanced classification (fraud, anomaly
                                        detection). gamma=2.
Mixup                                   Interpolate samples and labels. Improves
                                        generalisation on tabular data.
Contrastive learning                    Learn representations from unlabelled data using
                                        augmentation pairs.
HPO                                     Use Optuna. The objective function is just your
                                        training loop returning a metric.
