1. Why Sequence Modelling Matters in DS/AIOps

The Problem with Standard MLPs for Sequences

An MLP treats each input independently. Feed it [login, file_read, file_write] and

[file_write, login, file_read] — it doesn’t know these have different temporal meaning.
In AIOps:

  • A permission_denied after sudo_attempt is very different from permission_denied
    after file_read.
  • The order and context of events matters enormously for anomaly detection.

Three Architectures for Sequences

Architecture      Processes order?        Long-range deps?        Parallel training?

MLP No No Yes

LSTM/GRU          Yes                     Partially               No (sequential)

The LSTM Cell Intuition

An LSTM maintains two states: - Cell state c_t — long-term memory (the “conveyor belt”).
- Hidden state h_t — short-term working memory.
Three gates control what to keep, forget, and write:
Forget gate: f_t = (W_f · [h_{t-1}, x_t] + b_f)          ← what to forget
Input gate: i_t = (W_i · [h_{t-1}, x_t] + b_i)           ← what to write
Output gate: o_t = (W_o · [h_{t-1}, x_t] + b_o)          ← what to output

When LSTM/GRU Beat Transformers

LSTMs still win when: - Sequences are very long (> 10k tokens) and attention is prohibitively expensive. - Online/streaming inference — process one token at a time with constant memory. - Tiny datasets — Transformers need more data to generalise. - Deployment constraints — LSTMs are simpler to export and run on edge devices.

3. Attention Intuition

The Core Idea

Instead of compressing the entire sequence into a fixed-size hidden state, attention lets the model look back at any position in the sequence when computing each output. Real-World Analogy: Reading a log to detect an anomaly. Rather than summarising all 1000 events into a single vector, attention lets the model say: “To understand event 850, let me focus on events 10, 200, and 847 — they’re the most relevant context.”

  15. print(f"\nAnomaly detection @ 95th-pct threshold ({threshold:.3f}):")
  16. print(f" Precision: {precision_a:.3f}")
  17. print(f" Recall: {recall_a:.3f}")
