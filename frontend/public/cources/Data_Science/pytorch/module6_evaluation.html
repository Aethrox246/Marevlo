1. Train/Val/Test Patterns

The Three Roles

Split Purpose Rules

Train                             Fit model parameters             Can see as many times as
                                                                   you want
Validation                        Tune hyperparameters, select     See during development,
                                  models                           but don’t fit on it
Test                              Final, unbiased performance      Look at it exactly once
                                  estimate

Exclamation Important

The test set is sacred. The moment you tune anything based on test set results, it
  becomes a second validation set and your reported performance is optimistic. Report test
  performance only once — at the very end.

When to Use It

Use k-fold CV when: - Your dataset is small (< 5,000 samples) and a single val split is noisy.
- You want a reliable estimate of generalisation performance. - You are comparing multiple
models/architectures.
Do not use it on time-series (use time-series CV instead).

  3. rng = np.random.default_rng(42)
  4.

  1. alpha = (1 - confidence) / 2
