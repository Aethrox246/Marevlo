1. nn.Module, Parameters, and Buffers

What is nn.Module?

nn.Module is the base class for every neural network in PyTorch. It gives your model four superpowers:

1. Parameter tracking — any nn.Parameter or sub-module you assign is automatically

registered and returned by .parameters().

2. State saving/loading — .state_dict() and .load_state_dict() let you checkpoint

and resume.

3. Device management — .to(device) moves all parameters and buffers at once.

4. Training/eval modes — .train() and .eval() toggle behaviour of dropout, batch-

norm, etc.


Real-World Analogy: A Blueprint vs a Building

A class that inherits from nn.Module is like a blueprint. When you instantiate it, you get
an actual building (a model object) with real rooms (parameters) and fixtures (buffers). The
blueprint can be used to construct as many independent buildings as you want.
Key Takeaway

nn.Module turns raw math into a reusable model object that tracks learnable state, device moves, checkpointing, and train-vs-eval behavior.

Knowledge Check
  1. If you only used raw tensors, which PyTorch conveniences would you lose immediately?
  2. Why is a model object more than just a container for a forward() function?

4. Weight Initialisation

Why It Matters

Start with weights that are too large → activations explode → NaN loss. Start with weights too small → gradients vanish → network doesn’t learn. PyTorch’s default initialisations are already good, but understanding them helps you fix broken models.

nn.Module                             Base class for all models. Always call
                                      super().__init__() first.

                                      running stats).
nn.ModuleList                         Use instead of plain Python lists to hold submodules.
state_dict                            Save this, not the whole model. Load into a fresh
                                      instance.
model.eval()                          Always call before inference — disables dropout, fixes
                                      batchnorm.
Weight init                           Kaiming for ReLU networks; Xavier for
                                      Tanh/Sigmoid.
