THE ML PIPELINE

CI/CD for ML differs from software CI/CD: code, data, and model weights all change. You need to version and test all three independently.

Traditional CI/CD: commit code → run tests → deploy. ML CI/CD adds three more moving parts — data, model weights, and model performance — each of which can independently break production.

Hunter Pipeline Architecture

The Hunter ML pipeline (XGBoost + IsolationForest for Juniper linecard failure prediction) maps naturally to a CI/CD system. Each pipeline stage has a clear owner, artifact, and failure mode.

Stage 1
Data Ingestion
Pull S3 telemetry → validate schema → compute DVC hash. Fail fast if FPC coverage < 60%.
Stage 2
Feature Engineering
Adaptive null filtering, rolling window statistics, anomaly score delta features. Hash feature matrix.
Stage 3
Training
XGBoost + IsolationForest ensemble. Log all hyperparams, metrics, and model binary to MLflow.
Stage 4
Evaluation Gate
Precision ≥ 0.85, recall ≥ 0.80, AUC ≥ 0.90. Compare to current production model. Fail on regression.
Stage 5
Registration
Register passing model to MLflow Model Registry with stage=Staging. Tag with data hash + git SHA.
Stage 6
Deployment
Build Docker image → push to ECR → rolling deploy to inference fleet → smoke test → promote.

GITHUB ACTIONS

GitHub Actions orchestrates your entire ML pipeline as a YAML workflow — from code tests to training to deployment — triggered by commits, PRs, or schedules.

A GitHub Actions workflow is a YAML file in .github/workflows/. It defines when to run (triggers), where to run (runner), and what to run (jobs → steps).

Concept
Workflow
One YAML file. Triggered by events (push, PR, schedule, manual). Contains one or more jobs.
Concept
Job
Runs on a single machine (runner). Jobs run in parallel by default. Use needs: for sequential.
Concept
Step
A single shell command or reusable Action. Steps in a job run sequentially on the same machine.
Concept
Secrets
Encrypted values stored in repo settings. Injected as env vars: ${{ secrets.API_KEY }}.
Concept
Artifacts
Files uploaded between jobs with upload-artifact / download-artifact. Max 500MB.
Concept
Cache
Speed up pip installs with actions/cache. Keyed by requirements.txt hash.
YAML — .github/workflows/ml_ci.yml: Minimal ML CI
name: Hunter ML CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]
  schedule:
    - cron: '0 6 * * *'  # Daily 6am UTC

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Cache pip
        uses: actions/cache@v4
        with:
          path: ~/.cache/pip
          key: ${{ runner.os }}-pip-${{ hashFiles('requirements.txt') }}

      - name: Install dependencies
        run: pip install -r requirements.txt -r requirements-dev.txt

      - name: Lint
        run: ruff check src/ tests/

      - name: Type check
        run: mypy src/

      - name: Unit tests
        run: pytest tests/unit/ -v --tb=short

      - name: Integration tests
        run: pytest tests/integration/ -v --timeout=120
        env:
          AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
          AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}

DVC + DATA VERSIONING

DVC (Data Version Control) adds Git-like versioning for data and models. Large files stay in S3/GCS; Git stores tiny pointer files. Every dataset version is reproducible.

DVC works alongside Git. You add large files to DVC tracking (dvc add), then commit tiny .dvc pointer files to Git. Anyone with access can reproduce the exact dataset using dvc pull.

Shell — DVC Setup and Basic Commands
# Install DVC with S3 support
pip install "dvc[s3]"

# Initialize DVC in your Git repo
git init
dvc init
git commit -m "Initialize DVC"

# Configure remote storage (S3)
dvc remote add -d myremote s3://marevlo-hunter-data/dvc
dvc remote modify myremote region us-east-1
git add .dvc/config
git commit -m "Configure DVC S3 remote"

# ── Track a dataset ──────────────────────────
dvc add data/raw/telemetry.parquet
# Creates: data/raw/telemetry.parquet.dvc  (tiny pointer file)
# Updates: .gitignore (ignores actual data file)

git add data/raw/telemetry.parquet.dvc .gitignore
git commit -m "feat: add telemetry dataset v1.2.0"
dvc push    # Uploads to S3

# ── On another machine / in CI ───────────────
git pull    # Gets the .dvc pointer files
dvc pull    # Downloads actual data from S3

# ── Reproduce exact past dataset ─────────────
git checkout v1.1.0
dvc checkout   # Gets the data as it was at v1.1.0
✓
DVC pointer files are tiny: A .dvc file is just a few lines of YAML containing the MD5 hash of the original file. Commit these to Git like any other source file — they're what enables dataset reproducibility across your team and CI environment.

Data Validation in CI

Python — src/validate_data.py
import pandas as pd
import json, sys
from pathlib import Path
from dataclasses import dataclass

@dataclass
class DataValidationResult:
    passed:   bool
    errors:   list[str]
    warnings: list[str]
    stats:    dict

def validate_telemetry(path: str = "data/raw/telemetry.parquet") -> DataValidationResult:
    """Validate Hunter telemetry dataset before training."""
    errors, warnings = [], []

    # Load data
    df = pd.read_parquet(path)

    # ── Schema checks ──────────────────────
    required_cols = ["lc_id", "fpc_id", "ts", "cpu_util", "mem_util"]
    missing = [c for c in required_cols if c not in df.columns]
    if missing:
        errors.append(f"Missing required columns: {missing}")

    # ── Size checks ────────────────────────
    if len(df) < 1000:
        errors.append(f"Too few rows: {len(df)} (min: 1000)")
    elif len(df) < 5000:
        warnings.append(f"Low row count: {len(df)} (recommended: 5000+)")

    # ── FPC coverage check ─────────────────
    if "fpc_id" in df.columns:
        fpc_coverage = df["fpc_id"].notna().mean()
        if fpc_coverage < 0.6:
            errors.append(f"FPC coverage too low: {fpc_coverage:.1%} (min: 60%)")

    # ── Null rate checks ───────────────────
    null_rates = df.isnull().mean()
    high_null = null_rates[null_rates > 0.3]
    if not high_null.empty:
        warnings.append(f"High null rate columns: {high_null.to_dict()}")

    # ── Temporal coverage ──────────────────
    if "ts" in df.columns:
        df["ts"] = pd.to_datetime(df["ts"])
        days_covered = (df["ts"].max() - df["ts"].min()).days
        if days_covered < 7:
            warnings.append(f"Short temporal window: {days_covered} days")

    stats = {"rows": len(df), "cols": len(df.columns), "fpc_coverage": float(fpc_coverage)}

    for e in errors:   print(f"  ✗ ERROR: {e}")
    for w in warnings: print(f"  ⚠ WARN:  {w}")

    result = DataValidationResult(passed=not errors, errors=errors, warnings=warnings, stats=stats)
    if not result.passed:
        sys.exit(1)   # Fail the CI step
    return result

if __name__ == "__main__":
    validate_telemetry()

Model Registry: Staging → Production Promotion

Python — src/register_model.py
import mlflow
from mlflow.tracking import MlflowClient
import json, sys

client = MlflowClient("http://mlflow.marevlo.com")
MODEL_NAME = "hunter-xgb-v2"

def get_latest_run_id(experiment_name: str) -> str:
    exp = client.get_experiment_by_name(experiment_name)
    runs = client.search_runs(
        experiment_ids=[exp.experiment_id],
        order_by=["attributes.start_time DESC"],
        max_results=1
    )
    return runs[0].info.run_id

def register_and_stage(run_id: str, stage: str = "Staging") -> str:
    # Register model version from run
    version = mlflow.register_model(
        model_uri=f"runs:/{run_id}/hunter_xgb",
        name=MODEL_NAME
    )
    # Transition to requested stage
    client.transition_model_version_stage(
        name=MODEL_NAME,
        version=version.version,
        stage=stage,
        archive_existing_versions=True
    )
    # Add descriptive tags
    client.set_model_version_tag(MODEL_NAME, version.version, "promoted_by", "ci/cd")
    client.set_model_version_tag(MODEL_NAME, version.version, "git_sha", "${GITHUB_SHA}")
    print(f"Registered {MODEL_NAME} v{version.version} → {stage}")
    return version.version

def load_production_model():
    # Load the current production model — always the latest "Production" stage
    return mlflow.sklearn.load_model(f"models:/{MODEL_NAME}/Production")

def compare_with_production(new_metrics: dict, threshold: float = 0.02) -> bool:
    """Fail if new model is more than threshold worse than production."""
    prod_versions = client.get_latest_versions(MODEL_NAME, stages=["Production"])
    if not prod_versions:
        print("No production model — first deploy, skipping comparison")
        return True

    prod_run_id = prod_versions[0].run_id
    prod_metrics = client.get_run(prod_run_id).data.metrics

    regressions = []
    for metric in ["precision", "recall", "auc"]:
        delta = prod_metrics.get(metric, 0) - new_metrics.get(metric, 0)
        if delta > threshold:
            regressions.append(f"{metric} regressed by {delta:.3f}")

    if regressions:
        print(f"✗ Regression detected: {regressions}")
        sys.exit(1)
    return True

from mlflow.tracking import MlflowClient
import mlflow

client = MlflowClient()

def champion_challenger(experiment_name: str, n_recent: int = 5) -> dict:
    """Compare top N recent runs; promote best to Staging if it beats champion."""
    exp = client.get_experiment_by_name(experiment_name)
    runs = client.search_runs(
        experiment_ids=[exp.experiment_id],
        filter_string="attributes.status = 'FINISHED'",
        order_by=["metrics.auc DESC"],
        max_results=n_recent
    )

    if not runs:
        raise ValueError("No finished runs found")

    best = runs[0]
    print(f"Best challenger: run_id={best.info.run_id}")
    print(f"  AUC={best.data.metrics['auc']:.3f}")
    print(f"  Precision={best.data.metrics['precision']:.3f}")

    # Check gates
    thresholds = {"precision": 0.85, "recall": 0.80, "auc": 0.90}
    for metric, threshold in thresholds.items():
        value = best.data.metrics.get(metric, 0)
        if value < threshold:

REQUESTS = Counter("hunter_requests_total", "Total inference requests", ["risk_level"])
LATENCY  = Histogram("hunter_latency_seconds", "Inference latency")

# Model cache — loaded once at startup
model = None

class InferenceRequest(BaseModel):
    device_id:  str = Field(pattern=r"^[A-Z]{2,4}-\d{3}$")
    cpu_util:   float = Field(ge=0, le=100)
    mem_util:   float = Field(ge=0, le=100)
    pfe_errors: int = Field(ge=0)
    bgp_flaps:  int = Field(ge=0)

    device_id:   str
    risk_level:  Literal["LOW", "MED", "HIGH"]
    score:       float
    model_version: str

@app.on_event("startup")
async def load_model():
    global model
    model_uri = os.getenv("MODEL_URI", "models:/hunter-xgb-v2/Production")
    model = mlflow.sklearn.load_model(model_uri)
    logger.info(f"Loaded model: {model_uri}")

@app.post("/predict", response_model=InferenceResponse)
async def predict(req: InferenceRequest):
    t0 = time.perf_counter()
    X = np.array([[req.cpu_util, req.mem_util, req.pfe_errors, req.bgp_flaps]])

    risk  = "HIGH" if proba >= 0.8 else ("MED" if proba >= 0.5 else "LOW")

    REQUESTS.labels(risk_level=risk).inc()
    LATENCY.observe(time.perf_counter() - t0)

    return InferenceResponse(device_id=req.device_id, risk_level=risk, score=round(float(proba), 3), model_version="2.0")

        raise HTTPException(503, "Model not loaded")
    return {"status": "healthy"}

@app.get("/metrics")

    return generate_latest()

EVALUATION GATES

Eval gates are assertions that block deployment if model quality drops. They're the ML equivalent of failing unit tests — CI must not proceed if the model doesn't meet the bar.

Python — src/check_gates.py: Hard Evaluation Gates
import json, sys, argparse
from pathlib import Path

THRESHOLDS = {
    "precision": 0.85,   # Minimum precision
    "recall":    0.80,   # Minimum recall
    "auc":       0.90,   # Minimum AUC-ROC
}

def check_gates(metrics_path: str) -> bool:
    metrics = json.loads(Path(metrics_path).read_text())

    passed, failed = [], []

    for metric, threshold in THRESHOLDS.items():
        value = metrics.get(metric)
        if value is None:
            failed.append(f"  ✗ {metric}: MISSING from metrics file")
        elif value < threshold:
            failed.append(f"  ✗ {metric}: {value:.3f} < {threshold:.3f} (FAILED)")
        else:
            passed.append(f"  ✓ {metric}: {value:.3f} >= {threshold:.3f}")

    print("\n=== Evaluation Gate Results ===")
    for msg in passed + failed: print(msg)

    if failed:
        print(f"\n✗ {len(failed)} gate(s) FAILED — blocking deployment")
        sys.exit(1)   # Non-zero exit code fails the CI step

    print(f"\n✓ All {len(passed)} gates PASSED — proceeding to deployment")
    return True

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--metrics", required=True)
    args = parser.parse_args()
    check_gates(args.metrics)

Drift Detection as a CI Gate

Python — Automated Data Drift Detection
import numpy as np
from scipy import stats
import pandas as pd, json, sys

def detect_distribution_drift(
    reference: pd.DataFrame,    # Training data distribution
    current:   pd.DataFrame,    # New production data
    columns:   list[str],
    threshold: float = 0.05   # KS p-value threshold
) -> dict:
    results = {}
    drifted = []

    for col in columns:
        if col not in reference.columns or col not in current.columns:
            continue

        # Kolmogorov-Smirnov test for distribution shift
        ks_stat, p_value = stats.ks_2samp(
            reference[col].dropna(),
            current[col].dropna()
        )

        drifted_flag = p_value < threshold
        results[col] = {
            "ks_statistic": round(ks_stat, 4),
            "p_value": round(p_value, 4),
            "drifted": drifted_flag,
            "ref_mean": round(reference[col].mean(), 3),
            "cur_mean": round(current[col].mean(), 3)
        }
        if drifted_flag:
            drifted.append(col)
            print(f"  ⚠ DRIFT: {col} p={p_value:.4f} (ref_mean={reference[col].mean():.2f}, cur_mean={current[col].mean():.2f})")

    # Fail CI if more than 30% of features drifted
    drift_rate = len(drifted) / max(len(columns), 1)
    if drift_rate > 0.3:
        print(f"\n✗ Drift rate {drift_rate:.0%} exceeds threshold (30%) — retrain required")
        sys.exit(1)

    return {"drift_rate": drift_rate, "drifted_features": drifted, "details": results}

Shadow Mode Evaluation

Python — Shadow Mode: Run Challenger Without Impact
import asyncio, mlflow
from dataclasses import dataclass, field
from collections import defaultdict
import numpy as np

@dataclass
class ShadowEvaluator:
    """Run challenger model in shadow mode: record predictions, don't serve them."""
    champion_uri:   str
    challenger_uri: str
    n_samples:      int = 1000
    champion:       object = None
    challenger:     object = None
    results:        list = field(default_factory=list)

    def __post_init__(self):
        self.champion   = mlflow.sklearn.load_model(self.champion_uri)
        self.challenger = mlflow.sklearn.load_model(self.challenger_uri)

    def record(self, X: np.ndarray, ground_truth: int):
        """Record both models' predictions for the same input."""
        champ_prob  = self.champion.predict_proba(X)[0, 1]
        chall_prob  = self.challenger.predict_proba(X)[0, 1]
        self.results.append({
            "ground_truth":  ground_truth,
            "champion_prob": champ_prob,
            "challenger_prob": chall_prob,
        })

    def evaluate(self) -> dict:
        if len(self.results) < self.n_samples:
            raise ValueError(f"Need {self.n_samples} samples, have {len(self.results)}")

        from sklearn.metrics import roc_auc_score, precision_score
        truth = [r["ground_truth"] for r in self.results]
        champ = [r["champion_prob"] for r in self.results]
        chall = [r["challenger_prob"] for r in self.results]

        champ_auc  = roc_auc_score(truth, champ)
        chall_auc  = roc_auc_score(truth, chall)
        delta      = chall_auc - champ_auc

        print(f"Champion AUC:   {champ_auc:.3f}")
        print(f"Challenger AUC: {chall_auc:.3f}")
        print(f"Delta:          {delta:+.3f}")

        # Promote challenger if it's meaningfully better
        promote = delta >= 0.01
        print(f"Promote challenger: {'YES' if promote else 'NO'}")
        return {"champ_auc": champ_auc, "chall_auc": chall_auc, "delta": delta, "promote": promote}

Automated Rollback on Drift

Python — scripts/auto_rollback.py
import requests, mlflow, subprocess, time, logging

logger = logging.getLogger("hunter.rollback")
client = mlflow.tracking.MlflowClient()

def check_production_health(
    prometheus_url: str = "http://prometheus:9090",
    window_minutes: int = 10
) -> dict:
    def query(q): return requests.get(f"{prometheus_url}/api/v1/query", params={"query": q}).json()

    p95_latency = query(f"histogram_quantile(0.95, rate(hunter_latency_seconds_bucket[{window_minutes}m]))")
    error_rate  = query(f"rate(hunter_requests_total{{status='error'}}[{window_minutes}m]) / rate(hunter_requests_total[{window_minutes}m])")
    high_rate   = query(f"rate(hunter_requests_total{{risk_level='HIGH'}}[{window_minutes}m]) / rate(hunter_requests_total[{window_minutes}m])")

    return {
        "p95_latency_ms":  float(p95_latency["data"]["result"][0]["value"][1]) * 1000,
        "error_rate":      float(error_rate["data"]["result"][0]["value"][1]),
        "high_risk_rate":  float(high_rate["data"]["result"][0]["value"][1]),
    }

SLA = {"p95_latency_ms": 500, "error_rate": 0.01, "high_risk_rate": 0.4}

def monitor_and_rollback(check_interval: int = 60, duration: int = 600):
    deadline = time.time() + duration
    while time.time() < deadline:
        health = check_production_health()
        breaches = [k for k, limit in SLA.items() if health.get(k, 0) > limit]

        if breaches:
            logger.error(f"SLA breached on {breaches} — initiating rollback")
            subprocess.run(["python", "scripts/rollback.py", "--environment", "production"], check=True)
            return False

        logger.info(f"Health OK: {health}")
        time.sleep(check_interval)

    logger.info("Monitoring complete — no SLA breaches detected")
    return True
