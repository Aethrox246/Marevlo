01 · The Problem

Why Regular Databases Can't Do This

You have 10 million document chunks, each a 1536-dimensional vector. A user asks a question. You need the 5 most similar chunks in under 100ms. A traditional SQL database does exact row lookups by index — it cannot compute cosine similarity across 10 million high-dimensional vectors in real time. You need a specialized data structure.

❌ PostgreSQL (naive)

Full table scan: compare query vector against all 10M rows. ~60 seconds. Unusable for production.

⚠️ PostgreSQL + pgvector

Adds vector indexing. Good for <1M vectors, already using Postgres. Not ideal for very large scale.

✅ Vector Database

Purpose-built: HNSW or IVF index allows approximate nearest neighbor search in <10ms at any scale.

💡

The key trade-off: exact vs approximate search

Exact nearest neighbor search (brute force) guarantees finding the truly most similar vector — but is O(n) per query. Approximate Nearest Neighbor (ANN) algorithms like HNSW find the probably most similar vector in O(log n) — 99%+ accuracy at 100× the speed. For RAG, ANN is almost always the right choice.

02 · The Algorithm

HNSW: How Fast Search Actually Works

Hierarchical Navigable Small World (HNSW) is the dominant algorithm in modern vector databases. Understanding it explains why Pinecone, Weaviate, and Qdrant can search 100M vectors in milliseconds.

HNSW: a graph of graphs, searched top-down

Click Animate to see top-down search
Layer 2 (top)Few nodes, long-range connections. Entry point. Coarse navigation.
Layer 1 (mid)More nodes, medium connections. Refine the search region.
Layer 0 (base)All nodes, local connections. Final precise search.

04 · Implementation

Chroma and Qdrant in Practice

Two complete, runnable examples — Chroma for getting started quickly, Qdrant for production. Both show the same operations: create collection, upsert vectors, query with filters.

chroma_quickstart.py — zero-config local vector DB

Python
import chromadb
from chromadb.utils import embedding_functions

# Start Chroma — no config, stores to disk automatically
client = chromadb.PersistentClient(path="./chroma_db")

# OpenAI embedding function (or swap for SentenceTransformer for free)
ef = embedding_functions.OpenAIEmbeddingFunction(
    api_key="YOUR_API_KEY",
    model_name="text-embedding-3-small"
)

# Create (or get existing) collection
collection = client.get_or_create_collection(
    name="company_docs",
    embedding_function=ef,
    metadata={"hnsw:space": "cosine"}  # distance metric
)

# Add documents — Chroma embeds automatically
collection.add(
    ids=["doc1", "doc2", "doc3"],
    documents=[
        "Annual subscriptions cancelled after 30 days are non-refundable.",
        "Support tickets are answered within 24 hours on business days.",
        "API access is included in all plans above Starter tier.",
    ],
    metadatas=[
        {"source": "refund_policy.pdf", "section": "4.2", "dept": "legal"},
        {"source": "sla.pdf", "section": "2.1", "dept": "support"},
        {"source": "pricing.pdf", "section": "3.0", "dept": "product"},
    ]
)

# Query — returns top-2 most similar chunks
results = collection.query(
    query_texts=["What happens if I cancel my subscription?"],
    n_results=2,
    where={"dept": "legal"}  # metadata filter — only search legal docs
)
for doc, meta, dist in zip(results['documents'][0], results['metadatas'][0], results['distances'][0]):
    print(f"Score: {1-dist:.3f} | Source: {meta['source']} | {doc[:80]}...")

qdrant_production.py — production-ready with quantization

Python
from qdrant_client import QdrantClient
from qdrant_client.models import (
    Distance, VectorParams, PointStruct,
    ScalarQuantization, ScalarQuantizationConfig, ScalarType,
    Filter, FieldCondition, MatchValue
)
from sentence_transformers import SentenceTransformer

client = QdrantClient(url="http://localhost:6333")  # or use qdrant.tech API key
model = SentenceTransformer("BAAI/bge-large-en-v1.5")

# Create collection with scalar quantization (4× memory reduction)
client.create_collection(
    collection_name="rag_docs",
    vectors_config=VectorParams(size=1024, distance=Distance.COSINE),
    quantization_config=ScalarQuantization(
        scalar=ScalarQuantizationConfig(
            type=ScalarType.INT8,   # float32 → int8: 4× smaller
            quantile=0.99,         # clip 1% outliers for better quantization
            always_ram=True         # keep quantized index in RAM for speed
        )
    )
)

# Batch upsert (efficient for large ingestion)
docs = [
    ("refund_001", "Annual subscriptions cancelled after 30 days are non-refundable.", {"source": "tos.pdf", "dept": "legal"}),
    ("support_001", "Support tickets answered within 24 hours on business days.", {"source": "sla.pdf", "dept": "support"}),
]
embeddings = model.encode([d[1] for d in docs], normalize_embeddings=True)

client.upsert(
    collection_name="rag_docs",
    points=[
        PointStruct(id=i, vector=emb.tolist(), payload={"text": doc[1], **doc[2]})
        for i, (doc, emb) in enumerate(zip(docs, embeddings))
    ]
)

# Query with metadata filter
query_emb = model.encode(["refund policy"], normalize_embeddings=True)[0]
results = client.search(
    collection_name="rag_docs",
    query_vector=query_emb.tolist(),
    query_filter=Filter(must=[FieldCondition(key="dept", match=MatchValue(value="legal"))]),
    limit=3,
    with_payload=True
)
for r in results:
    print(f"Score: {r.score:.4f} | {r.payload['text'][:80]}")
