Medical Records and Clinical Documents
Clinical NER · Section Detection · Medication Attributes · ICD-10 · HIPAA De-identification

Clinical documents are among the most complex and highest-stakes documents a pipeline must process. Discharge summaries, radiology reports, operative notes, and progress notes each have distinct vocabulary, style, and entity type distributions that break cross-domain NER models. This module covers clinical section detection with alias dictionaries, medication attribute extraction beyond entity span detection, ICD-10 code suggestion with condition-complication relationship extraction, HIPAA de-identification with precise PHI category rules, and the domain shift patterns that cause models trained on discharge summaries to fail on radiology reports.

01 · Clinical Document Types and Section Detection

Alias Dictionaries for Closed-Vocabulary
Section Heading Detection

clinical_sections.py — section detection with alias dictionary

import re
from dataclasses import dataclass

SECTION_ALIASES = {
    "chief_complaint":    [rr"chief\s+complaint\s*:?", rr"cc\s*:"],
    "history":            [rr"(?:history\s+of\s+present\s+illness|hpi)\s*:?",
                           rr"history\s*:"],
    "medications":        [rr"(?:current\s+)?medications?\s*:?", rr"meds\s*:"],
    "assessment_plan":    [rr"assessment\s+(?:and|&|/)\s+plan\s*:?",
                           rr"a\s*[&/]\s*p\s*:", rr"assessment\s*:"],
    "physical_exam":      [rr"(?:physical\s+exam(?:ination)?|pe)\s*:?"],
    "discharge_diagnosis":[rr"(?:discharge\s+)?diagnos[ei]s\s*:?", rr"dx\s*:"],
    "vitals":             [rr"(?:vital\s+signs?|vitals?)\s*:?", rr"vs\s*:"],
    "plan":               [rr"(?:treatment\s+)?plan\s*:"],
}

COMPILED = {
    name: [re.compile(p, re.IGNORECASE) for p in patterns]
    for name, patterns in SECTION_ALIASES.items()
}

@dataclass
class ClinicalSection:
    name: str; start: int; end: int; text: str

def detect_sections(text: str) -> list[ClinicalSection]:
    """
    Detect clinical note sections using alias dictionary.
    Sections are delimited by heading matches at line start.
    This approach outperforms fuzzy matching (false positives on content words)
    and ML (requires annotated training data for a rule-based problem).
    """
    hits = []
    for name, patterns in COMPILED.items():
        for pattern in patterns:
            for m in pattern.finditer(text):
                # Only count matches at start of line
                line_start = text.rfind("
", 0, m.start()) + 1
                preceding  = text[line_start:m.start()].strip()
                if not preceding: hits.append((m.start(), name, m.end()))
    hits.sort(key=lambda x: x[0])
    sections = []
    for i, (start, name, hend) in enumerate(hits):
        end = hits[i+1][0] if i+1 < len(hits) else len(text)
        sections.append(ClinicalSection(name, start, end, text[hend:end].strip()))
    return sections
02 · Medication Extraction with Attributes

Drug Name, Dose, Unit, Route, Frequency —
Relation Extraction Beyond NER

medication_extractor.py

import re
from dataclasses import dataclass
from typing import Optional

@dataclass
class MedicationRecord:
    drug:       str
    dose:       Optional[str]
    unit:       Optional[str]
    route:      Optional[str]
    frequency:  Optional[str]
    raw_text:   str

DOSE_PATTERN = re.compile(
    rr"(\d+(?:\.\d+)?)\s*(mg|mcg|g|ml|units?|IU|mmol)", re.IGNORECASE)
ROUTE_PATTERN = re.compile(
    rr"(oral(?:ly)?|IV|intravenous(?:ly)?|SC|subcutaneous(?:ly)?|"
    rr"IM|intramuscular(?:ly)?|topical(?:ly)?|inhaled?)", re.IGNORECASE)
FREQ_PATTERN = re.compile(
    rr"(once|twice|three\s+times|four\s+times|"
    rr"\d+\s*x?\s*(?:daily|a\s+day)|(?:every|q)\s*\d+\s*h(?:ours?)?|"
    rr"OD|BD|TDS|QDS|PRN|as\s+needed)", re.IGNORECASE)

def extract_medication_attributes(drug_span: str,
                                    context: str,
                                    window: int = 60) -> MedicationRecord:
    """
    Extract medication attributes from context window around the drug span.
    Standard NER detects the drug span; this function extracts structured
    attributes (dose, unit, route, frequency) from the surrounding tokens.
    window: character radius around drug span to search for attributes.
    """
    dm = DOSE_PATTERN.search(context)
    rm = ROUTE_PATTERN.search(context)
    fm = FREQ_PATTERN.search(context)
    return MedicationRecord(
        drug      = drug_span,
        dose      = dm.group(1) if dm else None,
        unit      = dm.group(2) if dm else None,
        route     = rm.group() if rm else None,
        frequency = fm.group() if fm else None,
        raw_text  = context)
03 · ICD-10 Code Suggestion and HIPAA De-identification

Condition-Complication Extraction and
Precise PHI Category Rules

clinical_coding.py — ICD-10 suggestion and HIPAA de-id

import re
from sentence_transformers import SentenceTransformer
import numpy as np

def suggest_icd10(clinical_phrase: str,
                   icd10_descriptions: list[tuple[str,str]],
                   model: SentenceTransformer,
                   top_k: int = 5) -> list[dict]:
    """
    Suggest ICD-10 codes by embedding similarity.
    Handles condition-complication phrases that keyword lookup misses:
    "T2DM with nephropathy" matches E11.65, not E11.9 (without complications).
    icd10_descriptions: list of (code, description) pairs.
    """
    codes   = [d[0] for d in icd10_descriptions]
    descs   = [d[1] for d in icd10_descriptions]
    query   = model.encode(clinical_phrase)
    corpus  = model.encode(descs)
    scores  = np.dot(corpus, query) / (
              np.linalg.norm(corpus,axis=1)*np.linalg.norm(query)+1e-8)
    top_idx = np.argsort(scores)[::-1][:5]
    return [{"code":codes[i],"description":descs[i],
              "score":round(float(scores[i]),3)} for i in top_idx]

# HIPAA Safe Harbor PHI de-identification rules
DATE_PATTERN = re.compile(
    rr"(\d{1,2})[/\-\.](\d{1,2})[/\-\.](\d{4})")
AGE_PATTERN  = re.compile(
    rr"(\d{1,3})\s*(?:y/?o|year[s\-]old|yo)", re.IGNORECASE)

def hipaa_deidentify(text: str) -> str:
    """
    HIPAA Safe Harbor de-identification:
    - Dates: reduce to year only (redact day + month)
    - Ages >= 90: replace with "[AGE 90+]"; ages < 90: retain
    - Sex, race, clinical findings: not PHI, retain
    Does NOT redact ages < 90 — a common over-redaction error.
    """
    # Reduce dates to year only
    text = DATE_PATTERN.sub(lambda m: m.group(3), text)
    # Redact ages >= 90; retain ages < 90
    def age_handler(m):
        age = int(m.group(1))
        return "[AGE 90+]" if age >= 90 else m.group()
    return AGE_PATTERN.sub(age_handler, text)
04 · Assessment

Module 14 Quiz

1. Your clinical NER model trained on i2b2 discharge summaries achieves NER F1=0.89 on the test set. Deployed on radiology reports, F1 drops to 0.61. Two root causes and fastest fix?

Correct. Telegraphic style mismatch and entity type distribution shift are the two independent causes that compound to produce the large F1 gap. Both require radiology-specific annotated examples — there is no preprocessing that converts telegraphic radiology prose to the narrative style the model was trained on.

2. section_detector() must identify "Assessment and Plan" in clinical notes. Some notes have "A&P", others "Assessment/Plan", others "ASSESSMENT AND PLAN". What is the correct detection approach?

Correct. Clinical section headings form a closed vocabulary per note type — a regex alias dictionary is the correct approach because it is deterministic, interpretable, and does not require training data. The dictionary approach outperforms fuzzy matching (which generates false positives on content words) and ML (which requires annotated training data for a rule-based problem).

3. map_to_icd10() must code "Type 2 diabetes mellitus with diabetic nephropathy" to ICD-10. A keyword lookup returns E11.9 (T2DM without complications). What is wrong?

Correct. ICD-10 specificity requires matching the full clinical phrase including complications and manifestations — keyword lookup on the primary condition alone consistently produces the "without complications" catch-all code. Structured condition-complication extraction followed by embedding-based retrieval is the standard approach for automated ICD-10 suggestion systems.

4. Your de-identification pipeline for HIPAA Safe Harbor must handle "pt is a 67 y/o male admitted 3/15/2024 with chest pain." What must be redacted and what can be retained?

Correct. HIPAA Safe Harbor has precise rules: dates reduced to year only (day+month are PHI); ages under 90 are not PHI; sex is not PHI. A naive "redact all numbers" approach over-redacts age values. Medical context NER that distinguishes dates from ages is the required capability.

5. extract_medications() must extract "metformin 500mg twice daily" from a clinical note and return drug name, dose, unit, and frequency. It extracts drug="metformin" but returns dose=None. What is missing?

Correct. Medication attribute extraction requires relation extraction beyond entity span detection. Standard NER identifies the drug entity; a medication-specific attribute extractor links dose, unit, route, and frequency to the drug as structured attributes. MedSpaCy and regex-based attribute extraction within the drug span window are both valid production approaches.
