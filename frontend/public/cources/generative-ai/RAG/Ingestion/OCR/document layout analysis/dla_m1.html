01 · Projection Profiles

Summing Pixels Across Rows and Columns
to Find Whitespace Boundaries

A horizontal projection profile sums the number of foreground (dark) pixels in each row. A vertical profile sums per column. Valleys — rows or columns with few or zero dark pixels — correspond to whitespace separators between text lines, paragraphs, and columns. This is the oldest and still most robust method for detecting major layout boundaries in typed documents.

projection_profile.py

import cv2, numpy as np

def binarise(img: np.ndarray) -> np.ndarray:
    """Otsu binarisation → dark text on white bg becomes 1s on 0s."""
    grey = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) if img.ndim == 3 else img
    _, binary = cv2.threshold(grey, 0, 255, cv2.THRESH_BINARY+cv2.THRESH_OTSU)
    return cv2.bitwise_not(binary) // 255

def horizontal_profile(binary: np.ndarray) -> np.ndarray:
    """Dark pixels per row. Valleys = line/paragraph separators."""
    return binary.sum(axis=1).astype(np.int32)

def vertical_profile(binary: np.ndarray) -> np.ndarray:
    """Dark pixels per column. Valleys = column separators."""
    return binary.sum(axis=0).astype(np.int32)

def find_valleys(profile: np.ndarray,
                  min_run: int = 5,
                  threshold: int = 2) -> list:
    """
    Find contiguous runs where profile values are <= threshold.
    min_run: minimum run length to count as a separator.
    Returns list of (start, end) index pairs.
    """
    in_v = False; start = 0; valleys = []
    for i, v in enumerate(profile):
        if v <= threshold and not in_v: start = i; in_v = True
        elif v > threshold and in_v:
            if i - start >= min_run: valleys.append((start, i))
            in_v = False
    if in_v and len(profile)-start >= min_run: valleys.append((start,len(profile)))
    return valleys

def segment_lines(binary: np.ndarray, min_gap: int = 5) -> list:
    """Segment text lines using horizontal projection profile."""
    hp    = horizontal_profile(binary)
    cuts  = [0] + [(s+e)//2 for s,e in find_valleys(hp, min_gap, 0)] + [binary.shape[0]]
    return [(cuts[i], cuts[i+1]) for i in range(len(cuts)-1)
            if hp[cuts[i]:cuts[i+1]].sum() > 0]
02 · X-Y Cut Algorithm

Recursive Page Decomposition
Into a Binary Tree of Zones

The X-Y cut algorithm recursively decomposes a page by finding the widest whitespace gap, cutting there, and repeating on each sub-region. Cutting alternates between horizontal (creating top/bottom regions) and vertical (creating left/right regions). The result is a binary tree where leaves are document zones ready for OCR.

xy_cut.py

from dataclasses import dataclass, field
from typing import Optional
import numpy as np

@dataclass
class ZoneNode:
    x1: int; y1: int; x2: int; y2: int
    children: list = field(default_factory=list)
    is_leaf: bool  = True

def find_best_cut(binary: np.ndarray, axis: int,
                   min_gap: int = 10) -> Optional[int]:
    """
    Find the widest whitespace valley along the requested axis.
    axis=0: horizontal cut → search vertical profile (column sums)
    axis=1: vertical cut   → search horizontal profile (row sums)
    Returns midpoint of widest valley or None.
    IMPORTANT: profile axis = 1-axis (sum perpendicular to cut direction)
    """
    profile = binary.sum(axis=1-axis).astype(np.int32)
    valleys = find_valleys(profile, min_run=min_gap, threshold=1)
    if not valleys: return None
    widest = max(valleys, key=lambda v: v[1]-v[0])
    return (widest[0]+widest[1])//2

def xy_cut(binary: np.ndarray, x1: int, y1: int,
            min_h: int = 30, min_w: int = 30,
            depth: int = 0, max_depth: int = 10) -> ZoneNode:
    """
    Recursive X-Y cut. Alternates H cut (even depth) and V cut (odd depth).
    Returns tree of ZoneNodes; leaves are document segments.
    """
    h, w = binary.shape
    node = ZoneNode(x1, y1, x1+w, y1+h)
    if depth >= max_depth or h < min_h or w < min_w: return node
    axis = depth % 2
    cut  = find_best_cut(binary, axis)
    if cut is None: return node
    node.is_leaf = False
    if axis == 0:   # horizontal: top / bottom
        node.children = [
            xy_cut(binary[:cut,:], x1,    y1,    min_h,min_w,depth+1,max_depth),
            xy_cut(binary[cut:,:], x1,    y1+cut,min_h,min_w,depth+1,max_depth)]
    else:           # vertical: left / right
        node.children = [
            xy_cut(binary[:,:cut], x1,    y1,    min_h,min_w,depth+1,max_depth),
            xy_cut(binary[:,cut:], x1+cut,y1,    min_h,min_w,depth+1,max_depth)]
    return node

def get_leaves(node: ZoneNode) -> list:
    return [node] if node.is_leaf else [l for c in node.children for l in get_leaves(c)]
03 · Run-Length Smearing (RLSA)

Merging Character Blobs Into
Text Block Regions

rlsa.py

import cv2, numpy as np

def run_length_smear(binary: np.ndarray,
                      h_smear: int = 40,
                      v_smear: int = 10) -> np.ndarray:
    """
    Fill horizontal gaps of <= h_smear pixels between foreground runs.
    Fill vertical gaps of <= v_smear pixels between foreground runs.
    Result: characters within a text block merge into a single blob.

    Calibration rule:
    h_smear > max inter-word gap (15-25px at 300 DPI)  [merge words]
    h_smear < min inter-column gap (40-80px at 300 DPI) [keep columns]
    v_smear > max inter-line whitespace gap             [merge lines]
    v_smear < min inter-paragraph gap                   [keep paragraphs]
    """
    smeared = binary.copy()
    h, w = smeared.shape
    for row in range(h):
        last_fg = gap_start = -1
        for col in range(w):
            if smeared[row,col]:
                if gap_start >= 0 and col-gap_start <= h_smear:
                    smeared[row,gap_start:col] = 1
                last_fg = col; gap_start = col+1
            elif last_fg >= 0 and gap_start < 0: gap_start = col
    for col in range(w):
        last_fg = gap_start = -1
        for row in range(h):
            if smeared[row,col]:
                if gap_start >= 0 and row-gap_start <= v_smear:
                    smeared[gap_start:row,col] = 1
                last_fg = row; gap_start = row+1
            elif last_fg >= 0 and gap_start < 0: gap_start = row
    return smeared

def extract_text_blocks(binary, h_smear=40, v_smear=10, min_area=500):
    smeared = run_length_smear(binary, h_smear, v_smear)
    n,_,stats,_ = cv2.connectedComponentsWithStats((smeared*255).astype(np.uint8))
    return sorted([(s[0],s[1],s[2],s[3]) for s in stats[1:] if s[4]>=min_area],
                   key=lambda b:(b[1],b[0]))
04 · Morphological Dilation and Rule-Based Classification

Structuring Element Tuning and
Multi-Feature Heuristic Classification

morphological_layout.py

import cv2, numpy as np

def morph_extract_blocks(binary, h_dilate=50, v_dilate=8, min_area=1000):
    """
    Morphological dilation + connected components.
    h_dilate: wide horizontal kernel merges characters within a line.
    v_dilate: narrow vertical kernel merges adjacent lines into paragraphs.
    Simpler than RLSA but less controllable for mixed-layout documents.
    """
    u8 = (binary*255).astype(np.uint8)
    kh = cv2.getStructuringElement(cv2.MORPH_RECT, (h_dilate, 1))
    kv = cv2.getStructuringElement(cv2.MORPH_RECT, (1, v_dilate))
    dilated = cv2.dilate(cv2.dilate(u8, kh), kv)
    n,_,stats,_ = cv2.connectedComponentsWithStats(dilated)
    return [(s[0],s[1],s[2],s[3]) for s in stats[1:] if s[4]>=min_area]

def classify_block(x,y,w,h, page_w,page_h, median_font_h,
                    ink_density: float = 0.0) -> str:
    """
    Multi-feature heuristic classification.
    Uses position, aspect ratio, font-relative height, AND ink density.
    ink_density: mean foreground pixel fraction in original binary block.
    Low ink density (<0.05) = likely figure/whitespace area.
    High ink density (>0.1) = text (uniformly dense).
    """
    rel_y   = y / page_h
    aspect  = w / max(h, 1)
    height_r = h / max(median_font_h, 1)

    if rel_y < 0.06 and h/page_h < 0.06: return "header"
    if rel_y > 0.92 and h/page_h < 0.06: return "footer"
    if height_r > 1.8 and aspect > 3:       return "title"
    if ink_density < 0.05:                   return "figure"   # sparse = non-text
    if aspect < 1.5 and ink_density < 0.08: return "figure"   # narrow+sparse
    if h/page_h < 0.04 and aspect > 8:     return "separator"
    return "text"
05 · When Classical Methods Win

Structured Document Types Where
Heuristics Beat Neural Models

Classical methods outperform on

Fixed-template documents. Tax forms, government filings, standard contracts — a coordinate-based zone extractor outperforms any neural model with zero training data.
High-quality typed documents. Clean 300+ DPI scans of typeset text. Projection profiles find line boundaries with sub-pixel precision that neural models cannot match.
Interpretable failure modes. Classical method failures are inspectable — you see exactly why in the projection profile. Neural failures are opaque, which matters in regulated industries.
Low compute environments. RLSA and morphological dilation run in milliseconds on CPU. Neural layout models require GPU for real-time throughput.

Classical methods fail on

Complex mixed layouts. Magazine pages, scientific papers with irregular figure placement — geometric heuristics cannot generalise.
Degraded or noisy scans. Bleed-through, skew, shadows — projection profiles become noisy and valley detection fails.
Fine-grained classification. Distinguishing caption from footnote from sidebar by geometry alone — these require content-aware classification.
06 · Assessment

Module 1 Quiz

1. find_valleys() is called with threshold=2. A row has profile value 3. Is it inside a valley?

Correct. The threshold in find_valleys() is a strict pixel count ceiling. A row is in a valley if and only if its profile value is less than or equal to threshold. Value 3 > 2 breaks the valley. To tolerate noisy scans with sparse dark pixels in whitespace rows, increase threshold — but this risks merging regions that should be separate.

2. xy_cut() at depth=1 finds a horizontal cut when it should find the vertical column separator. The depth%2 rule sets axis=1 (vertical) at depth=1. What is the bug?

Correct. The axis inversion bug is subtle: binary.sum(axis=1-axis) inverts the intended axis, causing the algorithm to always analyse horizontal gaps regardless of the depth-alternating axis variable. The fix (binary.sum(axis=axis)) correctly aligns the profile computation with the cut direction.

3. run_length_smear() is called with h_smear=40 on a page where two text columns are separated by a 45px gap. What happens?

Correct. h_smear=40 with a 45px column gap means the columns remain correctly separated. The critical calibration principle is that h_smear must sit between the maximum inter-word spacing (to merge words) and the minimum inter-column spacing (to avoid merging columns). Violating this — setting h_smear too large — is the most common RLSA failure mode.

4. classify_block_heuristic() labels a narrow sidebar text column as "figure" because its w/h aspect ratio is below 1.5. What is the fundamental limitation?

Correct. Single-feature geometric classifiers fail because the feature distributions of different region types overlap. A narrow sidebar text column and a portrait-format figure both have low aspect ratios. Robust rule-based classification requires multiple features from different signal types — geometry, texture, and ink density — and even then fails on unusual document designs. This is the primary motivation for learning-based layout classification.

5. You want to use projection profile-based line segmentation on a page with a heading that uses 24pt font and body text at 10pt. The body line spacing is 14px and the heading line spacing is 35px at 300 DPI. What min_run value in find_valleys() correctly segments both heading and body lines?

Correct. The distinction between line spacing (full height including text) and inter-line whitespace gap (whitespace between text rows only) is critical. Body text at 14px line spacing has only 2-5px of actual whitespace between lines. min_run must be smaller than the minimum actual whitespace gap — setting it to the line spacing value (14px) would miss most body text inter-line separators entirely.
