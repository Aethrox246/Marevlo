The ReAct Loop

Three nodes. One feedback cycle. The architectural primitive of every agent you will ever build.

THOUGHT
ACTION
OBSERVE
ANSWER
THOUGHT
The LLM reasons about what to do next — given the goal and what it's seen so far.
ACTION
The LLM emits a structured tool call. The runtime executes it deterministically.
OBSERVE
Tool result is fed back. The LLM updates state. Loop continues — or terminates.

Pseudo-code only — you build the real thing in Module 0.2. This is the mental model.

# Module 0.0 — The ReAct loop in 12 lines.
# Course 02 / Track 0 — conceptual scaffold.

def react_loop(goal, tools, max_steps=10):
    history = []
    for step in range(max_steps):
        thought, action = llm.decide(goal, history, tools)

        if action.name == "final_answer":
            return action.args["answer"]

        observation = tools[action.name].run(**action.args)
        history.append((thought, action, observation))

    raise RuntimeError("agent exceeded step budget")
// STEP 01
THOUGHT → "I need the user's order status. I'll query the CRM first."
ACTION  → crm_lookup(user_id="U-9214")
OBSERVE → { orders: ["ORD-7711"], tier: "gold" }

// STEP 02
THOUGHT → "Order found. Check shipping status."
ACTION  → shipping_status(order_id="ORD-7711")
OBSERVE → { status: "delayed", eta: "+3d" }

// STEP 03
THOUGHT → "Gold tier + delay. Policy permits refund offer."
ACTION  → final_answer(answer="...refund offered...")

// 08 — DOWNLOAD SUMMARY

Key Takeaways

TAKEAWAY 01

A RAG pipeline has a hardcoded shape. An agent emits its own shape at run-time.

TAKEAWAY 02

The ReAct loop — Thought → Action → Observation — is the primitive every framework builds on.

TAKEAWAY 03

If you can draw the flowchart in advance, use a workflow. Agents are for the cases you can't.

TAKEAWAY 04

Agents pay 10–100× more in tokens and latency than equivalent workflows. Justify the spend.

TAKEAWAY 05

This course is layered: foundations → building → eval → production → capstone. Sequential by design.

TAKEAWAY 06

The MCP Course is a companion. Module 2.6 is the bridge. You don't need it today — you will later.
