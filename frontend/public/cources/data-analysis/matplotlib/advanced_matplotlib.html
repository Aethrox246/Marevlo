🌈 Colored Scatter Plots

Scatter plots can represent up to 5 dimensions simultaneously: x-axis, y-axis, color, size, and marker style. This enables rich, multi-dimensional data visualization.

Customer Segmentation Analysis

Input 
# Create synthetic customer data for analysis
np.random.seed(42)
n_customers = 150

customer_data = pd.DataFrame({
    'customer_id': range(1, n_customers + 1),
    'annual_income': np.random.normal(50000, 15000, n_customers),
    'spending_score': np.random.normal(50, 20, n_customers),
    'age': np.random.normal(35, 10, n_customers),
    'segment': np.random.choice(['Low Value', 'Medium Value', 'High Value'], 
                                n_customers, p=[0.3, 0.5, 0.2])
})

# Map segments to numeric values for coloring
segment_mapping = {'Low Value': 0, 'Medium Value': 1, 'High Value': 2}
customer_data['segment_code'] = customer_data['segment'].map(segment_mapping)

Creating Color-Mapped Scatter Plot

Input 
# Create a colored scatter plot with colormap
plt.figure(figsize=(12, 7))
scatter = plt.scatter(customer_data['annual_income'], 
                      customer_data['spending_score'],
                      c=customer_data['segment_code'], 
                      cmap='viridis',  # Color map
                      alpha=0.7, 
                      s=80,
                      edgecolors='black',
                      linewidth=0.5)

plt.xlabel('Annual Income ($)', fontsize=12, fontweight='bold')
plt.ylabel('Spending Score (1-100)', fontsize=12, fontweight='bold')
plt.title('Customer Segmentation Analysis', fontsize=14, fontweight='bold')
colorbar = plt.colorbar(scatter, label='Segment (0=Low, 1=Medium, 2=High)')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
💡 Pro Tip: The cmap parameter controls the color palette. Popular options include 'viridis', 'plasma', 'cool', 'hot', 'jet', and 'RdYlGn'. Choose colormaps that are colorblind-friendly when presenting to diverse audiences.

Available Color Maps

Category Color Maps Best For
Perceptual viridis, plasma, inferno, magma General purpose, colorblind-friendly
Sequential Blues, Greens, Reds, Purples Ordered data (low to high)
Diverging RdBu, RdYlGn, BrBG, PiYG Centered data (positive/negative)
Qualitative Set1, Set2, Pastel1, Pastel2 Categorical data

📐 Controlling Plot Size

The size of your figure is crucial for readability and professional presentation. The figsize parameter controls plot dimensions in inches.

Basic Size Control

Input 
# Controlling plot size with figsize parameter
# figsize=(width, height) in inches
# DPI (dots per inch) affects resolution

# Small plot - good for inline viewing
plt.figure(figsize=(8, 5))
plt.scatter(customer_data['annual_income'], customer_data['spending_score'],
           c=customer_data['segment_code'], cmap='plasma', 
           alpha=0.8, s=60, edgecolors='black', linewidth=0.5)
plt.xlabel('Annual Income ($)', fontsize=11)
plt.ylabel('Spending Score (1-100)', fontsize=11)
plt.title('Customer Analysis - Small Format', fontsize=13)
plt.colorbar(label='Segment')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Large plot - good for presentations
plt.figure(figsize=(16, 10), dpi=150)
plt.scatter(customer_data['annual_income'], customer_data['spending_score'],
           c=customer_data['segment_code'], cmap='plasma', 
           alpha=0.8, s=100, edgecolors='black', linewidth=1)
plt.xlabel('Annual Income ($)', fontsize=14)
plt.ylabel('Spending Score (1-100)', fontsize=14)
plt.title('Customer Analysis - Large Format', fontsize=16, fontweight='bold')
plt.colorbar(label='Customer Segment')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
💡 Pro Tip: Use plt.tight_layout() to prevent labels from being cut off. For presentations, use DPI >= 150. For print, use DPI >= 300.

Common Figure Sizes

📱 Mobile/Small Screens

figsize=(8, 5) - Standard aspect ratio for presentations

🖥️ Laptop Displays

figsize=(12, 7) - Good for web and inline viewing

🎬 Widescreen Presentation

figsize=(16, 9) - 16:9 aspect ratio for slide decks

📄 Publication/Print

figsize=(10, 8) - High DPI for paper quality

📝 Annotations

Annotations help identify and highlight specific data points. Use them strategically to tell a story with your data.

Employee Performance Dataset

Input 
# Create employee performance dataset
np.random.seed(42)
n_employees = 50

employees = pd.DataFrame({
    'employee_id': range(1, n_employees + 1),
    'name': [f'Employee_{i}' for i in range(1, n_employees + 1)],
    'productivity_score': np.random.normal(75, 15, n_employees),
    'efficiency_rating': np.random.normal(80, 12, n_employees),
    'performance_points': np.random.normal(150, 40, n_employees)
})

# Clip values to reasonable ranges
employees['productivity_score'] = np.clip(employees['productivity_score'], 30, 100)
employees['efficiency_rating'] = np.clip(employees['efficiency_rating'], 40, 100)
employees['performance_points'] = np.clip(employees['performance_points'], 50, 250)

Text Annotations with Boxes

Input 
# Select top performers for annotation
sample_df = employees.nlargest(10, 'performance_points')

plt.figure(figsize=(14, 9))
# Bubble plot: size = performance_points
scatter = plt.scatter(employees['productivity_score'], 
                      employees['efficiency_rating'],
                      s=50, alpha=0.6, c='lightblue', 
                      edgecolors='navy', linewidth=1)

# Annotate top performers
for idx, row in sample_df.iterrows():
    plt.text(row['productivity_score'], 
             row['efficiency_rating'],
             row['name'],
             fontsize=9, ha='center', va='bottom',
             bbox=dict(boxstyle='round,pad=0.3', 
                      facecolor='yellow', alpha=0.7))

plt.title('Top Employee Performance Analysis', fontsize=14, fontweight='bold')
plt.xlabel('Productivity Score', fontsize=12)
plt.ylabel('Efficiency Rating', fontsize=12)
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

Advanced Text Annotations

Input 
# Various annotation styles and box types
fig, ax = plt.subplots(figsize=(12, 8))

x = [1, 2, 3, 4, 5]
y = [5, 6, 7, 8, 9]

ax.scatter(x, y, s=150, c='#3b82f6', alpha=0.8, edgecolors='navy', linewidth=2)

# Different text annotation styles
styles = [
    ('round', 'Point 1', 'yellow'),
    ('round,pad=0.5', 'Point 2', 'lightgreen'),
    ('square', 'Point 3', 'lightcoral'),
    ('round,pad=0.3,rounding_size=0.2', 'Point 4', 'lightblue'),
    ('round,pad=0.7', 'Point 5', 'lightyellow'),
]

for (style, text, color), xi, yi in zip(styles, x, y):
    ax.text(xi, yi + 0.3, text, fontsize=11, color='#1a1a1a', 
            fontweight='bold', ha='center',
            bbox=dict(boxstyle=style, facecolor=color, alpha=0.8, 
                     edgecolor='black', linewidth=1.5))

ax.set_xlim(0.5, 5.5)
ax.set_ylim(4.5, 10)
ax.set_xlabel('X Values', fontsize=12)
ax.set_ylabel('Y Values', fontsize=12)
ax.set_title('Text Annotation Styles', fontsize=14, fontweight='bold')
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

📏 Reference Lines

Horizontal and vertical reference lines help highlight thresholds, targets, or important benchmarks in your data.

Performance Thresholds

Input 
# Create scatter plot with reference lines for performance thresholds
fig, ax = plt.subplots(figsize=(14, 9))

# Sample subset for clearer visualization
sample_df = employees.sample(30, random_state=42)

ax.scatter(sample_df['productivity_score'], 
          sample_df['efficiency_rating'],
          s=sample_df['performance_points'], 
          alpha=0.7, c='lightgreen',
          edgecolors='darkgreen', linewidth=1.5)

# Add horizontal reference lines (efficiency thresholds)
ax.axhline(y=85, color='red', linestyle='--', linewidth=2.5, 
          label='High Performance Threshold', alpha=0.7)
ax.axhline(y=70, color='orange', linestyle='--', linewidth=2.5, 
          label='Medium Performance Threshold', alpha=0.7)

# Add vertical reference lines (productivity targets)
ax.axvline(x=80, color='blue', linestyle='-.', linewidth=2.5, 
          label='Productivity Target', alpha=0.7)

# Fill regions between lines for clarity
ax.fill_between(ax.get_xlim(), 70, 85, alpha=0.1, color='yellow', label='Target Zone')

ax.set_title('Employee Performance Analysis with Reference Lines', 
            fontsize=14, fontweight='bold')
ax.set_xlabel('Productivity Score', fontsize=12)
ax.set_ylabel('Efficiency Rating', fontsize=12)
ax.legend(loc='upper left', fontsize=10, framealpha=0.95)
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
💡 Pro Tip: Use different line styles (solid `-`, dashed `--`, dotted `:`, dash-dot `-.`) to distinguish between different types of thresholds. Add transparency with alpha to prevent reference lines from overwhelming the data.

📊 Subplots

Subplots allow you to create multiple plots in a single figure, enabling comprehensive multi-view analysis.

2x1 Subplot Layout

Input 
# Create 2 subplots with shared x-axis
fig, ax = plt.subplots(nrows=2, ncols=1, sharex=True, figsize=(12, 10))

# Top subplot: Productivity vs Efficiency
ax[0].scatter(employees['productivity_score'], 
             employees['efficiency_rating'],
             color='#3b82f6', alpha=0.7, s=80, edgecolors='navy', linewidth=1)
ax[0].set_title('Productivity vs Efficiency', fontsize=12, fontweight='bold')
ax[0].set_ylabel('Efficiency Rating', fontsize=11)
ax[0].grid(True, alpha=0.3)

# Bottom subplot: Productivity vs Performance Points
ax[1].scatter(employees['productivity_score'], 
             employees['performance_points'],
             color='#10b981', alpha=0.7, s=80, edgecolors='darkgreen', linewidth=1)
ax[1].set_title('Productivity vs Performance Points', fontsize=12, fontweight='bold')
ax[1].set_ylabel('Performance Points', fontsize=11)
ax[1].set_xlabel('Productivity Score', fontsize=11)
ax[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

2x2 Subplot Grid

Input 
# Create 2x2 grid of subplots showing different employee metrics
fig, ax = plt.subplots(nrows=2, ncols=2, figsize=(14, 10))

# Top-left: Productivity distribution
ax[0,0].hist(employees['productivity_score'], bins=15, 
            alpha=0.8, color='#3b82f6', edgecolor='black')
ax[0,0].set_title('Productivity Score Distribution', fontweight='bold')
ax[0,0].set_xlabel('Productivity Score')
ax[0,0].set_ylabel('Frequency')
ax[0,0].grid(True, alpha=0.3, axis='y')

# Top-right: Efficiency distribution
ax[0,1].hist(employees['efficiency_rating'], bins=15, 
            alpha=0.8, color='#10b981', edgecolor='black')
ax[0,1].set_title('Efficiency Rating Distribution', fontweight='bold')
ax[0,1].set_xlabel('Efficiency Rating')
ax[0,1].set_ylabel('Frequency')
ax[0,1].grid(True, alpha=0.3, axis='y')

# Bottom-left: Scatter plot
ax[1,0].scatter(employees['productivity_score'], 
               employees['efficiency_rating'],
               color='#f59e0b', alpha=0.7, s=60, edgecolors='darkgoldenrod')
ax[1,0].set_title('Productivity vs Efficiency', fontweight='bold')
ax[1,0].set_xlabel('Productivity Score')
ax[1,0].set_ylabel('Efficiency Rating')
ax[1,0].grid(True, alpha=0.3)

# Bottom-right: Box plot
data_to_plot = [employees['productivity_score'], 
               employees['efficiency_rating'],
               employees['performance_points'] / 20]
ax[1,1].boxplot(data_to_plot, labels=['Productivity', 'Efficiency', 'Performance/20'])
ax[1,1].set_title('Metrics Comparison - Box Plot', fontweight='bold')
ax[1,1].set_ylabel('Score')
ax[1,1].grid(True, alpha=0.3, axis='y')

plt.tight_layout()
plt.show()

✨ Best Practices

📋 Visualization Checklist

✅ Clarity

  • Clear title and axis labels
  • Appropriate font sizes
  • Minimal clutter

✅ Accuracy

  • True to data scale
  • No misleading colors
  • Proper axis ranges

✅ Accessibility

  • Colorblind-friendly palettes
  • High contrast
  • Readable fonts

✅ Design

  • Consistent styling
  • Professional appearance
  • Proper whitespace

📌 Common Mistakes to Avoid

❌ Too Many Colors: Limit your color palette to 3-5 distinct colors for clarity.
❌ No Legend: Always include a legend when using multiple series or color maps.
❌ Misleading Scales: Start y-axis at 0 unless there's a compelling reason otherwise.
❌ Overcrowding: Don't try to show too much data at once. Use subplots if needed.

Complete Example: Professional Workflow

Input 
# Professional matplotlib workflow
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# 1. Prepare data
np.random.seed(42)
data = pd.DataFrame({
    'x': np.random.normal(50, 15, 100),
    'y': np.random.normal(75, 20, 100),
    'category': np.random.choice(['A', 'B', 'C'], 100)
})

# 2. Create figure with specific size and DPI
fig, ax = plt.subplots(figsize=(12, 7), dpi=150)

# 3. Plot with proper styling
for category in data['category'].unique():
    subset = data[data['category'] == category]
    ax.scatter(subset['x'], subset['y'], label=category, 
              alpha=0.7, s=100, edgecolors='black', linewidth=0.5)

# 4. Enhance with labels and formatting
ax.set_xlabel('X Variable', fontsize=12, fontweight='bold')
ax.set_ylabel('Y Variable', fontsize=12, fontweight='bold')
ax.set_title('Professional Visualization Example', fontsize=14, fontweight='bold')
ax.legend(framealpha=0.95, fontsize=10)
ax.grid(True, alpha=0.3, linestyle='--')

# 5. Optimize layout
plt.tight_layout()

# 6. Save high-quality output
plt.savefig('professional_plot.png', dpi=300, bbox_inches='tight')
plt.savefig('professional_plot.pdf', dpi=300, bbox_inches='tight')
plt.show()

print("✓ Figure saved successfully!")
